# Physics Puzzle

Engine **6.0.0**, Project Format 2/schema 29.

**Classification:** assisted, runtime/project-wide, reversible unless a confirmation states otherwise.

**Workspaces:** Design, Debug.

**Focus:** rigid bodies, joints, Rope2D, collision timeline, deterministic replay and recovery.

## Exact teaching workflow

1. Open the listed workspace and inspect the supplied content.
2. Perform the task described in Focus and resolve every visible Problem.
3. Save, close/reload and confirm authored values and UUID references persist.
4. Play, pause and step; compare Console, Runtime Inspector and Profiler with expected-output.json.
5. Build the configured player, launch it separately and repeat the observable interaction.
6. Recover from the supplied deliberate mistake using Undo, checkpoint, trash or recovery preview.

## Required packages

Only the packages already pinned by project.nova. Networking and plugin operations require explicit permission and never run implicitly.

## Target platforms

Windows x86-64 and Web are locally testable. Other hosts require their matching-host evidence.

## Known limitations

Publisher signing, two independent clean machines, real browser/hardware coverage and the 72-hour wall-clock soak remain pending external evidence.
