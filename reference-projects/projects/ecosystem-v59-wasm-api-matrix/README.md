1. Open **Ecosystem Studio** and select the matching Extensions, Package Lab, Templates, Delivery or Audit tab.
2. Inspect every permission and qualification gate before loading, trusting or preparing a plan.
3. Confirm that blocked samples remain blocked and that opening the project performs no network or process action.
4. Save, reload and repeat the local verification.
