# Nova_A v5.0 migration reference projects

This directory contains the complete supported schema 5–29 input/output matrix. Each expected file is generated by the same pinned Rust format authority used by desktop and WASM builds. Schema remains 29 while the 5.0 compatibility seal advances compatible projects to the frozen 5.x `<6.0.0` engine boundary. Malformed, missing, duplicate, and future-schema rejection cases remain in the Rust and fault/fuzz suites.
