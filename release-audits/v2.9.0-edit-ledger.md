## Consequence review

- Existing projects migrate in memory; schema 22 is only written on save. Newer unknown schemas are rejected rather than guessed.
- Android, telemetry, networking and external tools remain opt-in. Missing platform tools cause validation errors, not partial output.
- Signing secrets are never stored or executed; only identity/profile handoff metadata is persisted.
- Stable serialization sorts object keys but preserves arrays, so semantic scene/entity ordering does not change.
- Registry browsing is data-only; installation is separate. Native extension download/execution remains prohibited.
- Status snapshots, telemetry, tests, jobs, conflicts, locks, temporary files and reports all have explicit bounds or expiry.
- Responsive UI changes hide no feature: a selector replaces tabs only when the container cannot display them safely.
