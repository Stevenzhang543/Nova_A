# Nova_A 5.5.0 candidate release notes

## Materials, effects and particles

Nova_A 5.5 adds deterministic visual material graphs for Sprite, UI and Light targets, named input authoring, capability previews and inspectable generated source. Version-3 materials add up to sixteen ordered Tint, Mask, Gradient, Palette, Outline, Dissolve or Distortion layers with Alpha/Additive/Multiply/Screen blending. WebGL2 compiles graph/layer output into isolated material programs; Canvas2D applies its supported color approximations and names unsupported fallbacks. A shader failure falls back only the affected material.

Post processing now uses editable presets and bounded priority camera volumes. WebGL2 runs exposure, contrast, saturation, vignette, bloom and blur through the scene framebuffer even without a custom post material; Canvas2D retains its documented approximation. A visible estimate reports passes and expected 1080p cost.

Version-2 particle-system assets add ordered Spawn, Shape, Velocity, Force, Color, Size, Rotation, Collision, Events, Sub-emitter, Trail and Renderer modules. Simulation remains deterministic CPU; WebGL2 uses GPU-batched drawing while Canvas2D honestly reports CPU drawing. Collision/death/sub-emitter events and trails are bounded. Opening legacy assets no longer mutates a selected emitter. Diagnostics adds actual atlas/import thumbnails and actionable draw-call, overdraw, batch and texture-budget remedies.

Project Format 2/schema 29, Rhai API 2, Plugin API 2, Package Manifest 1, Build CLI 1 and workspace document 3 remain compatible. Signing, independent clean-machine lifecycle, matching-host non-Windows builds and real wall-clock soak remain external gates and are not claimed.
