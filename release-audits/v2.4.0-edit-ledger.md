# Nova_A v2.4.0 edit ledger

This ledger covers the v2.4.0 release work layered on the existing v2.3.0 working tree. No feature, source file, or user data was deleted.

- `src/editor/animationStudioState.ts` — shared playhead, snap, record, selection, and visible-clip recording state.

## Consequences and compatibility

- Old clip/controller documents normalize to the v2.4 document versions without changing their existing key values or visual output.
- Project Format 2 advances from schema 16 to 17. Schemas 5–16 still migrate; unsupported future formats are rejected; unknown asset fields round-trip.
- Animation/Timeline sampling uses fixed ticks and explicit sample rates, so render FPS does not change authored motion.
- Controller preview now enters the authoritative play-session snapshot and therefore restores editor state on Stop.
- Rigging and Timeline cost is opt-in; player packs omit their unreferenced resource classes.
- Text Input became less horizontally stretched (300 x 96 instead of 360 x 88). No other existing component default changed.
- No deletions were made.

## Known non-blocking limitations

- Vite reports the shared crash-reporting/player chunk at about 514 kB minified. It is a performance optimization opportunity, not a compile/runtime failure.
- Tauri 2.9.6 reports a missing optional `__TAURI_BUNDLE_TYPE` updater marker while patching MSI/NSIS binaries. Nova_A does not currently ship an updater flow; both installers and the application are produced and launchable. Recheck when adding auto-update support or changing the Tauri toolchain.
