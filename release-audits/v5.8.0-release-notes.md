# Nova_A 5.8.0 candidate release notes

## Networking, replay and services

Nova_A 5.8 adds optional, permission-gated local and direct-connect multiplayer. Protocol 2 provides bounded reliable-ordered and unreliable-sequenced channels, per-peer acknowledgements/retries, declared RPC direction/authority/schema/rate contracts, bandwidth budgets, replicated transform/rotation/velocity state, interpolation, prediction, reconciliation and input-linked rollback.

Network Studio separates Session, Protocol, Replication, Simulation/Replay and Diagnostics. Deterministic lag/loss/duplicate/reorder simulation, Multiplayer Replay 1 comparison, Multiplayer Save 1 checksums, sanitized diagnostic capture and authoritative headless validation are included. Rhai API 2 and generated visual nodes can query callback-boundary network state and invoke declared RPCs, but receive no raw socket access.

Networking is disabled and unloaded by default. No connection starts unless the optional package, project toggle, explicit permission and explicit start policy all allow it. Nova_A provides no mandatory cloud. Project Format 2/schema 29, Rhai API 2, Plugin API 2, Package Manifest 1, Build CLI 1 and workspace document 3 remain compatible. Public Internet NAT traversal, hostile-network review, long cross-host soak, authentication/relay infrastructure, publisher signing and matching-host non-Windows builds remain external gates and are not claimed.
