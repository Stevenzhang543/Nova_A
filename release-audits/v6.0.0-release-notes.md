# Nova_A 6.0.0 candidate release notes

## Stable creator experience

Nova_A 6.0 freezes and exposes seven compatible contracts: Project Format 2/schema 29, Rhai API 2, Graph Format 1, Plugin API 2, Package Manifest 1, Build CLI 1 and workspace document 3. First-run onboarding, a searchable Learning Center and twelve complete guided projects teach the complete author→save→reload→play→build→standalone-player lifecycle. Every public feature has purpose, preconditions, exact steps/result, persistence/export, recovery, mistakes/fixes, accessibility, minimal/production examples and Rhai/graph links in English, German and Chinese.

Large-project qualification covers startup ownership, 10,000 hierarchy objects, 50,000 assets, 1,000 graph nodes, bounded memory and a low-end profile. The Hierarchy ancestor path now uses a prebuilt UUID map instead of repeated world scans. No authored content, shortcut, animation or existing feature was removed.

This remains an honestly labeled local candidate. Publisher/artifact signing, independent clean-machine install/upgrade/repair/uninstall, two-machine reproducibility, matching-host builds, independent browser/hardware accessibility and a real 72-hour soak remain pending external evidence.
