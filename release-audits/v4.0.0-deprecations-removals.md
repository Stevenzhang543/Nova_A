# Nova_A 4.0 removals and deprecations

- The Experimental networked project is removed from the Stable default template list; its package, project type, runtime and reference remain available.
- New writes no longer preserve the 3.9 manifest ceiling `<4.0.0`; migration seals it as `<5.0.0` while schema remains 29.
- Unmaintainable hidden/unsupported Stable platform choices remain unavailable. Dormant compatible metadata is read without implying support.
- Incomplete/unverified package manifests remain disabled and preserved; new Stable installation is rejected.
- No renderer, animation, physics, audio, scripting, UI, world-data, package, build, or collaboration capability was removed.
