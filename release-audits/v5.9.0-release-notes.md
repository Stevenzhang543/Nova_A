# Nova_A 5.9.0 candidate release notes

## Extension ecosystem and platform delivery

Nova_A 5.9 adds a permanent Ecosystem Studio for Plugin API 2 contributions, lifecycle isolation, Package Manifest 1 authoring, canonical Ed25519 signing requests, malicious-package certification, bounded offline registries, Export Template 1, CI Matrix 1, deterministic content caching, Delta Build 1 and explicit deployment connectors. Docks, Inspectors, importers, components, graph nodes, render passes, build steps, templates, commands and settings each map to a declared permission and bounded WASM export.

Native Extension ABI 1 is validation and planning only: binaries are platform/architecture/SHA pinned, permissions are explicit, isolation is sidecar-process, and launch plans set implicitExecution=false. Deployment plans set implicitNetworkOperation=false and executableAction=false. No package import or panel opening downloads content, launches a process or contacts a connector. Project Format 2/schema 29, Rhai API 2, Graph Format 1, Plugin API 2, Package Manifest 1, Build CLI 1 and workspace document 3 remain compatible.

Windows/Web templates are available locally. Publisher identity signing, independent clean-machine lifecycle, Linux/macOS matching-host builds, Android SDK/template/device qualification and real wall-clock soak remain pending external evidence and are not claimed.
