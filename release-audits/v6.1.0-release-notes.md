# Nova_A 6.1.0 candidate release notes

Nova_A 6.1.0 is portable from the repository root at E:\\Nova_A and contains no active dependency on the former OneDrive checkout. The dependency workspace was rebuilt from the lockfile, native and web paths remain repository-relative, and the editor now honors the maximized-window preference before saved geometry while remaining decorated and resizable.

The editor adopts a restrained system-native visual language: system-first variable typography, quieter dark and light semantic colors, consistent control/panel/dialog radii, clearer hierarchy and compositor-friendly motion. Glass remains on transient and floating surfaces instead of every docked panel. English, German and Chinese layouts are qualified through the release scale matrix.

Startup and editing work are reduced without deleting a feature or animation. Heavy workspaces and rare overlays load asynchronously and warm during idle time, pointer moves coalesce to one update per animation frame, render diagnostics publish once per frame, profiler sampling is adaptive, and crash/recovery data loads only when needed. Physics and exported-game cadence are unchanged.

Project Format 2/schema 29 and all frozen v6 creator contracts remain unchanged. Publisher signing, independent clean-machine lifecycle, second-machine reproducibility, matching-host non-Windows qualification, independent hardware/accessibility review and a real 72-hour soak remain pending external evidence.
