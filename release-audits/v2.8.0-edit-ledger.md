# Nova_A 2.8.0 edit ledger

This ledger lists every v2.8 edit by file. No user-facing feature or animation was removed.

## Release identity, build and compatibility

- `Cargo.toml`: advanced the Rust workspace to 2.8.0.
- `Cargo.lock`: refreshed workspace package versions.
- `package.json`: advanced the application to 2.8.0; registered `audit:v2.8` in the full audit chain.
- `pnpm-lock.yaml`: synchronized root package metadata/dependency lock state.
- `src-tauri/Cargo.toml`, `src-tauri/Cargo.lock`, `src-tauri/tauri.conf.json`: advanced native metadata to 2.8.0.
- `src/projects/projectFormat.ts`: advanced frontend format authority to schema 21 / engine 2.8.0.
- `crates/nova_format/src/lib.rs`: advanced Rust format authority; added migration/defaults and bounded validation for production settings, tests, save migrations, jobs, networking replication and headless runtime; added schema-21 tests.
- `src/projects/templates.ts`: marked every built-in template as rendered Game runtime.
- `src/assets/projectFolder.ts`, `src/panels/SettingsPanel.vue`, `src/layout/TopBar.vue`, `src/components/ProjectManager.vue`, `src/components/ScriptStudio.vue`, `src/components/EditorBottomPanel.vue`, `src/world/World.ts`, `src/runtime/crashReporter.ts`, `src/runtime/novaPak.ts`, `src/i18n.ts`: synchronized visible/exported engine identity and schema metadata.

## Production settings, traces and memory

- `src/runtime/production.ts` (new): defined bounded persisted performance/replay/test/data/job/network settings and normalization.
- `src/runtime/profiler.ts`: expanded frame samples with input, allocations, GPU passes and asset jobs; made trace capacity project-configurable.
- `src/runtime/performanceTools.ts` (new): added budgets, memory/asset sampling, bounded lifetime events, leak trends, captures and comparisons.
- `src/components/WorldCanvas.vue`: correlated input/runtime/render timings, GPU passes, job counts and entity lifetime changes per frame; enabled high-quality overlay smoothing.
- `src/components/ProfilerPanel.vue`: built the responsive seven-tab Production Lab; preserved trace/physics debugger; added every v2.8 authoring/diagnostic control and responsive property replication choices.
- `src/components/CommandPalette.vue`, `src/components/EditorBottomPanel.vue`: exposed Production Lab and new asset types without adding inspector clutter.

## Replay, tests and deterministic scripts

- `src/runtime/replay.ts` (new): added replay documents, input snapshots, checksums, bounded history, deterministic PRNG, recording/playback and normalization.
- `src/runtime/testRunner.ts` (new): added isolated four-kind test execution, assertions, timeouts, fixed steps, screenshots, result state and JSON/JUnit report generation.
- `src/runtime/GameplayRuntime.ts`: substituted replay input at fixed boundaries, recorded/checked physics checksums, seeded each script invocation and started/stopped production runtime systems.
- `crates/nova_script/src/lib.rs`: added `random_seed`, deterministic `random()`/`random_range()` and a repeatability/range unit test.
- `src/editor/scriptApi.ts`: documented seeded random functions in the generated Engine API.

## Data, saves and bounded jobs

- `src/runtime/dataResources.ts` (new): added schema/table normalization, validation, asset creation/read/write, CSV/JSON/database-result import and typed accessor generation.
- `src/runtime/jobScheduler.ts` (new): added bounded worker pool, queue, cancellation, timeouts, status, shutdown and serialized fallback; fixed saturation/fallback lifecycle.
- `src/runtime/jobScheduler.worker.ts` (new): added bounded CSV/JSON parsing, hashing and comparison worker tasks.
- `src/assets/AssetDatabase.ts`: registered Data Schema, Data Table and Replay inference/folders/text editing/load normalization.
- `src/runtime/saveGame.ts`: added versioned save envelopes and ordered rename/default/remove migrations with gap/future-version rejection.
- `src/store/physics.ts`: persisted, loaded and reset production settings with project state.

## Optional networking and native UDP

- `src/runtime/packages.ts`: registered the compatible official optional networking package and 2.8 package compatibility default.
- `src/runtime/networking.ts` (new): added WebSocket/native UDP transport abstraction, safe bounded messages, bidirectional bandwidth budget, connect/disconnect/reconnect, RPC, authority/property-aware snapshots, interpolation, prediction, rollback and diagnostics.
- `src/runtime/productionRuntime.ts` (new): lazy-loaded networking only for enabled projects and generation-guarded asynchronous startup/shutdown.
- `src-tauri/src/lib.rs`: added bounded nonblocking UDP open/send/receive/close commands and socket state; synchronized release/log metadata.
- `src-tauri/capabilities/default.json`: retained only required app capabilities for current editor/manual/external-link behavior.

## Headless build

- `src/runtime/buildSettings.ts`: added normalized/persisted Game vs. Headless Server runtime mode.
- `src/components/BuildSettingsPanel.vue`: added runtime-mode selector and translated headless requirements.
- `src/runtime/gameExporter.ts`: validated native target, networking package/settings and authority role before headless export.
- `src/PlayerApp.vue`: omitted renderer UI and drove fixed gameplay with a cleaned-up timer in headless packages.
