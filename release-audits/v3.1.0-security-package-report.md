# Security and package-permission report

- Tauri main-window mutation permissions are limited to fullscreen, size, position, and center; opener URLs remain scoped to the Nova_A GitHub project/security pages.
- Browser alert, confirm, and prompt calls are absent.
- Safe Mode disables unverified/non-Whitelist third-party packages and restores safe layout.
- Package browsing remains data-only; install/update/uninstall are explicit, validated, history-tracked operations with impact confirmation and Task Center reporting.
- Native package extensions remain blocked. Plugin API 2 WASM permissions, hashes, signatures, memory/call limits, fault isolation, and project enablement retain their v3.0 audits.
- Dependency vulnerability audit reported no known vulnerabilities on this lockfile during release qualification.
- No dependency versions or external permissions were added for v3.1.
