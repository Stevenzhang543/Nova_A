# Nova_A 2.7.0 edit ledger

This ledger records every v2.7 source, configuration, documentation, audit, and release edit. No user-facing feature or animation was removed.

## Fatal manual-opening correction

- `src/runtime/openManual.ts`: replaced the rejected Tauri internal-URL/webview flow with bounded reactive state for an in-app manual viewer.
- `src/components/ManualViewer.vue`: added the same-origin full-screen manual overlay, loading state, reload and close controls.
- `src/App.vue`: mounted the manual viewer in editor and project-manager flows.
- `src-tauri/capabilities/default.json`: removed the obsolete manual window target while retaining the allowlisted external GitHub opener.

## Responsive UI, themes, localization, and accessibility runtime

- `src/runtime/gameUi.ts`: implemented responsive layout resolution, safe areas, size/aspect policies, breakpoints, containers, RTL order, nested clips/masks, wheel scroll views and scrollbars, themes/states, localization/font fallback, focus/gamepad navigation, accessibility export and input-remap capture.
- `src/runtime/uiTheme.ts`: added bounded theme documents, variables, state classes, parent inheritance, asset persistence, style resolution and sanitized overrides.
- `src/runtime/localization.ts`: added bounded locale/table models, live locale state, fallback, plural/select, variables, number/date formatting, pseudo text, RTL and font fallback.
- `src/runtime/presentation.ts`: added separately persisted runtime accessibility settings.
- `src/runtime/input.ts`: exposed safe input-action rebinding while preserving action semantics.
- `src/components/WorldCanvas.vue`: connected game-wheel scrolling, remap history, focus/accessibility nodes and screen-reader DOM export to the canvas runtime.
- `src/world/components.ts`: expanded Canvas, RectTransform, Panel, Text and controls with v2.7 layout/theme/localization/focus/accessibility/remap fields; expanded AudioSource with routing/priority/streaming/attenuation fields.
- `src/store/physics.ts`: normalized, persisted, restored and referenced every v2.7 component, presentation and audio setting; sanitized style overrides.

## Audio mixer and asset workflow

- `src/runtime/audio.ts`: replaced the flat bus layer with a bounded Web Audio graph supporting parent buses, sends, mute/solo, effects, wet/dry, delay feedback, meters, snapshots, ducking, spatial curves, streaming and voice limits; fixed legacy-gain synchronization and live loop-marker updates.
- `src/assets/types.ts`: added UI-theme type/folder and audio normalization/loop import settings.
- `src/assets/AssetDatabase.ts`: added `.nova-theme` creation/loading and deep import-setting migration so old audio records receive every new nested default.
- `src/components/PresentationPanel.vue`: added UI/theme, localization, mixer/waveform and runtime-accessibility tabs with only Nova-native dialogs.
- `src/components/RuntimeComponentsInspector.vue`: exposed responsive layout, safe area, focus/a11y/remap, localization, theme/style, scroll and advanced AudioSource properties.
- `src/runtime/novaPak.ts`: stripped unselected localization assets from players while always preserving the source locale.

## Editor discovery and localization

- `src/store/editor.ts`: added the persistent Presentation bottom-tab identifier.
- `src/editor/workspaces.ts`: included Presentation in bottom tools and made it the Interface workspace surface.
- `src/components/EditorBottomPanel.vue`: mounted/filter-routed Presentation and UI-theme assets and updated visible release metadata.
- `src/components/CommandPalette.vue`: added the Presentation command.
- `src/i18n.ts`: added and translated every v2.7 editor/inspector/manual string in English, German and Chinese; updated release labels.
