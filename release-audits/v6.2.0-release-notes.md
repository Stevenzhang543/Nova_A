# Nova_A 6.2.0 candidate release notes

Nova_A 6.2.0 adds opt-in behavior contracts to the frozen Rhai API 2 runtime. Existing scripts remain valid. New scripts can declare strict and deterministic intent, required components, input actions, assets and packages, plus per-callback command and log budgets below the global sandbox limits.

Script Studio now has a localized Contract page with requirements, budgets, API module, thread, determinism and permission information. The runtime, Project Health and Build Settings use the same analyzer, so missing requirements and false deterministic claims fail before release. Visual Graph 1, graph-to-Rhai synchronization, Project Format 2/schema 29 and every existing editor feature and animation remain unchanged.

The release includes the complete code-derived feature inventory and a comparison-led 6.2.0–7.0.0 implementation manual. Publisher signing, independent clean-machine lifecycle, second-machine reproducibility, matching-host non-Windows qualification, independent hardware/accessibility review and a real 72-hour soak remain pending external evidence.
