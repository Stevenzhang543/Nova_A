# Nova_A 2.6.0 edit ledger

This ledger records every source/documentation edit included in the 2.6.0 workspace release, including the completed 2.5 asset/package foundation that had not yet been packaged.

## Root, build, and version metadata

- `Cargo.toml`, `Cargo.lock`: moved every workspace crate and lock entry to 2.6.0.
- `package.json`: moved the app to 2.6.0; added v2.5/v2.6 connectivity audits to the complete audit command.
- `README.md`, `README.zh-CN.md`: documented 2.5 asset/package tooling, 2.6 world/gameplay systems, Schema 19, optional packages, exact CharacterBody units, build gates, and complete release deliverables.
- `vite.config.ts`: preserved workers/manual assets and production chunk boundaries needed by imports and optional gameplay packages.
- `scripts/package-release.ps1`: added repeatable, validated packaging for portable EXE, MSI, NSIS, web/source ZIPs, license, notes, and SHA-256 checksums.

## Rust format, physics, runtime, scripting, and WASM

- `crates/nova_format/src/lib.rs`: upgraded to Schema 19/engine 2.6; normalized and validated world/package settings; registered all gameplay components; validated AI/pool asset references; added migration, bounds, preservation, and fresh-component regression tests.
- `crates/nova_physics/src/lib.rs`: exported the character query result/API.
- `crates/nova_physics/src/query/mod.rs`: added masked/excluding box shape casts and an exact-unit character controller with slopes, steps, slide limits, floor snap, one-way handling, moving-platform velocity, and regression coverage.
- `crates/nova_physics/src/world/persistent.rs`: added retained-world character movement plus accumulating one-tick transient forces that do not trigger configuration rebuilds; added tests.
- `crates/nova_physics/src/world/legacy.rs`: kept the legacy façade compatible with new force/query behavior.
- `crates/nova_physics/src/rope/mod.rs`, `crates/nova_physics/src/solver/contact_solver.rs`, `crates/nova_physics/src/tests.rs`: retained the audited 2.5 rope/collision corrections and their exact-force/fragment/contact regression coverage.
- `crates/nova_runtime/src/lib.rs`: exposed character motion and transient-force commands through the retained runtime.
- `crates/nova_wasm/src/lib.rs`: exposed JSON character results and force calls to TypeScript.
- `crates/nova_script/src/lib.rs`: added CharacterBody snapshots, movement/despawn commands, floor/wall/ceiling/coyote helpers, vector normals/platform velocity, and matching aliases.
- `nova_core/src/lib.rs`: retained the backend façade and workspace version integration.
- `src-tauri/Cargo.toml`, `src-tauri/Cargo.lock`, `src-tauri/tauri.conf.json`, `src-tauri/src/lib.rs`: moved desktop metadata/default project values to 2.6.0 and Schema 19.
