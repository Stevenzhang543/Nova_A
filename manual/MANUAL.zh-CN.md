## 1. 快速开始

1. 启动 Nova_A，首先进入项目管理器。
2. 选择模板、输入项目名并点击**创建项目**；也可以用**打开项目**选择现有 `.nova`／JSON 文件。
3. 在“场景”页创建和摆放对象，在对象检查器中添加组件。
4. 在“设置 > 输入映射”中创建具名操作，不要在脚本里写死键位。
5. 点击**运行**，在“游戏”页测试；使用暂停和单步定位问题。
6. 用“文件 > 保存项目”保存可继续编辑的项目。
7. 打开“构建设置”，排列场景、指定启动场景和目标平台，然后构建。

编辑状态与运行状态相互隔离。停止运行时，Nova_A 会恢复按下运行前的编辑快照，运行期间产生的临时变化不会污染项目。

## 2. 项目管理器与模板

- **打开项目**：验证并打开 `.nova`／JSON，保留原项目 UUID。
- **导入项目**：把所选项目作为副本打开，并生成新的项目 UUID。
- **继续项目**：返回进入管理器之前的项目。
- **项目名称**：用于显示与构建，自动清理非法字符，最长 80 字符。
- **创建项目**：生成并立即审计所选模板；缺失必要系统时会拒绝打开。
- **最近项目**：保存本地快照。项目太大而无法缓存时，需要重新选择文件。
- 最近项目旁的 **×**：只删除历史记录，不会删除项目文件。
- **语言**：立即切换英文、德文、中文。
- **使用手册／GitHub**：打开本地手册或源代码仓库。

四个模板：

- **空白 2D**：干净场景、Camera2D、输入映射、构建设置。
- **平台跳跃**：精灵、动画、输入、脚本、刚体、碰撞体、瓦片地图、音频和 HUD。
- **俯视角**：两个场景、预制体生成、触发器切场景、敌人巡逻、粒子与存档。
- **物理沙盒**：刚体、材质、距离关节，以及可碰撞、可断裂的物理绳索。

## 3. 编辑器布局与按钮

### 文件菜单

- **项目管理器**：记录当前项目后回到启动页。
- **保存项目 / Ctrl+S**：保存完整可编辑项目，不是游戏存档。
- **导入项目**：使用与项目管理器相同的迁移、验证和元数据流程。
- **清空场景**：通过 Nova_A 自己的确认框删除当前场景对象与连接，可撤销。

### 编辑菜单

- **撤销 / Ctrl+Z**；**重做 / Ctrl+Y 或 Ctrl+Shift+Z**。
- **复制 / Ctrl+C**、**粘贴 / Ctrl+V**、**重复 / Ctrl+D**：保留组件和层级，但生成新 UUID。
- **重命名 / F2**、**删除 / Delete 或 Backspace**、**取消选择 / Escape**。

### 视图与帮助

- **网格**只控制平行网格线；X 轴、Y 轴、全部坐标轴不会再隐藏网格。
- **重置相机**恢复编辑器平移与缩放。
- **控制台／性能分析／项目／构建设置**打开相应底部面板。
- **帮助**包含本手册和 GitHub；版本胶囊显示当前版本。

### 页面与鼠标工具栏

- **场景**：可编辑世界、选择轮廓、层级、图层与变换手柄。
- **游戏**：活动 Camera2D 的输出和运行时 UI；原生文本输入在这里工作。
- **设置**：主题、语言、无障碍、默认物理值、输入、音频、插件、存档与安全项。
- **选择**：点击对象；Shift 切换选择；拖动空白处框选。
- **移动／旋转／缩放**：操作选中对象，支持吸附。
- **矩形／椭圆／三角形**：按下并拖到松开创建；退出检查器时的短点击会被抑制，避免误画。
- 滚轮缩放；中键或右键拖动按当前上下文平移。
- **运行**启动隔离运行时；**暂停**冻结；**单步**精确推进一个固定物理 tick；**停止／重置**恢复编辑快照。

### 工作区、面板与命令面板

顶栏下方提供五种任务布局。**设计**显示层级与检查器并折叠底部抽屉；**脚本**打开较高的资源抽屉；**动画**打开动画工具；**界面**保留场景、层级与检查器；**调试**切换到游戏视图并打开控制台。切换工作区只会重新排列现有工具，不会删除项目数据或功能。

**H**、**I**、**B** 分别显示或隐藏层级、检查器和底部面板。**专注模式**会临时隐藏这三个面板，但不会清除保存的布局。布局设置只保存在本机，不会修改项目文件。通过“视图 > 重置布局”恢复默认设计工作区。编辑器支持的最小窗口为 900 × 600。

按 **Ctrl/Cmd+K** 或 **Ctrl/Cmd+Shift+P** 打开命令面板。搜索可找到工作区、场景/游戏/设置页面、所有底部工具、面板开关、专注模式与布局重置。方向键、Enter 和 Escape 可完成纯键盘操作。

检查器头部会在滚动时保持可见。搜索框按区段或组件名称过滤；分类包括全部、常规、变换、渲染、物理、玩法与界面。顶部的**添加组件**按钮打开可搜索、已分类的组件选择器，不再要求滚动到底部。搜索和分类只改变显示，不会禁用或删除组件。

## 4. 场景、层级与图层

层级面板列出活动场景内全部实体。搜索按名称过滤；箭头展开子对象。重新设父级使用 Transform2D 的父 UUID，并拒绝循环层级。锁定对象不能编辑；编辑器隐藏对象仍保留在项目中。

图层可创建、重命名、复制、排序、隔离和删除。渲染排序层与物理层是两套概念：物理交互需要层号和碰撞掩码互相允许；连接系统还要求对象位于同一编辑图层。不同层对象不会发生碰撞或连接作用。

场景列表支持创建、复制、加载／卸载、重命名、删除和切换。运行时可用场景 UUID 或准确名称切换。标记为“跨场景保留”的实体会在切换时继续存在。

## 5. 对象检查器与右侧添加区

常用属性包括名称、启用、可见、锁定、标签、图层、预制体状态和组件。组件按类型提供启用、复制、粘贴、重置和移除。Transform2D 必须存在，不能移除；标记为唯一的组件不能重复添加。

数值必须有限；只有真实格式或物理边界才会被限制。输入位置 10 或移动 10，会严格对应 10 个世界／网格单位。

右侧 UI 添加区包含 Canvas、Panel、Image、Text、Button、Slider、ProgressBar、Checkbox、TextInput。非 Canvas 元素会自动使用已有根 Canvas；没有时自动创建。新控件具有清晰可见的默认大小和错开位置。所有 UI 都能在场景页和游戏页看到、选择、编辑。Image 可直接导入项目图片，丢失图片显示诊断占位符。TextInput 在游戏页使用原生输入，支持中文输入法、选择、粘贴、多行和密码模式。

## 7. 物理系统

Nova_A 使用持久化 Rust PhysicsWorld 和固定时间步。渲染在 30、60、144 或 240 FPS 下不会改变模拟结果。场景设置可调整 tick 频率和最大追赶步数。

- 动态刚体整合力、冲量、重力和碰撞；运动学刚体按速度移动并能推动动态体；静态刚体不移动。
- 自动质量 = 密度 × 面积；自动惯量使用形状解析公式。力持续作用，冲量瞬时作用；扭矩／角冲量遵循施力点和惯量。
- 线性／角阻尼与时间步无关；摩擦可大于 1；恢复阈值可抑制低速弹跳。
- 传感器只发送进入／保持／离开事件，不产生碰撞冲量；单向平台只从配置方向阻挡。
- Discrete 成本较低；Continuous 对高速刚体使用自适应子步，减少穿透。
- 静止刚体会休眠；力、冲量、变换或有效接触会唤醒。
- 射线、全部射线、点／形状重叠和形状投射遵循掩码，并返回有序精确结果。

物理和渲染严格分离：SpriteRenderer 不会自动创建碰撞体，碰撞体也不会自动显示图形。

## 8. 连接、绳索、关节与绑定

在对象的“连接”区选择同一图层的两个对象，然后选**直线**或**手绘**。从第一个对象的中心、表面、边上点或顶点拖到第二个对象。蓝色外圈与白点表示中心；“显示中心”可临时隐藏或显示。

拉伸、弯曲、刚度、阻尼、最大伸长、弯曲／拉伸承重、粗细、线密度、碰撞都真正连接到运行时。直线在对象移动或缩放时重新连接锚点；手绘路径作为采样绳索自然变形。绳索永不与两端原对象碰撞，但可与其他同层对象碰撞。节点碰撞冲量沿绳索传到锚点，再给物体施加力和扭矩。负载超限会在正确链节断裂，剩余绳段继续参与模拟。

对象重叠时，**绑定**生成复合刚体：隐藏内部重叠边界，拖动任一部分会一起移动，质量、惯量和碰撞响应按整体计算。**拆分**恢复独立对象。

## 9. 渲染器与相机

正式渲染后端为 WebGL2，Canvas 只承担安全的编辑器覆盖层。渲染命令会批处理，并按排序层和层内顺序绘制；支持纹理图集、过滤、世界文字、瓦片分块和粒子。网格、手柄和选择框不会进入 Nova Player。

底部**渲染**工具显示 World、Lighting、Post Process、Editor Overlay、UI 渲染图，并报告通道耗时、Draw Call、三角形、纹理、渲染目标、过度绘制，以及支持时的 GPU 时间。**捕获帧**生成 PNG；Overdraw、Lighting、Normals 仅用于诊断。

**Light2D** 包含点光、聚光、方向光、区域光；颜色、强度、范围、角度、区域尺寸和 32 位遮罩均参与渲染。环境光是项目设置。**ShadowCaster2D** 与 Off／Hard／Soft／Ultra 控制阴影；SpriteRenderer2D 法线贴图产生方向性光照。

材质保存安全 GLSL ES `nova_material`、最多 8 个纹理、32 个有限统一变量、四种混合、Nearest／Linear、sRGB／Linear 和颜色写入。运行时循环和危险操作被拒绝，源码上限 32 KB；实时诊断与默认回退保护帧。材质也可作为全屏后处理材质。

Camera2D 支持优先级／堆叠、视口、剔除遮罩、排序范围、像素完美和命名渲染纹理。可选后处理包含曝光、对比度、饱和度、暗角、泛光、模糊、用户材质；仅用户材质分配可选 WebGL 帧缓冲。世界精灵和 UI Image 支持九宫格；导入保存图集、过滤、sRGB／Linear 和平台压缩变体。Canvas2D 继续作为后备。

Camera2D 决定游戏页：正交尺寸控制可见世界高度，Zoom 继续缩放；Viewport 使用 0–1 归一化坐标；Pixel Perfect 适合像素画；背景先于场景绘制。网格总在对象下方。丢失资源显示占位符并写入控制台，不让编辑器崩溃。

## 10. 资源系统

标准目录包括 Scenes、Sprites、Audio、Scripts、Fonts、Prefabs、Plugins、Tiles、TileSets、Materials、Animations、Controllers；`.nova/cache` 和 `.nova/imported` 由引擎管理。

- **导入资源**导入支持文件并分配永久 GUID。
- Scripts、Animation Clip、Animator Controller、TileSet 等按钮创建对应类型资源。
- 导入设置包含过滤、压缩、每单位像素、区域、轴心和是否加入图集。
- 重命名、移动、复制、删除会更新数据库；引用使用 `asset://UUID`，不依赖文件名。
- 缺失引用不会悄悄消失，用户可以修复。
- 支持时使用 File System Access API 绑定项目文件夹，否则通过保存／导入文件工作。

## 11. 输入与脚本参考

输入操作有 Button、Axis、Vector2。绑定支持键盘、鼠标按钮／滚轮、手柄按钮／轴，并可设置缩放、向量分量、手柄序号和死区。

Rhai 生命周期：`awake()`、`start()`、`fixed_update(dt)`、`update(dt)`、`late_update(dt)`、`on_destroy()`、`on_timer(name)`，以及碰撞 Enter／Stay／Exit 和触发器 Enter／Exit。用 `@export let speed = 5.0;` 暴露检查器属性。

读取 API：

- `entity()`、`entity_name()`、`find_entity(name)`、`has_component(kind)`、`get_component(kind)`。
- `transform()`、`rigid_body()`、`animator()`、`audio_source()` 返回安全快照／句柄。
- `time()` 与所有 `time_*`；`input_down/pressed/released` 及别名；`input_axis/axis`；`input_vector/vector`；鼠标与滚轮。

命令 API：

- `apply_force`、`apply_impulse`、`set_velocity`、`set_position`、`set_rotation`、`set_scale`、`set_angular_velocity`。
- Animator 的 bool／float／integer／trigger／play；音频 play／pause／stop。
- `instantiate(assetReference)`、`destroy()`、`scene_load(nameOrUuid)`、`scene_reload()`、`scene_quit()`。
- timer start／pause／resume／cancel，以及下文 Save API。

脚本不能访问文件系统、网络、进程、DOM 或动态导入。操作数、调用层级和表达式深度限制会终止失控脚本。单个坏脚本会被禁用并记录资源来源，不会结束其他脚本或编辑器。

## 12. 动画、音频、UI、瓦片地图与粒子

动画工作室会按资源类型打开剪辑、控制器、动画遮罩、骨架、蒙皮和时间轴。摄影表和曲线编辑器支持多目标轨道、框选／多选、按帧吸附、拖动、复制粘贴，以及 Auto、Linear、Constant、Free 切线。精灵帧和信号／载荷事件共用精确时间。显式“录制”模式会把检查器和移动／旋转／缩放 Gizmo 的修改写成吸附关键帧。

Animator Controller 支持类型化参数默认值、状态与子图、条件、退出时间、过渡时长和中断策略、带权／叠加图层、属性遮罩以及一维混合树。“运行时实时预览”会在使用该控制器的对象上启动所选状态。曲线和事件在固定模拟 tick 采样，不受渲染帧率影响；动画事件通过有界信号队列进入 `on_signal`。

骨架资源保存父子骨骼、局部位置／旋转／缩放／长度、IK 链、旋转／复制／位置约束和姿势工具。蒙皮资源保存网格顶点、UV、三角形和归一化骨骼权重。给对象添加 `Skeleton2D` 并指定匹配的骨架和蒙皮后，逆绑定姿势会在 WebGL2 与 Canvas2D 中变形精灵；`Skeleton2D.pose` 可覆盖每根骨骼的局部姿势。

时间轴支持 **Animation、Audio、Camera、Event、Visibility、ScriptCall** 轨道。给对象添加 `TimelinePlayer`，再设置资源、自动播放、循环、速度和当前时间。一次性片段在固定步跨过开始点时也会正确触发。

在资源检查器中选择动画目标，指定另一个源剪辑、1–240 Hz 采样率和可选属性映射，然后点击“重新导入动画”。Nova_A 会确定性重采样并保留目标 GUID，源剪辑不会被修改。

音频通过 AudioSource 播放；混音器有 Master、Music、SFX、UI 总线和采样率。AudioListener 提供空间位置；Spatial Blend 与最小／最大距离控制衰减和平移。

运行时 UI 基于 Canvas／RectTransform，支持悬停、按下、点击、拖动 Slider、切换 Checkbox 和输入文字；ProgressBar 只显示。UI 遵循层级和 Canvas 排序。

TileMap 可绘制、擦除、拾取和填充，按 Chunk 渲染；碰撞可选 None、Box、Polygon、OneWay。ParticleEmitter 使用有上限对象池、确定性随机种子、发射率／爆发、寿命、速度、颜色／透明度插值和纹理。

## 13. 场景、预制体与运行模式

每个场景独立保存实体、连接、图层和全局物理设置。预制体来自实体子树，实例记录 `prefabAsset`、源 UUID 和覆盖表。应用预制体更新未覆盖属性；还原会删除覆盖。缺失预制体保持可诊断。脚本实例化请求会在安全的结构阶段执行。

运行时先快照编辑文档，再启动输入、脚本、音频、动画和插件，并组合固定物理更新与渲染更新。暂停停止正常推进，单步只走一个固定 tick，停止执行销毁生命周期并恢复快照。

## 14. 控制台、性能分析器与物理调试器

控制台级别：Trace、Debug、Info、Warning、Error、Fatal。支持级别／类别过滤、搜索、清空和点击源文件。类别区分 Engine、Runtime、Physics、Script、Asset、Build、Save、Plugin；日志数量有上限。

性能分析器显示帧、物理、脚本、渲染、动画、音频、资源、FPS、刚体数、Draw Call 和内存，保存 180 个样本；Freeze 冻结，Clear 清空。

物理调试器可显示碰撞体、AABB、接触点、法线、关节、绳索节点、休眠刚体，只改变可视化，不修改模拟。前端／原生致命异常会尽可能写崩溃日志；单个资源、脚本或插件错误不会带崩整个编辑器。

## 15. 游戏存档 API

游戏存档与项目／场景序列化分开，并按项目 UUID + Slot 隔离。支持有限数字、布尔、字符串、null、嵌套数组和 Map；拒绝引擎对象与任意二进制。

- `save_has(key)`、`save_get(key, fallback)` 读取当前工作数据。
- `save_set(key, value)`、`save_delete(key)`、`save_clear()` 修改。
- `save_load(slot)` 从槽位替换工作数据。
- `save_commit(slot)` 校验深度／大小后持久化。

“设置 > 游戏存档”可选择槽位、加载、提交、清空并预览 JSON。限制：序列化后 1 MB、深度 8、每个集合最多 2,000 项。

## 16. WASM 插件基础

Nova_A 2.0 只接受保守的 WebAssembly 插件，不加载原生 DLL。在“设置 > 插件”中同时选择 manifest JSON 和对应 `.wasm`。

清单字段：反向域名 `id`、名称、语义版本、`apiVersion: 1`、引擎范围、安全相对入口、权限（仅 `log`、`events`）、启用状态。模块必须导出返回 1 的 `nova_plugin_api_version()` 和 `nova_plugin_init()`；可选 `nova_plugin_update(delta)`、`nova_plugin_shutdown()`。

插件只获得数值、日志、事件接口；没有文件、进程或网络权限。超过 16 MB、不安全路径、未知权限或不兼容 API 会被拒绝。运行时 trap 会让该插件在本次运行中停用，避免每帧重复报错。

## 17. 构建与导出

构建设置包含：游戏名、Windows／Linux／macOS／Web、桌面 x86_64、可上下移动的场景顺序、必须在列表内的启动场景、开发构建、输出目录。Windows／Linux 可选择单文件；默认导出 Player + `game.nova-pak`。**构建**只打包，原生目标的**构建并运行**还会启动结果。

`.nova-pak` 包含 magic／版本头、路径／类型／GUID 索引、相对偏移、原始／存储长度、可选 gzip 数据块和 SHA-256。加载会拒绝路径穿越、越界和校验失败。

桌面目标要在对应操作系统构建；Web 输出静态文件。导出的 Player 没有编辑器菜单、面板、网格和手柄。CI 在 Windows、Linux、macOS 检查 Rust 测试／lint、TypeScript、手册完整性、WASM／前端生产构建和 Tauri 后端。

## 18. 迁移与兼容性

Nova_A 2.0 正式声明 **Nova_A Project Format 2**，当前 2.9 使用 Schema 22，最低支持旧 Schema 5。项目包含格式名称／主版本、Schema、引擎版本、兼容记录和项目元数据 UUID。Schema 22 校验平台与交付设置，并保留生产、呈现、音频、世界、骨架／蒙皮、时间轴和未知资源字段。

打开旧项目会按顺序迁移数字 ID、组件、层级、场景、资源、预制体、输入、音频、瓦片、粒子、关节、构建设置和 2.0 元数据。有效数据会保留。遇到更新的主版本／Schema 时会明确拒绝，不猜测转换。

迁移前保留备份或 Git 提交；迁移后检查资源缺失、脚本、图层、场景和构建顺序，再保存为 Format 2。2.0 起，任何未来 Schema 改动都必须提供迁移。

## 19. 三个完整教程

### 教程 A：物理游乐场

创建“物理沙盒”。检查两个刚体与碰撞体，修改恢复系数和摩擦并运行。查看 DistanceJoint2D。打开绳索连接，启用物理碰撞，改变刚度／阻尼。打开碰撞体、关节、绳节点调试层。增大负载直到绳索断裂，观察两段继续模拟。

### 教程 B：平台跳跃

### 教程 C：俯视角游戏

创建“俯视角”。WASD 移动，E 生成敌人预制体。检查敌人巡逻脚本和玩家粒子。进入 Exit Trigger 后，脚本会保存检查点并切换到 Main Menu。回到“设置 > 游戏存档”加载 `slot1`。修改预制体并应用，确认实例覆盖仍保留，最后按正确顺序构建两个场景。

## 21. 脚本工作室 2.2

“脚本”工作区现在打开独立的全宽编辑器。左侧包含项目文件和源代码搜索；上方是文件标签；中央 Rhai 编辑器支持行号、断点、查找替换、行列状态、补全、签名/上下文帮助与转到定义；右侧提供诊断、符号、模块、调试器、测试、信号和由统一目录生成的引擎 API。F2 会先显示应用内确认，并在所有受影响模块都成功编译后才执行项目级安全重命名。

## 21. Nova_A 2.5：资源管线、软件包、Plugin API 2 与物理监视器

### 资源导入与缓存

打开底部面板的**资源**。**导入资源**支持图片、音频、字体、场景、预制体、Rhai 脚本、材质、动画／控制器／遮罩、骨架／蒙皮／时间轴、图块集、图集、着色器和本地化文件。每个任务显示排队、读取、处理、写入缓存、完成、取消或失败；取消操作会停止队列等待、流式读取和哈希。缓存键由源字节 SHA-256、导入器版本、目标平台和规范化设置组成；重复导入会显示**复用缓存产物**。重新导入保持 GUID 不变；失败时报告错误并继续使用上次有效产物。

选择资源可查看预览和专用设置。图片提供过滤、区域、图集、颜色空间、每单位像素、轴心、压缩和平台变体；音频提供试听、标准化、流式播放和采样率；字体提供实际字体预览；脚本显示 UTF-8／模块设置并可进入脚本工作室；图集、图块、着色器、动画和本地化资源都有各自的设置与源预览。

**未使用报告**扫描项目和资源引用；**缺失引用**报告未知的 `asset://` GUID。检查器的“引用与构建”显示引用来源以及资源为何进入 Player 包。移动／重命名会修复路径引用；删除仍使用 Nova_A 应用内确认框，并清理已知场景／文档引用。

### 软件包与 Plugin API 2

在底部面板或命令面板打开**软件包**。视图分为已安装、项目、可更新、不兼容和已禁用。可导入描述本地、Git 或注册表来源的 JSON 清单。Nova_A 校验反向域名 ID、语义版本、引擎范围、依赖、来源类型、哈希与项目锁定文件。导入更高版本会先存入离线缓存作为更新；查看兼容报告后再**应用更新**。如果其他项目软件包依赖它，卸载会被阻止。

Plugin API 2 可声明编辑器命令、菜单、面板、导入器、资源编辑器、自定义组件／检查器、Gizmo、设置页、构建钩子、运行时系统和事件；每种贡献都必须具有对应权限。标准插件在 WASM 沙盒中运行，二进制／内存上限为 16 MB，并限制单次调用时间；同时校验 SHA-256 和可选 Ed25519 签名。原生扩展绝不会被自动下载或运行。软件包可以按项目禁用；插件安全模式会跳过全部第三方代码，`?safe-mode=1` 可单次安全启动。只使用日志／事件权限的旧 Plugin API 1 项目仍兼容。

### 物理监视器与碰撞时间线

点击 Play 或 Pause，右侧会滑出物理监视器而不替换场景／游戏视图。“对象物理属性”显示每个已启用刚体的世界位置（m）、方向、速率、速度、加速度、力、角速度、动能、接触数和活动／休眠状态。数据来自权威 Rust 运行时，渲染插值不会回写物理状态。

“碰撞时间线”记录碰撞／触发的开始、持续和结束，包含对象名称、固定步与会话时间、碰撞点、碰撞前后相对速度、方向变化、法向／切向冲量和法向／摩擦力。冻结保留当前快照，清空只重置时间线，搜索可筛选两个视图，折叠会归还画布空间。历史和渲染行数都有上限；持续接触会更新同一条记录，不会每个固定步无限增长。

### 2.5 发布审计

发布前依次检查：所有模板；每种资源的导入与重导入；取消大文件导入；缓存命中与失败回退；移动／重命名／删除；未使用／缺失／引用报告；兼容、不兼容、API 1、API 2 和原生清单；更新、卸载影响与安全模式；Play／Pause／Step／Stop；移动刚体与碰撞时间线；所有视图、工作区、主题和语言；保存重开；构建并启动 Player。必须通过 Rust 格式、严格 Clippy、全部 Rust 测试、Vue 类型检查、生产构建、全部审计脚本，以及 900 × 600 和普通桌面尺寸下的浏览器冒烟测试。

## 22. Nova_A 2.6：世界、导航与玩法工具

从底部抽屉或命令面板打开**世界工具**。各标签将世界编辑从冗长的对象检查器中分离；“添加”仍走正常撤销历史。

- **CharacterBody2D：**附加到带碰撞体的 Kinematic 刚体。最大斜坡角、台阶高度、地面吸附、安全边距和最大滑动次数会以世界单位传入 Rust 求解器；可继承移动平台速度，并显示地面／墙壁／天花板状态。Rhai 提供 `move_character`、`can_coyote_jump`、接触状态、地面法线和平台速度。配置移动 1 米就会精确移动 1 个世界米。
- **Area2D：**选择 Box／Circle 和掩码，添加重力、风、阻力、浮力、伤害或自定义信号。力只累加到一个 Rust 固定步；进入／离开、伤害和自定义信号使用有界事件队列。
- **导航：**按需启用 Nova 导航软件包，然后编辑多边形／网格区域、静态／动态障碍和代理。支持 A*／流场、对角线、层、重寻路／重烘焙、局部避障和平滑；调试叠加层显示有界路径。纯物理项目不会加载导航模块。
- **AI：**可选游戏 AI 软件包提供行为树和分层状态机资源；动作、进入与退出名称连接运行时信号。
- **流式加载：**WorldChunk2D 保存边界、加载／卸载距离、优先级、估算内存和场景。项目内存预算限制已加载分块，场景任务异步排队；原点移动保持大坐标稳定。Player／CharacterBody 进入 Portal2D 半径时发送 `portal.entered` 并排队加载目标场景。
- **对象池：**ObjectPool2D 选择预制体、预热、容量和有界扩容。`instantiate` 优先取得预备实例，`despawn()` 将其归还；`pool.spawned`／`pool.despawned` 遵循生命周期边界。

**图块地图**面板可创建 Tile Palette、Brush Preset 和 Terrain Rules 资源。可添加、重复、切换或删除带可见／锁定／透明度的图层。图块定义保存地形、导航成本、遮挡体以及 None／Box／Polygon／OneWay 碰撞。“烘焙图块地图”报告合并碰撞形状、导航单元、遮挡体和有界分块；碰撞读取所有可见图层。Schema 19 保存世界预算／调试开关及全部新组件／资源，并保留未知字段。平台跳跃模板已使用 CharacterBody2D 精确移动与土狼时间跳跃。

## 23. Nova_A 2.7：响应式 UI、主题、本地化、Audio 与 Accessibility

从底部抽屉、“界面”工作区或命令面板打开“呈现”。UI 标签集中 Canvas／RectTransform／Panel：锚点、Fixed／Fill／Content 尺寸策略、最小／最大尺寸、宽高比、安全区域、最多 32 个宽度断点、水平／垂直／网格容器、内边距、换行、裁剪、圆角遮罩、滚轮滚动视图、滚动条和可复用 UI 预制体。“保存可复用 UI 场景”会把所选子树保存到 `Assets/Prefabs/UI`。

`.nova-theme` 主题资源包含父主题继承、变量、样式类以及普通／悬停／按下／禁用／聚焦状态。Canvas 选择主题，各控件选择样式类并可单独覆盖背景，预览会实时更新。

RectTransform 启用“可聚焦”后使用 Tab 顺序、可选方向 UUID；没有显式目标时，方向键／D-Pad 选择该方向最近控件。Enter、空格和手柄 0 号键激活。角色、标签、说明会在游戏页导出到有界屏幕阅读器树。Button 设置“输入重映射动作／槽位”后会捕获下一次键盘／手柄按键。运行时无障碍与编辑器对比度、字体、减少动画偏好严格分离。

本地化表保存字符串或复数／选择 Map，支持 `{name}`、`{value, number}`、`{value, date}`。项目可配置源语言、实时预览、回退链、伪本地化、字体回退、RTL 和构建语言；未选择语言不会进入 Player。

音频混音器最多 32 条总线、每条 8 个效果和 16 个 Send，并支持快照、闪避、静音／独奏、表头及声部上限。Low／High Pass、Compressor、Delay、Reverb 会实际使用 Enabled 与 Wet／Dry，Delay 也应用 Feedback。AudioSource 支持总线、优先级、流式覆盖、空间衰减曲线和距离。资源预览显示解码波形、循环起止、标准化目标／增益；性能信息显示活动、流式、缓冲和受限声部。

“帮助 > 手册”在 Nova_A 内以同源覆盖层打开内置页面，不再把内部 `tauri.localhost` URL 交给外部打开器。发布审计需覆盖全部 UI 布局／状态／焦点／重映射、三种语言与伪本地化／RTL／回退、构建语言裁剪、全部混音路由／效果／闪避／快照／声部上限、波形／循环／流式／空间音频、手册、保存／迁移、运行／暂停／单步／停止以及 Web／Windows 全部发布文件。

## 24. Nova_A 2.8：Production Lab、确定性测试、数据、任务与可选联网

从底部面板或命令面板打开 **Production Lab**。**Trace** 用有界历史逐帧记录输入、脚本、动画、物理、音频、渲染、资源、JavaScript 分配和 GPU Pass；Capacity 控制保留帧，Capture 保存可比较快照。物理调试图层只读取权威求解器。**Memory** 设置总计／资源／纹理／音频／脚本预算，显示当前／峰值字节、保留对象与生命周期。Detect leaks 只报告超过观察窗口的对象，绝不自动删除；两个 Capture 可比较字节／对象增减。

**Replay：**设置 Seed／Capacity 后 Record；每个固定步保存规范化输入和物理校验和。停止会创建可导出／播放的 Replay 资源；Play 恢复初始项目、固定种子并替换实时输入，Mismatch 精确显示固定帧、预期与实际哈希。Rhai `random()`／`random_range()` 使用同一确定性流。Nova_A 不承诺任意浮点脚本在全部硬件位级一致。

**Tests：**Add Test 创建 Unit／Scene／Integration／Headless，可设场景、超时、固定步上限和截图。断言支持最少对象数、名称／UUID 对象存在、物理值有限、物理校验和以及无运行时错误。Run Selected／All 输出 Pass／Fail／Error／Timeout；Export JSON／JUnit 供 CI 使用。Headless 不依赖渲染也不截图。

**Data：**Data Schema 定义唯一安全键、String／Number／Integer／Boolean／JSON、Required 和 Default；Data Table 选择 Schema。Import JSON 支持数组或 `{ rows }`，Import CSV 支持表头／引号，Import database result 接收外部工具导出的 JSON 行数组；Nova_A 不保存数据库凭据。Validation 显示行、字段、级别、消息；Generate accessor 下载类型化 TypeScript 接口。存档使用带版本 `nova-save` 封装，按顺序执行 Rename／Remove／Default；迁移缺口或未来版本会被拒绝。

**Jobs：**Worker 数和队列有上限，任务显示排队／运行／完成／失败／取消；Cancel 可移除排队或拒绝未完成结果。无 Worker 时只允许一个可让出主线程的串行回退，反复点击不会无限堆积。

**Networking：**默认未安装、禁用且从 Player 数据剔除。先安装官方联网包，再选择 WebSocket／原生 UDP、端点、Client／Server／Host、收发带宽上限、快照率、插值延迟、预测、回滚。Connect／Disconnect 管理传输、重连定时器和队列；UDP 仅原生 Tauri 可用。Replicate selected 添加当前对象并选择 Authority／属性；RPC／快照有大小和序号校验。诊断显示状态、Peer、延迟、包／字节、丢弃和预测修正。Build Settings 的 **Authoritative headless server** 要求原生目标和已启用联网，移除画布并以有界定时器推进固定模拟。

WebGL 场景／材质启用多重采样，Canvas 使用高质量平滑和圆角端点／连接，文字启用 Kerning／连字／光学尺寸；显式 Nearest 像素画仍保持锐利。发布审计：逐一操作全部 Production Lab 标签／按钮；Trace／Capture／Compare；预算／生命周期／Leak；Replay／Mismatch；四类测试／两种报告；数据导入／校验／存档迁移；Worker／回退饱和与取消；联网未装、安装禁用、WebSocket、UDP、加载中断开；普通／Headless 构建；三种语言、主题、减少动画、900×600 与桌面布局；最后运行格式化、严格 Clippy、Rust 测试、TypeScript、生产构建、静态审计、浏览器冒烟、Tauri 安装包、发布归档与 SHA-256 校验。

## 25. Nova_A 2.9：平台发布、团队协作、软件包与项目升级

### 更清晰的构建设置

打开**项目 → 构建设置**。面板按**概览／平台／交付／团队**分页，避免在超长右栏中寻找。概览包含游戏名、目标、x86_64／aarch64、Debug／Release、运行模式、场景顺序、启动场景、输出和构建／构建并运行。预检错误会阻止导出，警告会说明条件限制；构建并运行只支持与宿主一致的桌面目标。

平台页包含应用标识符、版本、图标、启动图、方向、权限、签名身份和公证配置。Windows、Linux、macOS、Web 使用可复现模板。Android 还必须显式安装官方包，并提供 `ANDROID_HOME`／`ANDROID_SDK_ROOT`、`JAVA_HOME` 和 `NOVA_A_ANDROID_TEMPLATE`；工具链不完整时安全禁用，绝不会生成半成品。主机未附带受限的主机游戏 SDK。

### 确定性构建、CLI 与隐私

交付页控制确定性元数据、增量写入、Store／Balanced／Maximum 压缩、补丁清单、结构化日志、崩溃捕获与遥测。每次构建生成 SHA-256 内容记录、稳定 Build ID、`nova-build-report.json`、缓存清单与可选的新增／修改／删除补丁清单；原生包还带符号映射。

无界面导出示例：`pnpm export -- --project ./project.nova --target web --profile release --output ./Builds/MyGame`。`--architecture`、`--runtime`、`--compression`、`--no-incremental`、`--no-patch` 可调整；`--help` 显示完整有界语法。

遥测默认关闭，只接受标量属性并使用有界队列；只有用户显式开启且端点、隐私政策均为 HTTPS 时才发送。关闭会停止收集并清空队列。结构化日志、崩溃记录与符号文件是独立的交付选项。

### 团队、仓库、升级与模板

团队页按 UUID 显示 Scene／Prefab／Asset／Package／设置的变化，生成 `.gitignore`，并在无 Shell 的前提下启动用户指定的 Diff／Merge。选择传入 `.nova` 后执行 Base／Ours／Theirs 三方冲突检查；合并工具接收有界文件，用户审查后再导入输出。项目锁带所有者与到期时间；稳定 JSON 只排序对象键，不改变有语义的数组顺序。

Registry Browse 显示已验证发布者、评分、权限、文档与安全链接。浏览只读取数据，绝不执行包；只有显式“安装”才修改项目和锁文件。支持离线缓存与主动导入的本地镜像。

打开旧项目会先显示源／目标 Schema、引擎、Scene／Entity／Asset 统计、警告与软件包兼容性审计。建议保留“下载完整升级前备份”。迁移先在内存完成，只有完整校验通过才替换会话；容量允许时保留本机回滚副本，项目管理器提供“下载回滚副本”。

六个模板分别覆盖 Empty、Platformer、Top-down、Physics Sandbox、UI Showcase 和 Networked Optional；创建前均执行审计。v2.9 发布审计还要求逐一检查全部界面／语言／主题／尺寸、保存／升级／回滚、运行／物理、资源／包／团队、全部平台分支、确定性／增量／Delta／CLI／Headless、隐私／崩溃，并通过 Rust fmt／Clippy／测试、TypeScript、静态审计、浏览器交互、Tauri 安装包、归档和 SHA-256。

## 26. Nova_A 3.0：稳定契约、错误恢复与验证证据

打开**帮助 → 工作室状态**可查看 Project Format 2／Schema 22、Runtime API 1、Plugin API 2、Package Manifest 1 和 Build CLI 1。Schema 5–22 使用迁移预览、完整原文件备份、软件包审计、内存校验、原子会话替换与回滚副本；未来 Schema 会在会话改变前被拒绝。
