Nova_A Project Format 2 · Engine 3.0.0

Build complete 2D games.

The complete reference for the Nova_A editor, runtime, physics, production tools, tests, collaboration and standalone export.

1. Quick start

  1. Start Nova_A and choose a Project Manager template, or open a .nova/JSON project.
  2. Create entities in Scene, add components in the Object Inspector and configure named actions in Settings.
  3. Play in Game view; Pause and Step diagnose fixed physics. Stop restores the edit snapshot.
  4. Save the project, order scenes in Build Settings, choose startup/target and Build.

One entered world unit equals one grid unit. Runtime and editor state are deliberately isolated.

3. Every editor command

File

Project Manager caches and returns home; Save Project/Ctrl+S saves the editable document; Import Project migrates/validates; Clear Scene uses the Nova confirmation and remains undoable.

Edit

Undo/Redo, Copy/Paste/Duplicate (new UUIDs), Rename/F2, Delete, Deselect/Escape. Destructive actions use the in-app dialog, never browser confirm.

View and Help

Grid is independent from X/Y axes. Reset Camera restores pan/zoom. Console, Profiler, Project and Build open bottom tools. Help opens this manual or GitHub.

Pages and tools

Scene edits; Game displays Camera2D/runtime UI; Settings configures experience and project systems. Select/Shift/marquee, move/rotate/scale gizmos and rectangle/ellipse/triangle drawing are undoable. Short exit clicks are suppressed. Play starts, Pause freezes, Step advances one fixed tick, Stop restores.

4. Scene, workspaces, hierarchy, layers and inspector

Design, Script, Animation, Interface and Debug workspaces rearrange existing tools. H/I/B independently toggle Hierarchy, Inspector and the bottom drawer; Focus Mode hides them temporarily. Layout choices remain local and Reset Layout restores Design. Ctrl/Cmd+K or Ctrl/Cmd+Shift+P opens a keyboard-navigable command palette for every workspace, view, bottom tool and layout action.

Hierarchy search filters names; expansion shows children. Reparenting uses Transform2D UUIDs and rejects cycles. Visible/locked/enabled are distinct. Scenes can be created, renamed, duplicated, loaded, unloaded, deleted and activated; runtime loads by UUID or name and retains persistent entities.

Editor/render layers and physics layers are separate. Collision requires mutual layer/mask permission; connections require the same editor layer. The sticky Inspector search and category chips filter metadata/components without disabling them. Add Component opens a searchable categorized picker. Transform2D is mandatory; unique components cannot duplicate. Component tools enable, copy, paste, reset and remove.

The Add UI area creates Canvas, Panel, Image, Text, Button, Slider, ProgressBar, Checkbox and TextInput. Parent Canvas, readable sizes and positions are automatic. UI renders/selects in Scene and Game; images have missing placeholders; Game text input supports IME, paste, multiline and passwords.

6. Physics

Persistent Rust PhysicsWorld uses a fixed timestep, so render refresh rate does not alter results. Dynamic bodies integrate forces/impulses; kinematic bodies follow velocity and transfer motion; static bodies stay fixed. Automatic mass is density × area and inertia is analytic. Damping is timestep-independent. Friction may exceed one; restitution threshold controls low-speed bounce.

Sensors report enter/stay/exit without impulses. One-way platforms block one side. Continuous mode uses adaptive substeps. Sleeping wakes on relevant changes. Raycast/all, overlap point/shape and shape casts honor masks. Rendering and collision geometry never imply each other.

7. Connections, joints and binding

Choose exactly two same-layer objects, Straight or Manual, then drag between center/surface/side/vertex anchors. Center markers are blue rings with white dots. Stretch, bend, stiffness, damping, maximum strain, bend/stretch load, thickness, density and collision are runtime values.

Straight lines repatch between moving/resized anchors. Manual paths deform as sampled rope. Ropes exclude the two attached bodies but may collide with others; impacts travel to anchors and bodies. Overload breaks the correct link and fragments continue. Overlapping objects can Bind into a compound with removed internal outline, shared drag, combined mass/inertia/collision; Separate reverses it.

8. Renderer and assets

The Rendering tool exposes five passes; Point/Spot/Directional/Area Light2D; masks, ambient and normal-mapped lighting; ShadowCaster2D; safe GLSL ES materials; camera stacks, viewports and render textures; optional effects; debug views; GPU/pass statistics; and PNG captures. Only a custom post material allocates the optional framebuffer; Canvas2D remains fallback.

Sprite and UI Image support nine-slice. Imports preserve atlas/filter, sRGB/Linear and platform compression variants. Assets use persistent asset://UUID references.

9. Input and scripting API

Input actions are Button, Axis or Vector2; bindings cover keyboard, mouse/button/wheel and gamepad button/axis with scale, vector contribution, pad index and deadzone.

Lifecycles: awake, start, fixed_update(dt), update(dt), late_update(dt), on_destroy, on_timer, collision enter/stay/exit and trigger enter/exit. Export with @export let speed = 5.0;.

Read: entity/name/find/has/get component, transform, rigid_body, animator, audio_source, time functions, input down/pressed/released/axis/vector, mouse/wheel. Commands: apply force/impulse; set velocity/position/rotation/scale/angular velocity; animator parameters/play; audio play/pause/stop; instantiate/destroy; scene load/reload/quit; timer start/pause/resume/cancel; Save APIs.

The Rhai sandbox has no filesystem, network, process, DOM, eval/import. Operation/call/depth limits stop runaway scripts; one error disables/logs that instance without crashing the engine.

10. Animation, audio, UI, tilemaps, particles and prefabs

AnimationClip has exact sprite-frame durations/property keys. AnimatorController has typed parameters, states and conditional transitions. Audio uses Master/Music/SFX/UI buses, sample rate, AudioListener and spatial blend/ranges. Canvas/RectTransform UI dispatches hover, press, click, slider drag, checkbox and native text; ProgressBar is display-only. TileMap palette paints/erases/picks/fills chunked tiles with None/Box/Polygon/OneWay collision. Particles use bounded deterministic pools.

Prefabs store entity subtrees, source UUIDs and instance overrides. Apply updates only non-overridden values; Revert clears overrides; missing sources stay diagnosable. Runtime instantiation waits for a safe structural phase.

11. Console, profiler and debugger

Console levels are Trace, Debug, Info, Warning, Error, Fatal with text, category and source filters. Categories include Engine, Runtime, Physics, Script, Asset, Build, Save and Plugin. Profiler tracks frame/physics/scripts/render/animation/audio/assets, FPS, bodies, draw calls and memory over 180 samples; Freeze/Clear control it. Physics overlays show colliders, AABBs, contacts, normals, joints, rope nodes and sleeping bodies without changing simulation. Crash logging records fatal failures where supported.

12. Save-game API

Save data is isolated by project UUID + slot and separate from project/scene files. Values: finite number, boolean, string, null, arrays and maps. Use save_has, save_get, save_set, save_delete, save_clear, save_load(slot), save_commit(slot). Settings can inspect/load/commit/clear. Limits: 1 MB, depth 8, 2,000 items per collection.

13. WASM Plugin API 1

Import manifest + matching WASM. Manifest requires reverse-domain ID, name, SemVer, API 1, engine range, safe entry, enabled and only log/events permissions. Required exports: nova_plugin_api_version() == 1, nova_plugin_init(); optional update/shutdown. No filesystem/process/network, maximum 16 MB. Invalid plugins are rejected; a trap disables it for that play session.

14. Build and export

Set game name, Windows/Linux/macOS/Web, x86_64, ordered scenes, startup scene, development build, output and optional Windows/Linux single executable. Default is Player + game.nova-pak; Build & Run starts native output. The pack uses a versioned header/index, safe relative paths, GUID/type, offsets, compressed/original lengths, gzip and SHA-256. Desktop targets build on matching OS; Web is static. Player contains no editor UI.

Animation Studio, rigging and Timeline

Clip assets open a dope sheet and curve editor with multi-target tracks, box/multi-selection, snapping, copy/paste and Auto/Linear/Constant/Free tangents. Record mode writes Inspector and gizmo transforms. Controllers provide conditions, exit time, interruption, weighted/additive layers, masks, subgraphs and 1D blend trees. Skeleton2D combines rig bones, pose overrides, IK, constraints and weighted inverse-bind skins. TimelinePlayer runs Animation, Audio, Camera, Event, Visibility and ScriptCall tracks at deterministic fixed ticks. Animation events use signals. Asset reimport maps and resamples a source clip while keeping the target GUID.

15. Worlds and gameplay tools

World Tools contains CharacterBody2D, Area2D effectors, optional Navigation and AI packages, WorldChunk2D streaming, portals and prefab object pools. Character motion uses exact Rust world units with slopes, steps, moving platforms, one-way surfaces and coyote helpers. Tilemap supports palettes, brush/terrain assets, layers and collision/navigation/occluder bake reports. See the English Markdown manual for every field and runtime signal.

16. Compatibility and release audit

Nova_A Project Format 2 uses schema 22 and supports legacy schema 5+. Files contain format/major/schema/engine/compatibility/project UUID. Schema 22 validates platform/delivery settings while preserving production, presentation, audio, world and unknown asset data. Ordered migrations preserve IDs, components, hierarchy, scenes, assets, prefabs, input/audio, tiles/particles/joints and build data. Newer unknown formats are rejected.

Audit: test every Presentation, World Tools and Production Lab tab; UI controls/focus/locales/mixer; replay/tests/data/jobs/networking; tile layers and bakes; save/reopen; Play/Pause/Step/Stop; game/headless builds; confirm unused optional resources/locales/networking are stripped.

16. Three complete tutorials

Physics playground

Create Physics Sandbox, tune body materials, run, inspect DistanceJoint/rope, enable physical rope collision and debug overlays, then overload it and observe simulated fragments.

Platformer

Inspect exported speed/jump, sprite, Animator assets and jump audio. Review MoveHorizontal/Jump, paint TileMap, adjust platforms/camera/HUD, play with A/D + Space, add a scene and export.

Top-down

WASD moves; E spawns the enemy prefab. Inspect patrol/particles. Enter Exit Trigger to commit checkpoint and load Main Menu. Load slot1, edit prefab while preserving overrides, then build both scenes.

17. Shortcuts and troubleshooting

Ctrl/Cmd+S save; Z undo; Shift+Z or Y redo; C/V/D copy/paste/duplicate; Delete remove; F2 rename; Escape cancel. Invisible: check enabled, scene/layer, camera, sorting, asset. No collision: check colliders, body types, physics layers/masks, sensor. Script: use Console source, action names, export types. Build: valid ordered/startup scenes and matching host OS. Never hand-edit a failed legacy schema; preserve original and report the migration error.

18. Script Studio 2.2

The Script workspace is a full-width Rhai IDE with project/source search, tabs, line gutter, breakpoints, find/replace, completion, signature and hover context, symbols, definitions, safe rename, diagnostics, modules, debugger, tests, signals and a generated Engine API. Valid saves hot-reload cached bytecode at a safe frame boundary; invalid edits keep the prior program. Read-only use modules reject missing/circular dependencies. Typed handles return valid/kind/id/error. Entity-owned tasks and the shared physics/UI/animation/scene signal queue are lifetime-safe. Release builds strip debug metadata unless Development Build is enabled.

19. Presentation: UI, Audio, localization and Accessibility

UI: Canvas/RectTransform/Panel apply anchors, fixed/fill/content policies, min/max, aspect, safe areas, responsive breakpoints, horizontal/vertical/grid containers, clipping, rounded masks, wheel scrolling and reusable UI prefabs. Theme assets inherit parents and variables, provide control states and allow style-class/per-control overrides.

Accessibility: Tab/arrows/D-pad navigate visible focus; explicit direction UUIDs override spatial lookup. Buttons can capture input remaps. Role, label and description export to the Game screen-reader tree. Runtime accessibility stays separate from editor preferences.

Localization: tables support locale fallback, plural/select maps, variables, number/date formatting, pseudo, font fallback, RTL and live preview. Builds retain only source plus selected locales.

Audio: the bounded graph has buses, parents, sends, mute/solo, wet/dry effects, meters, snapshots, ducking, spatial curves, streaming and voice limits. Assets expose waveform, loop markers and normalization; diagnostics split active/streaming/buffered/limited voices. Help opens this manual inside the same-origin editor overlay, never through the external opener.

20. Production Lab, tests, data and optional networking

Trace/Memory: bounded frame traces correlate input, scripts, animation, physics, audio, render, asset work, allocations and GPU passes. Capture/Compare, memory budgets, lifetime views and leak candidates are diagnostic and never delete project data.

Replay/Tests: Record stores normalized fixed-step input, seeded random state and physics checksums; Play restores the initial project and reports exact mismatches. Unit, Scene, Integration and Headless tests support assertions, tolerance, timeout, step limits, optional screenshots and JSON/JUnit output.

Data/Jobs: Data Schema/Table assets validate typed rows, import CSV/JSON/external database result arrays and generate TypeScript accessors. Versioned saves apply ordered migrations. Worker queues and fallback execution are bounded and cancellable.

Networking/Build: official WebSocket/native-UDP networking is uninstalled, disabled and stripped by default. Once installed it exposes lifecycle, RPC, replication, snapshots, interpolation, prediction/rollback, budgets and diagnostics. Authoritative headless mode requires native output plus enabled networking. WebGL multisampling, high-quality Canvas smoothing and font optical shaping improve anti-aliasing while Nearest pixel art stays crisp.

6. Physik

Persistente Rust-World, fester Timestep, FPS-unabhängig. Dynamisch integriert Kraft/Impuls; kinematisch folgt Geschwindigkeit; statisch bleibt. Masse=Dichte×Fläche, analytische Trägheit, timestepunabhängige Dämpfung, Reibung >1, Restitutionsschwelle. Sensor/One-Way/CCD/Sleep und maskierte Raycasts/Overlaps/Shape-Casts sind echte Runtime-Funktionen. Renderer und Collider sind getrennt.

7. Verbindungen und Bindung

Zwei Objekte derselben Ebene, Gerade/Manuell, Zentrum/Oberfläche/Seite/Vertex. Blau-weiße Anker. Dehnung, Biegung, Steifigkeit, Dämpfung, Belastung, Dicke, Dichte, Kollision wirken physikalisch. Seil schließt Endkörper aus, kollidiert optional mit anderen, leitet Impulse weiter und bricht in simulierende Fragmente. Bind erzeugt Compound ohne innere Kontur mit gemeinsamer Masse/Trägheit; Trennen kehrt um.

8. Renderer und Assets

Rendering zeigt fünf Passes, vier Light2D-Arten, Masken, Umgebung/Normal Maps, ShadowCaster2D, sichere GLSL-ES-Materialien, Kamera-Stapel/Viewports/Rendertexturen, optionale Effekte, Debugansichten, GPU-/Pass-Statistik und PNG-Aufnahmen. Nur ein User-Postmaterial reserviert den optionalen Framebuffer; Canvas2D bleibt Fallback. Sprite/UI unterstützen Nine-Slice; Importe speichern Atlas/Filter, sRGB/Linear und Plattformkompression.

Lesen: Entity/Komponente/Transform/RigidBody/Time/Input/Maus. Befehle: Force/Impulse/Transform, Animator, Audio, Instantiate/Destroy, Scene, Timer und Save. Sandbox ohne Datei/Netz/Prozess/DOM/Import; Limits stoppen Endlosskripte.

10. Animation, Audio, UI, Tiles, Partikel, Prefabs

6. 物理

持久 Rust 世界、固定时间步、结果与渲染 FPS 无关。动态体整合力／冲量；运动学体按速度移动；静态体固定。质量=密度×面积，解析惯量，时间步无关阻尼，摩擦可大于 1，恢复阈值抑制慢速弹跳。Sensor／单向平台／CCD／休眠以及带掩码的射线、重叠、形状投射都连接真实运行时。渲染与碰撞分离。

7. 连接与绑定

选择同层两个对象，直线／手绘，从中心／表面／边／顶点拖动，锚点为蓝环白点。拉伸、弯曲、刚度、阻尼、承重、粗细、密度、碰撞全部生效。绳索排除两端对象，可撞其他对象，冲量传到锚点；超载在正确链节断裂且碎段继续。绑定生成无内部边界、共同拖动、质量／惯量／碰撞合并的复合体；拆分可还原。

8. 渲染与资源

“渲染”工具显示五个通道、四类 Light2D、遮罩、环境光／法线贴图、ShadowCaster2D、安全 GLSL ES 材质、相机堆叠／视口／渲染纹理、可选后处理、调试视图、GPU／通道统计和 PNG 捕获。仅用户后处理材质分配可选帧缓冲；Canvas2D 保持后备。世界精灵／UI 支持九宫格，导入保存图集／过滤、sRGB／Linear 与平台压缩。

9. 输入与脚本

Button／Axis／Vector2 可绑定键盘、鼠标、滚轮、手柄并设置缩放、向量、序号、死区。生命周期：awake/start/fixed_update/update/late_update/destroy/timer、碰撞与触发器；用 `@export` 导出。

读取：实体／组件／变换／刚体／时间／输入／鼠标。命令：力／冲量／变换，Animator，Audio，生成／销毁，场景，Timer，Save。沙盒无文件／网络／进程／DOM／import；限制会终止死循环，单个错误不崩引擎。

10. 动画、音频、UI、瓦片、粒子、预制体

Clip 有精确帧／轨道；Controller 有状态／参数／转移。Audio 使用 Master/Music/SFX/UI、Listener 和空间属性。Canvas UI 处理悬停／按下／点击／Slider／Checkbox／Text；ProgressBar 只读。TileMap 绘制／擦除／拾取／填充分块，碰撞 None/Box/Polygon/OneWay。粒子池有上限且确定性。Prefab 保存子树、源 UUID、覆盖；应用尊重覆盖，运行时安全阶段实例化。

11. 调试

控制台 Trace 到 Fatal，支持类别／文字／源过滤；性能分析包含帧、物理、脚本、渲染、动画、音频、资源、FPS、刚体、Draw Call、内存，180 样本和 Freeze/Clear。物理层显示碰撞体、AABB、接触、法线、关节、绳节点、休眠体而不改模拟。崩溃日志不会让单个坏资源拖垮全部。

12. 游戏存档

按项目 UUID + Slot 隔离，支持有限数字、布尔、字符串、null、数组、Map。`save_has/get/set/delete/clear/load/commit`；设置页可预览。限制 1 MB、深度 8、集合 2,000 项。

13. WASM 插件

同时导入清单+WASM：反向域名 ID、SemVer、API 1、安全入口、仅 log/events。必须 `nova_plugin_api_version()==1` 和 init；可选 update/shutdown。无文件／进程／网络，最大 16 MB；trap 会停用本次运行中的插件。

14. 构建

20. Production Lab、测试、数据与可选联网

Trace／Memory：有界帧追踪关联输入至 GPU；预算、生命周期、Leak 与 Capture 比较不会删除数据。Replay／Tests：固定种子、输入与物理校验和可重放；四类测试支持断言、超时、截图与 JSON／JUnit。Data／Jobs：Schema／Table 校验 CSV／JSON／数据库结果并生成类型访问器；存档按序迁移；Worker／回退有界且可取消。Network／Build：联网默认剔除；安装后提供 WebSocket／UDP、RPC、复制、快照、插值、预测／回滚和诊断。Headless 要求原生目标和联网。多重采样、Canvas 平滑和字体光学整形改善抗锯齿。

21. Asset pipeline, packages, Plugin API 2, and Physics Monitor

Assets uses content-addressed background imports with progress/cancel, cache reuse, debounced reimport, last-valid fallback, type-specific previews/settings, dependency and reverse-dependency reports, reference/build explanations, and move/rename repair. Packages separates Installed, Project, Updates, Incompatible, and Disabled views; validates SemVer dependencies and lockfiles; and previews update/uninstall impact. Plugin API 2 declares capability-scoped editor/runtime contributions, hashes/signatures, WASM limits, per-project enablement, fault isolation, and Safe Mode; native extensions are never downloaded or run.

The right-side Physics Monitor opens during Play/Pause. Object Properties shows position, direction, speed, velocity, acceleration, force, energy, contacts, and sleep state. Collision Timeline shows collision point, before/after relative velocity, direction change, impulses and forces. Freeze, search, clear, collapse, and bounded history remain safe in long sessions.

Audit: every asset type; cancel/cache/failure fallback; dependency reports; package compatibility/update/uninstall; API 1/API 2/native plugin manifests; Safe Mode; Play/Pause/Step/Stop; moving bodies and collisions; all locales/themes/workspaces; save/reopen/build/player; Rust fmt/clippy/tests, Vue type-check, production build, audits, and browser smoke.

21. Asset-Pipeline, Pakete, Plugin API 2 und Physikmonitor

Assets verwendet inhaltsadressierte Hintergrundimporte mit Fortschritt/Abbruch, Cache, entprelltem Neuimport, letztem gültigen Artefakt, typspezifischen Vorschauen, Abhängigkeits- und Referenzberichten sowie Pfadreparatur. Pakete trennt Installiert, Projekt, Updates, Inkompatibel und Deaktiviert, prüft SemVer/Lockdatei und zeigt Update-/Deinstallationsauswirkungen. Plugin API 2 besitzt berechtigungsgebundene Beiträge, Hash/Signatur, WASM-Grenzen, Projektaktivierung, Fehlerisolation und Sicherheitsmodus; native Erweiterungen werden nie heruntergeladen oder ausgeführt.

Der Physikmonitor öffnet bei Play/Pause und zeigt Objektbewegung sowie einen begrenzten Kollisionsverlauf mit Punkt, relativer Geschwindigkeit vorher/nachher, Richtungsänderung, Impulsen und Kräften. Einfrieren, Suche, Leeren und Einklappen bleiben auch in langen Sitzungen begrenzt.

21. 资源管线、软件包、Plugin API 2 与物理监视器

资源面板使用内容寻址后台导入，提供进度／取消、缓存复用、防抖重导入、上次有效产物回退、专用预览与设置、依赖／反向依赖、引用／构建原因和移动／重命名修复。软件包按已安装、项目、可更新、不兼容和禁用分类，校验 SemVer 与锁定文件并预览更新／卸载影响。Plugin API 2 使用权限限定扩展点、哈希／签名、WASM 上限、项目级启用、故障隔离和安全模式；绝不会下载或执行原生扩展。
