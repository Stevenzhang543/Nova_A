# Nova_A 2D 游戏引擎与编辑器

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](./LICENSE.md)
[![Platforms](https://img.shields.io/badge/platform-Windows%20%7C%20macOS%20%7C%20Linux-lightgrey)](https://v2.tauri.app/start/prerequisites/)
[![Release](https://img.shields.io/badge/release-4.0.0-63c6ff)]()

Nova_A 是一款开源 2D 游戏引擎与桌面编辑器，使用 Rust、WebAssembly、Vue 3 与 Tauri 构建。

版本 **4.0.0** 是 Nova_A 的生产稳定二维基线：Project Format 2 模式 29、Runtime API 1、Plugin API 2、Package Manifest 1 与 Build CLI 1 已锁定，并在 4.0.x 补丁中保持兼容。完整的编辑器、物理、渲染、动画、音频、脚本、UI、世界数据、构建、软件包与协作功能均保留。

**手册：** [中英德三语交互网页](./manual/index.html) · [中文 Markdown](./manual/MANUAL.zh-CN.md) · [English](./manual/MANUAL.en.md) · [Deutsch](./manual/MANUAL.de.md)

- **升级助手：**所有外部项目打开前都会显示格式／引擎／内容／软件包预检。受支持的 3.x 升级必须完整备份并保留回滚数据，在内存中迁移、完整验证和规范化；失败时不会替换当前会话。模式 29 保持冻结。

- **生产文档：**三语完整手册连接 API、迁移、构建／CI、软件包、性能、安全、无障碍、故障排除、支持、许可证及小游戏创建／导出指南。
- **稳定默认值：**实验性联网继续作为可选软件包和参考工程提供，但不再属于默认项目模板。
- **最终验证：**v4 证据记录迁移、Tier-1／浏览器／布局／参考项目矩阵、软件包安全、异常输入、性能、无障碍、文档、SBOM／许可证、来源、发布健康、安装程序门槛与签字状态，绝不伪报未执行的外部门槛。

### 保留的 v3.3 创作基础

- **通用创建：** 按 Shift+A 或“创建对象”打开可搜索的 Core／2D／Physics／UI／Audio／Camera／Navigation／Script／Packages 面板，显示兼容性、依赖、收藏与最近使用；每次创建只产生一个撤销步骤。
- **完整视口编辑：** 移动、旋转、缩放、枢轴、矩形、路径、多边形、碰撞体与标尺工具，配合对齐／分布／镜像／旋转 90°／聚焦／隔离／分组、框选和七类吸附。
- **专业检查器：** 搜索、分类、多选混合值、重置、恢复预制体覆盖、复制／粘贴值、复制路径、关键帧、帮助、固定与仅显示修改项均已连接；组件支持启停、复制／粘贴、排序、重置和移除。
- **精灵与相机：** 支持枢轴、区域、翻转、调制、九宫格边框、排序与可见性；资源导入支持透明裁剪、精灵表切片、过滤／压缩／色彩／像素画预览；相机支持限制、缩放、平滑、拖动边距、跟随、预览与像素对齐。
- **高效层级：** 重命名、重复、重设父级、排序、分组和删除均可撤销。普通拖动保留世界变换，Alt 保留局部变换，Shift 调整顺序；面包屑、组件／标签搜索、状态标记和性能模式适用于大型场景。
- **发布证据：** 新增像素画、分辨率无关、视差、多相机、嵌套预制体和 5,000 对象六个参考工程，并记录创建／往返、检查器事务、像素对齐、视口性能与平台跳跃流程结果。

### 保留的 v2.9 发布与协作基础

- **清晰的发布工作区：**构建设置按“概览／平台／交付／团队”分页；校验结果与构建报告无需在一张超长表单中寻找。底部空间狭窄时自动切换成紧凑选择器。
- **平台交付：**Windows、Linux、macOS、Web 与条件启用的 Android 支持 Debug／Release、x86_64／aarch64、标识符、版本、图标、启动图、方向、权限及签名／公证指引。Android 仅在官方包、SDK、JDK 与本地模板齐备时可用。
- **可复现导出：**稳定项目文本、排序资源、确定性 `.nova-pak` 时间、SHA-256 构建记录、增量写入、缓存指标、补丁清单与 `pnpm export -- …` 无界面 CLI 便于 CI 审查。
- **运行与隐私：**结构化日志、崩溃记录和符号映射均为显式选项。遥测默认关闭，只允许有界标量事件，要求 HTTPS，并在启用前说明隐私约束。
- **团队协作：**UUID 状态标记、忽略规则生成器、有界原生 Diff／Merge、三方冲突检查、稳定 Scene／Prefab JSON 与到期锁文件支持安全审查。
- **软件包安全：**浏览页显示已验证发布者、权限、评分、文档与安全链接；浏览绝不执行软件包，安装必须显式触发，并支持离线／本地镜像。
- **安全升级与示例：**旧项目先预览 Schema／包影响，可下载完整备份；验证成功后才替换会话，并可下载回滚副本。空白、平台跳跃、俯视角、物理沙盒、UI 展示与可选联网模板均在创建时审计。

### 保留的 v2.8 Production Lab

- **Production Lab：**逐帧关联输入、脚本、动画、物理、音频、渲染、资源、分配与 GPU Pass；内存／生命周期快照保持有界并可比较。
- **确定性回归：**记录输入，以固定种子重放，比较物理校验和并导出 Replay 资源；Rhai 的 `random()`／`random_range()` 使用运行时种子。
- **自动测试：**Unit、Scene、Integration、Headless 测试支持断言、超时、可选截图和 JSON／JUnit CI 报告。
- **数据资源：**Schema／Table 资源校验类型字段、导入 CSV／JSON／数据库结果、生成 TypeScript 访问器，并迁移带版本的存档封装。
- **有界任务：**Worker 数、队列、取消与串行回退避免无 Worker 时阻塞或淹没界面线程。
- **可选联网：**安装官方软件包后可使用 WebSocket／原生 UDP、RPC、快照、插值、预测／回滚助手、复制预算与诊断；默认禁用且不会进入构建。
- **无头服务器：**原生构建可选择权威 Headless 模式；平台或联网软件包不满足时会在导出前阻止错误构建。
- **抗锯齿：**WebGL 多重采样、高质量 Canvas 插值、圆角线段连接和字体光学整形改善界面与游戏画面，同时保留显式最近邻像素画。

- 独立的“呈现”面板集中 UI、本地化、音频与运行时无障碍编辑，可从“界面”工作区和命令面板打开，避免继续堆叠对象检查器。
- Canvas／RectTransform／Panel 实际应用锚点、固定／填充／内容尺寸策略、安全区域、宽高比、响应式断点、水平／垂直／网格容器、裁剪、圆角遮罩、滚轮滚动视图和可复用 UI 预制体。
- `.nova-theme` 资源支持父主题继承、变量、普通／悬停／按下／禁用／聚焦状态、实时预览、样式类和控件级覆盖。
- 运行时 UI 支持可见键盘／手柄焦点、显式或空间导航、屏幕阅读器元数据以及输入重映射控件；运行时无障碍与编辑器偏好保持分离。
- 本地化表支持源／预览语言、回退链、复数／选择规则、变量、数字／日期格式、伪本地化、字体回退、RTL、实时预览和按构建语言裁剪。
- 音频图支持自定义总线、父级路由、Send、静音／独奏、带干湿比的效果、表头、快照、闪避、空间衰减曲线、流式覆盖和有界总／分总线声部。
- 音频资源新增解码波形预览、循环标记、峰值标准化、流式选择以及活动／流式／缓冲／受限声部诊断。
- 内置手册改为同源应用内覆盖层，不再让 Tauri 打开 `http://tauri.localhost/manual/index.html`，从而修复用户报告的致命 URL 权限错误。
- 每次发布包含 Web、源码、便携 EXE、MSI、NSIS、发布说明、许可证和 SHA-256 校验文件。

### 保留的 v2.6 世界与玩法基础

- CharacterBody2D 支持斜坡、台阶、地面／墙壁／天花板状态、地面吸附、移动平台速度、单向平台、土狼时间辅助和 Rhai 精确单位移动。
- Area2D 的重力、风、阻力和浮力只在权威 Rust 固定步中累加一次；伤害和自定义信号使用有界运行时事件队列。
- 导航区域／代理支持有界网格、多边形、障碍、A*／流场、局部避障、平滑、动态重烘焙和场景调试叠加层；导航与行为工具仍是独立延迟加载的软件包。
- 行为树和分层状态机资源连接运行时信号，不会进入纯物理项目。
- 图块地图新增调色板、笔刷／地形资源、图层、流式控制以及碰撞／导航／遮挡体烘焙诊断。
- 世界分块按优先级和内存预算异步流式加载场景，支持大坐标原点移动与运行时传送门。
- 对象池预热有界预制体实例，并发送生成／回收生命周期信号；平台跳跃模板已演示 CharacterBody2D。
- 独立“世界工具”底部面板集中角色、区域、导航、AI、流式加载和对象池编辑，避免对象检查器继续堆叠。

### 保留的 v2.5 资源与软件包基础

- 内容寻址导入会哈希源文件字节、导入器版本、平台和规范化设置；相同输入直接复用缓存产物。
- 导入使用有上限的后台队列，并显示进度和取消操作；文件监视经过防抖，缓存先暂存再提交，重导入失败时继续使用上次有效产物。
- 资源工具提供依赖／反向依赖查询、引用和构建包含原因、未使用报告、缺失引用报告，以及移动／重命名时的路径修复。
- 导入器为图片、图集、字体、音频、图块数据、脚本、着色器、动画和本地化数据提供专用设置与预览。
- 软件包管理器支持本地／Git／注册表清单、语义版本兼容、锁定文件、离线清单缓存、更新预览、禁用／不兼容视图与卸载影响检查。
- Plugin API 2 新增编辑器／运行时扩展点、项目级启用、能力权限、SHA-256／签名校验、WASM 内存与调用时间上限、故障隔离和安全模式；原生扩展绝不会被自动下载或执行。
- Play／Pause 时会滑出物理监视器，显示位置、方向、速度、加速度、力、动能和接触数；碰撞时间线显示冲击力、冲量、碰撞点和碰撞前后相对运动，并保持有界。
- ResizeObserver 的平台通知不再作为致命错误；尺寸变化合并到每个动画帧一次，修复用户报告的渲染误报崩溃。
- Project Format 2 Schema 18 校验软件包状态和 Plugin API 1／2 清单，并完整保留 2.4 动画资源。
### 保留的 v2.3 渲染基础

- 底部“渲染”工具可编辑环境光、阴影质量、颜色空间、调试视图、后处理、用户后处理材质、安全着色器和实时预览。
- 点光、聚光、方向光和区域光遵守渲染层／遮罩；ShadowCaster2D 支持硬／柔和／超高质量，SpriteRenderer2D 法线贴图会改变光照响应。
- 材质保存经校验的着色器、纹理、有限统一变量、混合、采样、颜色空间和颜色写入状态。无效着色器安全回退，不会中断帧。
- 多 Camera2D 支持优先级／堆叠、归一化视口、剔除遮罩、像素完美定位和命名渲染纹理捕获。
- 颜色调整、暗角、泛光、模糊和自定义材质通道均为可选；世界精灵和 UI 图片均支持九宫格。
- 图片导入支持 sRGB／线性元数据和平台压缩变体，同时保留图集、采样和精灵区域设置。
- 渲染诊断显示通道耗时、Draw Call、三角形、纹理、过度绘制、渲染目标及受支持时的 GPU 时间，并可下载 PNG 帧捕获。
- 场景工具栏进入正常文档流，不再覆盖工作区栏和 Canvas 标签；完整清理覆盖层与切换场景时重置选择，消除随机白色控制点残影。

### 保留的 v2.2 脚本基础

- 脚本现为全宽专用工作区，不再挤在资源导入器的狭小文本框中。
- `use "…"` 项目模块具有缺失/循环依赖诊断；包依赖为只读元数据。
- Entity、Component、Animator 与 AudioSource 句柄统一返回 `valid`、`kind`、`id` 和 `error`。
- 自定义、脚本、物理、UI、动画与场景生命周期信号共享安全事件队列。
- `task_wait` / `on_task` 任务跟随对象和场景生命周期自动取消。
- 开发运行支持断点、继续/单步、调用栈、局部变量和安全监视；非开发发布包会移除调试元数据。

## 引擎工作区

```text
Vue 编辑器
  └─ nova_wasm        唯一 WebAssembly 边界
       ├─ nova_runtime  固定时间、事件、诊断、运行时骨架
       │    └─ nova_physics  刚体、碰撞、求解器、绳、持久化世界
       │         └─ nova_math  向量、变换、AABB、射线、矩形
       ├─ nova_script   沙箱化 Rhai 游戏脚本执行
       └─ nova_format   版本化格式、验证与迁移
```

物理、数学、运行时、脚本和格式 crate 不导入 Vue、DOM、JavaScript 或 Tauri。内部 crate 采用静态链接，因此桌面发布仍是一个完整应用，不需要 Nova_A DLL 插件。

## 物理属性绑定情况

配置变化会通过 Vue → `nova_wasm` 以明确的持久化世界命令传入。固定物理步保留在 Rust 内；复用的 Float64 状态缓冲区把运行时变换和绳状态返回渲染器，不进行隐藏单位换算，也不会为每个刚体创建 JavaScript 返回对象。一个配置世界单位严格等于一米；相机缩放只负责将世界坐标转换为像素。

## 项目兼容性

- 新存档使用 **Nova_A Project Format 2**、Schema 29 与引擎版本 `4.0.0`。
- 持久化场景、对象、组件和连接使用 UUID；运行时句柄绝不会写入磁盘。
- 格式迁移与验证集中在 `nova_format`，不会散落在各个编辑器组件中。
- v1.9 格式 13、v1.8 格式 12、v1.7 格式 11、v1.6 格式 10、v1.5 格式 9、v1.4 格式 8、v1.3 格式 7、v1.2 格式 6、v1.1.2 格式 5、更早的对象根节点和旧顶层实体数组仍能加载；只有用户再次保存时才会写成 Format 2。

| 属性 | 求解器/渲染行为 |
| --- | --- |
| 位置、旋转、尺寸 | 直接用于世界变换、碰撞几何、锚点和渲染。 |
| 线速度、角速度 | 每个子步积分并回传渲染器。 |
| 加速度 | 直接加入动态刚体的线加速度。 |
| 密度与质量 | 密度 × 精确形状面积得到质量；编辑质量会同步更新密度。 |
| 自动/手动转动惯量 | 默认使用精确椭圆或凸多边形公式；关闭自动计算后严格使用手动值。 |
| 全局/局部重力与重力倍率 | 每个动态刚体子步都会组合并应用。 |
| 力与扭矩 | 遵循 `F = ma` 与 `τ = Iα`；偏心冲量也会产生角冲量。 |
| 线性/角/空气阻尼 | 每个稳定子步执行指数衰减。 |
| 静态/运动学刚体 | 静态刚体保持固定；运动学刚体只积分配置速度，不受动态力影响。 |
| 恢复系数与阈值 | 只有闭合速度超过阈值时才产生反弹。 |
| 静摩擦/动摩擦 | 顺序冲量先尝试静摩擦，再限制为动摩擦。 |
| 传感器 | 刚体之间会报告重叠诊断但不施加碰撞冲量；物理绳会穿过仅传感器对象。 |
| 渲染排序层/顺序 | 只控制绘制顺序，绝不会改变碰撞行为。 |
| 物理层/掩码/矩阵 | 仅当双方碰撞掩码与项目碰撞矩阵都允许该层组合时才求解接触；零掩码会明确禁用全部接触。 |
| 碰撞器偏移/旋转/形状 | 碰撞几何与渲染几何独立，使用自己的局部变换、材质、传感器状态和形状。 |
| 离散／连续碰撞、休眠、锁定旋转 | 默认 Discrete 刚体使用固定步进；可按对象启用 Continuous 自适应防穿透子步。静止刚体无需接触即可休眠，并会在受力、冲量、碰撞、关节牵引或编辑变换时唤醒；锁定刚体拒绝扭矩和角冲量。 |
| 绳路径与锚点 | 直线和归一化手绘路径会在编辑变换后重新拼接；中心/表面/顶点/边上点锚点跟随当前几何。旧版自动曲线记录仍可读取。 |
| 绳的伸长、弯曲、刚度、阻尼 | 作用于两端约束或每个物理绳分段；每段常数按节点数缩放，因此改变采样数不会改变整条绳的配置刚度或阻尼。 |
| 绳半径、线密度、碰撞 | 半径控制连续线段碰撞和渲染直径；线密度控制精确总质量；排除源对象，并向同图层第三方对象传递大小相等、方向相反的冲量与摩擦。 |
| 绳断裂承重 | 配置的等效质量会使用标准重力与实际伸长/弯曲力比较；过载线段断开后，两段残绳继续模拟。 |
| 绑定 / FixedJoint2D | 使用合并质量和平行轴转动惯量生成同一个组合体运动状态；移除内部重叠边线与接触，外部冲量会带动整个组合体。 |
| TileMap 与 TileSet | 图集区域按格子坐标解析；可见块提交渲染批次，连续静态碰撞格被合并，并在编辑后只重建受影响块。 |
| 物理查询 | 射线、重叠与形状投射使用实际椭圆／凸多边形窄相检测、图层掩码和稳定场景 UUID；TileMap 内部合并碰撞体会去重为所属对象。 |
| 2D 关节 | Fixed、Distance、Revolute、Prismatic 和 Spring 约束在每个物理子步求解；锚点、轴、限位、刚度、阻尼和连接对象碰撞开关均传入 Rust。 |
| 粒子发射器 | 发射、寿命、运动与颜色曲线在固定运行时步长更新；图像粒子进入精灵批次，无纹理粒子使用椭圆绘制，且从不创建物理碰撞体。 |
| 颜色、纹理、透明度 | 仅影响渲染，不改变质量或碰撞几何。 |

## 数值范围

Nova_A 在前端、WASM 和后端完整路径中使用 64 位浮点数。非有限输入会被规范化。一般物理量限制为 ±`1e50`；正的几何尺寸、质量与密度下限为 `1e-6`。

多边形碰撞几何必须保持凸形。求解器至少使用 8 个自适应子步，高速运动时最多 128 个，并在每个子步进行 20 次顺序冲量迭代。这些措施可减少穿透和不稳定，但 Nova_A 仍是离散实时求解器，不是符号或无限精度物理系统。
