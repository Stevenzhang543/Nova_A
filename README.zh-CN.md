# Nova_A 物理与渲染引擎

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](./LICENSE.md)
[![Platforms](https://img.shields.io/badge/platform-Windows11-lightgrey)]()
[![Release](https://img.shields.io/badge/release-0.12.0-6ea8fe)]()


> **Nova_A 是一个完全开源的 2D 物理引擎、渲染器和 GUI 编辑器项目，使用 Rust + Vue 3 从零构建。**  
> 版本：**0.12.0** — 现代化编辑器、多语言工作流与物理连接系统。

# v0.12.0 更新内容

* 新增自适应深色／浅色主题、现代分层控件、响应动画，以及紧凑、高对比度、减少动态效果和渲染质量设置。
* 编辑器界面完整支持英语、德语和简体中文。
* 新增多对象物理绳索／连接：支持表面、顶点、边上点或中心锚点，直线、曲线和手绘路径，弹性／刚性、阻尼及弯曲／拉伸超载断裂。
* 新增本地自动保存、网格吸附、缩放灵敏度、新对象默认值和删除确认。
* 项目格式升级为 v2，可保存连接数据，并兼容旧版仅含对象的场景文件。


## 构建要求

  要构建并运行此项目，请确保已安装以下环境：
* **Node.js**：`v18.0.0` 或更高（`.node-version` 记录为 `22.22.2`）
* **pnpm**：`v9.0.0` 或更高（`package.json` 记录为 `10.30.0`）
* **Rust/Cargo**：当前稳定版工具链和 `wasm32-unknown-unknown` 目标（记录在 `rust-toolchain.toml`）
* **wasm-pack**：`0.14.0` 或更高（需单独安装，并不随 Cargo 自动提供）
* **Windows 桌面构建**：Microsoft C++ Build Tools 和 WebView2

## 构建指南

### 1. 初始化（安装依赖）
  在首次运行引擎之前，你需要安装所有所需的 node 模块。进入 `Nova_A` 根目录并运行：

```powershell
corepack enable
corepack prepare pnpm@10.30.0 --activate
pnpm install --frozen-lockfile
cargo install wasm-pack --version 0.14.0 --locked
```

如果已经安装 `wasm-pack`，可以跳过对应的安装命令。

### 2. 开发构建（本地服务器）
  启动一个带有热模块替换（HMR）的本地开发服务器，以便快速迭代测试：

```powershell
pnpm tauri dev
```

开发命令会先从 Rust 源码重新生成 `nova_core/pkg`，避免浏览器误用旧的 WASM 构建。
（使用 Vite 时通常会在 http://localhost:1420 启动编辑器。）

### 3. 生产发布（构建）
  为生产部署编译、打包并压缩应用：

```powershell
pnpm tauri build
```

生产命令会重新构建发布版 WASM、检查 Vue/TypeScript 类型，然后打包前端和 Tauri 应用。
（这将生成一个 `dist/` 文件夹，其中包含静态 HTML、CSS 和优化后的 JS 资源。）

### 4. 验证

```powershell
pnpm test:core
pnpm check
pnpm build
```

## 物理属性

### TRANSFORM（变换）

  **Position（位置）**
    物体在屏幕上的位置。就像把一个玩具放在桌子上——你决定它左右（x）和上下（y）的位置。范围：无限*。
  **Rotation（旋转）**
    物体旋转的角度。就像在桌面上旋转一本书。0° 表示正常，90° 表示侧放。范围：-180 到 180 度。

### MOTION（运动）

  **Linear Velocity（线速度）**
    物体移动的速度和方向。就像扔一个球——它会向前移动，可能还会向上。范围：无限*。
  **Angular Velocity（角速度）**
    物体旋转的速度。就像旋转的硬币。正值表示一个方向，负值表示相反方向。范围：无限*。
  **Linear Damping（线性阻尼）**
    随时间减慢运动，就像空气阻力。值越高，物体停止得越快。范围：0 到 1。
  **Angular Damping（角阻尼）**
    随时间减慢旋转，就像轮子的摩擦。范围：0 到 1。

### MASS & PHYSICAL BEHAVIOR（质量与物理行为）

  **Mass（质量）**
    物体的重量。越重的物体越难推动。就像羽毛和石头的对比。范围：0.1 到 100。
  **Moment of Inertia（转动惯量）**
    物体旋转的难易程度。长棍比小球更难旋转。自动计算。
  **Gravity Scale（重力系数）**
    控制重力对物体的影响程度。1 表示正常重力，0 表示漂浮，2 表示下落更快。范围：0 到 5。

### FORCES（力）

  **Force（力）**
    施加在物体上的推力。就像推动一个箱子——更大的力会让它移动得更快。范围：无限*（x 和 y）。
  **Torque（扭矩）**
    使物体旋转的扭转力。就像在门的边缘推门。范围：无限*。

### SHAPE & SIZE（形状与大小）

  **Size / Radius（尺寸 / 半径）**
    物体的大小。更大的物体更容易发生碰撞并占据更多空间。范围：无限*。

### MATERIAL（材质）

  **Restitution（弹性）**
    物体的弹性程度。0 表示没有弹性（像粘土），1 表示非常有弹性（像橡胶球）。范围：0 到 1。
  **Static Friction（静摩擦）**
    接触其他表面时开始移动的难易程度。就像推动一个不容易动的重箱子。范围：0 到 1。
  **Dynamic Friction（动摩擦）**
    物体在已经移动时抵抗滑动的程度。就像在冰面和砂纸上滑动的区别。范围：0 到 1。

### COLLISION STATE（碰撞状态）

  **Is Static（是否静态）**
    如果开启，物体将完全无法移动。就像墙或地面。
  **Is Kinematic（是否运动学）**
    物体仅在你控制时移动，而不是由物理驱动。就像游戏中的移动平台。

## RENDERING（渲染）

  **Color (RGB)（颜色）**
    使用红、绿、蓝值表示物体的颜色。就像混合颜料。每个值控制该颜色的强度。范围：每个通道（R, G, B）为 0 到 255。
  **Transparency (Alpha)（透明度）**
    物体的透明程度。0 表示完全不可见，1 表示完全不透明。范围：0 到 100。
