## Consequences and risk controls

- Window mutation now needs four explicit Tauri capabilities; the allowlist is limited to the main window and only the operations used by F11/recovery.
- Autosaves consume bounded local storage (maximum 12 snapshots and 12 MB) and may discard oldest snapshots, never the manual file.
- Read-only recovery disables pointer mutation in Inspector/viewport and all edit commands check editing/read-only state.
- Custom layout import validates format/version, bounds names/counts/sizes, and falls back to safe presets.
- Optional tools remain available for existing projects so hiding discovery cannot orphan data.
- Task history is bounded to 100 entries; diagnostics omit callback functions.
