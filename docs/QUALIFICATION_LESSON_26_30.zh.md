## 26.30 — 完整创作与发布验收

Engine: **26.30.0** · 项目格式2/schema29。先复制项目并保留迁移备份。运行 Project Health，修正失效引用，保存并重新打开；不要覆盖唯一旧版副本。

从 Library 创建模板，找到主场景和入口脚本，修改一个可见属性。预览、停止、撤销、重做、保存、重开，确认创作值一致。导出 Web 游戏并单独检查下载的播放器。对实际准备发布的每个模板重复这些步骤；模板出现在列表不等于演练通过。

编写含变量、条件和循环的小函数，切换 Visual 检查连接和嵌套，修改受支持值，再切回 Code 比较行为。不支持的源码必须保留并给出诊断。项目 use 模块共享程序命名空间，不等于原生别名导入。故意制造语法错误，确认最后有效程序仍运行；修复后重载，再重新打开已保存脚本。持久结构变更可能要求重启，预览状态不等于创作数据。

动画菜单应修改绑定/关键帧，跳转和播放，检查嵌套片段及结束姿态后导出。试听静音/独奏只属于会话，创作混音器更改才写入项目。流式世界应卸载/加载单元并替换导航目标：目标缺失立即停止，单元恢复不得修改其他单元。多人游戏授权后连接两个客户端，检查所有权、断线重连，并运行真实下载播放器。变换差量快照不是完整确定性回滚。

每个工作区都使用长路径、有内容列表、窄/宽窗口、大文字、中英德语言、键盘焦点和鼠标菜单检查。取消操作应保留创作数据。高对比与低端模式可选，默认动画和已有特效保留。记录待机时长、设备和帧采样，不宣称任意机器最高FPS或永不泄漏。

将 Web ZIP 内容部署到 HTTP(S) 根目录或子路径，保持相对资源路径和正确 WASM MIME。本地编辑无需应用后端，可选认证/中继需要兼容服务。安装/添加主屏幕是在线快捷方式：没有Service Worker，不支持离线重新加载。桌面版仍需规定的系统运行库。原生物理JSONL工具只执行有限物理请求，不运行项目/Rhai游戏或多人服务器。其他系统、设备和独立无障碍观察需要真实环境验收。

阅读26.30功能、面板、对比与问题关闭清单，区分声明路径与执行证据。故障时恢复迁移备份、使用 Recovery Browser、停用问题包、查看Console/Build诊断并保留最后有效输出。发布通过取决于冻结源码报告和校验和；未执行、无法提供环境的项目不能标记通过。
