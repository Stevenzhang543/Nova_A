# Nova_A 26.30 / 26.30.0

This release closes the 26.21–26.30 plan with refreshed source, feature, edit-route and panel inventories; explicit issue dispositions and platform/service boundaries; current English, German and Chinese lessons; and a bounded final qualification plan.

Existing functionality and animations are retained. Reachable-panel navigation, pending edits, keyboard/touch focus and representative layouts are checked against the actual build. Static inventories include conditional panels but do not imply every state was executed. See UI_26_30.md and ISSUE_CLOSURE_26_30.md for the exact scope and remaining constraints.

Release qualification requires current Windows/WASM/Web builds, native tests, focused world/network/native-service regressions, actual downloaded delivery, clean and moved checkout builds, template packaging output, short measured idle/resume and fresh npm advisory results. The final qualification bundle records success or failure; planned checks here are not evidence of completion.

The Web ZIP can be served at a website root or subdirectory without a mandatory application backend for local authoring. It remains online-only with no service-worker offline reload. Optional multiplayer services need their own configured endpoints. Native physics JSONL tooling is deliberately narrower than a full scripted game server.

The eleven-artifact release contract and prior releases are preserved. Linux/macOS binaries, physical mobile qualification, independent testing, signing, multi-hour stability and universal performance claims are not inferred from this Windows run. Project Format 2/schema29 is unchanged. Full path-level changes are recorded in EDIT_LEDGER_26_30.md.
