# Nova_A 3.9 platform support

| Platform | Tier | Scope |
|---|---|---|
| Windows x86-64 | Tier 1 | Editor, runtime, MSI, setup and portable |
| Web runtime | Tier 1 | Chromium, Firefox and WebKit reference matrix |
| Linux x86-64 | Experimental | Promotion waits for clean-machine driver/audio/input/export evidence |
| macOS x86-64/arm64 | Experimental | Promotion waits for hardware, signing, notarization and regression capacity |
| Android/mobile/console | Unsupported | Deferred until after 4.0 |

The editor displays this matrix directly. A platform cannot be promoted merely by changing a label; the reference and clean-machine evidence must pass.
