X/Y 读数通过导出属性 readout_elapsed 保存计时状态。普通 Rhai 局部变量在每次回调时重新初始化；跨回调状态应使用导出属性。

## 明确单位与运动控制权

在 Design 选择实体，展开物理检查器并调整宽度。World Studio 提供更大的角色、区域、导航、AI、流送、模拟表单。展开“物理与世界状态”，观察只读刚体数量、配置重建次数、寻路耗时、流送估算和原点偏移。内部使用米、秒、千克、牛顿和弧度。主检查器角度显示为度，子碰撞体旋转为弧度；速度为 m/s，角速度 rad/s，面密度 kg/m²，转动惯量 kg·m²。正的全局重力设置使物体沿世界负 Y 方向下落。

Dynamic 接受力积分，Kinematic 由运动指令驱动，Static 用于固定场景。Animation 控制的变换按运动学处理，同时保留以后切回 Physics 时使用的编辑速度。自动质量使用启用的碰撞几何、有符号父级／世界缩放和有效材质密度；手动质量使用输入值。自动／手动惯量是独立选择。关联材质提供运行时系数，不会覆盖内联编辑值；用户在检查器明确应用材质仍属于编辑操作。

物体运行后再修改尺寸、偏移、角度、密度、摩擦、弹性、反弹速度阈值、阻尼、重力、力与扭矩。暂停区分编辑值和接触／休眠观测。继续运行后，下次原生同步必须应用修改，同时保留无关刚体的句柄和速度。测试撤销／重做、Stop、保存与重开。世界与设置表单中的无效数值应恢复上一有效值并显示错误。

## 平台游戏与接触

Player 使用 CharacterBody2D。明确设置地面吸附、安全边距、台阶高度、滑动次数、坡度上限、土狼时间和平台速度继承。A/D 移动，Space 跳跃；Play、Pause、Step 每个固定步只能执行一次角色运动。测试低台阶、单向 Platform 与 Moving Platform。演示移动平台持续前进，请在20秒内检查，或自行添加往返控制器后长时间游玩。

修改平台摩擦和掩码，测试从上方落地、从下方穿越。物理层编号0–31，导航层1–32；渲染层不筛选物理查询。复合子碰撞体具有独立传感器、层、掩码和单向设置。子圆／椭圆以完整宽高为准，旧 radius 字段仅作兼容元数据。凹形／Chain 的动态限制与 WorldBoundary 的静态限制需要先修正再运行。

角色查询使用包含实体偏移、子形状偏移和旋转的保守包围形状，复合角色中的空隙会被包住，不是精确凹形角色扫掠。上台阶必须先通过顶部净空检测。静止角色刷新地面，已移除的平台不能继续传递旧速度。CCD 比离散检测需要更多计算。使用实际固定频率、子步与求解迭代配置，检查高速穿透、堆叠和休眠。

## 约束谜题与连接身份

选择 Jointed Box，修改距离和两端局部锚点。关节类型决定轴、线性／角度限制、电机速度和最大力如何生效。正的断裂力／扭矩启用阈值，旧值0表示无限。组件关节断裂后保持断裂，直到禁用再启用、删除或重置运行会话。首次 Play 不再覆盖明确编辑的距离；参考偏移／角度只初始化一次。

从 Connections 打开已有绳索，会直接进入保存路径对应的物理设置。编辑半径（米）、线密度（kg/m）、刚度、阻尼、拉伸／弯曲参数和点数。旧“绳索分段”标签实际选择3–32个模拟点。保存明确重建绳索并重置断裂状态，但保留 UUID、启用标记和隐藏关节设置。取消仅丢弃草稿。测试超限点数恢复、取消、重新编辑、保存、撤销／重做与重开。布料示例是实体与连接组成的网格，不具备织物求解器或布料自碰撞。

## 导航烘焙与 AI

World Navigation 可选择 Manual、SceneGeometry 或 TileMap。Manual 定义边界；SceneGeometry 捕获符合条件的碰撞体；TileMap 捕获格子内容、变换、掩码和资源字节，始终使用网格。设置正的单元尺寸和角色净空半径；更大的净空可能关闭窄通道。网格 AStar、带回退的 HierarchicalAStar、FlowField 共用带权连接和成本区域；Polygon 使用独立的可见性路径搜索与连续净空检测。有向连接可以串联多个不连通岛，FlowField 每个网格缓存四个目标。

烘焙只发布完整且仍与源一致的结果。大任务运行时可以取消；进度条出现会移动按钮，请点击当前可见的取消。取消的工作不会自动重启，修正源后重新烘焙。碰撞体／障碍物、缩放、净空、成本、连接、Tile 内容和资源字节改变会使旧路径失效。旧路径代理在拿到新路径前停止。保存的 bakedRevision 只是失效标记，不是可移植的烘焙产物。

导航参考中 WASD 移动 Player，Navigator 绕过障碍追踪它。检查目标 UUID、速度、加速度、半径、停止距离、重新寻路间隔和避障范围／优先级／邻居上限。加速度0保留当前速度，静态障碍不提供预测运动。启用 Navigation 与 AI 包。行为资源含感知与 Wait，检查标签、距离、视野、结果上限和黑板键。覆盖值在源或覆盖修改后初始化，后续运行时黑板写入跨帧保留。延期代理只消费一次对应信号代次。缺失资源／包和预算超限应明确修复。

## 实际流送与原点平移

检查 Stream Cell 的场景、依赖、加载／卸载／预取距离、优先级、缓存策略、所有权、保存键和内存估算。Prefetch 仅准备独立数据，Active 才安装实际实体和可查询刚体，层级应出现 Streamed Landmark。多个所有者共享场景时，最后一个活动所有者释放才移除成员。编辑时禁用的子物体保持禁用；持久实体、后代和内部连接保留稳定 UUID。

取消待处理流送并确认不会自动重试。修复缺失依赖、循环、源变更或预算后点击 Retry。MiB 值是准入估算，不是测量到的堆内存。传送门预取失败时修复源，并关闭／重新打开预取。目标门户 UUID／名称在场景提交后解析，到达速度归零并避免立即弹回。找不到目标会显示明确错误。

在 Play 中暂停，选择 Player，使用“将原点移至选中实体”。相对几何、原生句柄、速度、休眠／接触、绳索点、导航目标及缓存／流送坐标必须一致。绝对位置等于当前世界位置加原点偏移。Stop 恢复编辑场景；多次平移与重载不能复制持久 UUID，也不能让同一绳索平移两次。

## 保存、导出与资格检查

保存编辑项目，通过 Open Project 重开并重复操作。使用 Build 导出完整 Web ZIP，解压后通过 HTTP 运行。比较公开的 X/Y 坐标文本与暂停检查器。审计独立比较全部场景／实体／组件／连接值和包／文件哈希，再用全新浏览器进程运行下载文件。组合在同一浏览器中的导出与跳转曾出现本机超时，这些尝试仍保留失败记录，独立播放器结果分别报告。

在目标设备上测量 Profiler。位置迭代现在真正独立于速度迭代执行位置修正，旧性能假设需要重新测试。查询、导航缓存、AI 求值／跟踪、流送成员与存档交接均有明确资源边界，超限报错而不是悄悄返回部分结果。原生／WASM 的解析、力学、模糊测试、回放和清理属于程序验证；真实鼠标／键盘、布局、保存和导出游玩属于独立用户验证。软件渲染、有限本地持续运行和指定负载不能证明所有设备的最高性能、真实辅助技术、发行签名或所有使用情形。
