# Nova_A 26.26 — 资源生产与面板可读性

Engine 26.26.0 · Project Format 2/schema 29。保留全部 40 个模板、现有动画和功能；旧版发布文件独立保留。发布资格以冻结源码、实际执行日志及发布目录 SHA256SUMS.txt 为准。

## 资源和导出
- 导入批次先准备后提交，失败或取消不会留下半批资源。重导入保持 UUID、作者设置和引用；过期任务不能覆盖更新结果。
- 更新图片、图集、字体与音频时清理过期派生资源；同 UUID 的音频替换释放旧播放源。播放期间资源编辑应保留到停止后，并可撤销。
- 重开项目按已保存路径恢复资源，避免同名字体或其他资源在重新载入时交换路径。
- 为浏览器拒绝直接解码的有效 SVG 增加有尺寸、超时和清理约束的备用解码。命令行导出正确解码百分号编码 data URL，避免导出损坏的 SVG。
- 依赖遍历限制实际访问数量；包提交后的观察者异常不能把成功事务显示为失败，升级回滚基线仅在验证成功后保存。

## 界面
- Assets 支持键盘选择、完整路径、列表与网格，以及所有宽度下的整页详情和返回操作。资源配置避免嵌套滚动陷阱。
- 导入错误以英、德、中三语给出可执行建议；原始技术详情独立折叠。生产配置名称本地化，技术标识保持稳定。
- Physics、World、场景导航与协作面板修正窄列、状态换行和键盘操作；场景关闭按钮不再嵌套在切换按钮中。
- 全部 Vue 面板和条件状态记录于 PANEL_INVENTORY_26_26.md；静态检查与实际操作证据分别标明，不把源代码扫描视为所有状态已实际执行。

## 验证与边界
针对本版改变执行资源事务、取消/竞争、撤销/保存/重开/导出、包生命周期、音频边界、实际面板操作和全部 40 个模板的启动与导出检查。导出检查核对归档资源 UUID 和字节，并使用实际原生播放器打包。保留构建、类型、WASM、历史兼容、Windows 启动、无窗口输出、归档校验和三语手册检查。

大型库测量覆盖有界依赖遍历的耗时与 Node 堆变化，不能推导渲染 FPS 或长期无泄漏。按用户要求不重复无关全矩阵和依赖认证。Windows 本机/Edge 的证据不能替代 Linux/macOS、Firefox/WebKit、真实手机、签名清洁安装、原生辅助技术或长期运行测试；在线库发布服务亦不作认证。

Web 压缩包可整包部署至静态网站子目录，参见 WEB_HOSTING_26_26.md。三语手册保留已有教程并加入本版资源工作流。逐文件编辑记录见 EDIT_LEDGER_26_26.md。
