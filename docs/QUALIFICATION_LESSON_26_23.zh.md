# Nova_A 26.23 操作课程

## 启动与草稿

点击“新建”后显示项目名称、位置和全部四十个模板。取消或 Escape 会恢复焦点并保留创建草稿。“打开”和“继续”仍直接可用；“更多”显示导入、迁移和恢复。取消的草稿不等于已保存的项目。

## 动态脚本与安全热重载

Rhai 支持动态类型、可变数组和映射、闭包以及函数指针回调。辅助模块使用字面量 use，合并到同一命名空间；不支持原生 import 别名或任意求值。导出常量支持嵌套数组、映射和 null。先验证整个受影响程序包，再原子替换。新的无效请求取消同一脚本旧的等待请求。失败时旧程序继续运行；兼容的导出状态保留，不兼容布局需要重启。停止运行清除会话所属的回滚数据；空脚本仍是有效回滚目标。SCRIPTING_CONTRACT_26_23.md 说明精确限制与权限。

## 诊断与菜单

脚本详情区加宽，长路径和错误可换行。监视路径支持自身字段、数组索引和带引号的映射键，显示快照值类型。它不是读取全部暂停 VM 局部变量的承诺；不执行 getter、原型遍历或表达式，长内容有上限。协作任务分派有所有者的回调，并不挂起任意 VM 调用栈。

顶栏切换保持一个可交互分支并保留动画。鼠标离开有缓冲区域和短暂延迟，返回取消关闭；Escape 恢复焦点，外部点击关闭临时菜单。表单不因鼠标离开丢失草稿。网站只允许指定 HTTPS 地址，拒绝打开时显示可恢复提示。

## 网页发布与检查

将编辑器 Web ZIP 完整解压到静态 HTTP(S) 网站并保留子目录。支持根路径和子路径；HOSTING.md 说明 WASM MIME、HTTPS 和缓存策略。本地编辑不需要应用后端，联网服务另行配置。“构建 Web → 下载 Web ZIP”在支持文件夹导出的浏览器中也可用。游戏 ZIP 解压后以 index.html 和全部文件部署；不以 file:// 代替网站测试。

检查新建/取消/恢复草稿、四十模板、语言切换、键盘链接、快速菜单切换、错误模块重载后修复、保存重开和子路径下的导出游戏。记录真实五分钟空闲和恢复的 CPU、DOM 与监听器变化。默认动画与游戏画质保留。原生/WASM 测试、浏览器自动化和模拟原生调用分别记录；Linux、macOS、iPhone、旧电脑、签名及独立安全和辅助技术测试需要对应环境，不能声称所有设备最佳 FPS 或绝无错误。
