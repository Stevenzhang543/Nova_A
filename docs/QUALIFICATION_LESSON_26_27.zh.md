# Nova_A 26.27 / 26.27.0

## 26.27 — 可测量性能与编辑器独立设置

Engine: **26.27.0** · Project Format 2/schema 29.

在设置中选择低端编辑器预设，再独立覆盖装饰动态效果、空闲帧率上限和预览策略。重置恢复预设默认值；系统减少动态效果和手动无障碍偏好保持独立。这些控件不会重写项目动画、物理或导出质量。

使用同一场景、分辨率、效果及硬件比较。Profiler 展示实际后备尺寸、后端、抗锯齿采样、CPU 各阶段及 GPU 计时是否可用。中位数、p95、p99 对应已记录帧；GPU 数据缺失不等于零耗时。按真实时间观察到堆增长不等于已证明泄漏。

切换 Design/Script，前台静置，进入后台并恢复，反复重开项目再检查输入。低端预览采用有界画布，关闭时释放像素和待执行回调。复用现有设计画布，不额外预加载一个缓存。保存、导出并运行游戏，确认作者效果、分辨率与动画保持。

报告保留受干扰的测量和不可用设备说明。短时间本机观察不能认证全天稳定、旧电脑或真实手机 GPU。
