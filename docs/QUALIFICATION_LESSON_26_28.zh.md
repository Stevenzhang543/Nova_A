## 26.28 — 动画、音频与本地化游戏界面

Engine: **26.28.0** · Project Format 2/schema 29。打开 creator-v2628-animated-menu 参考工程：时间轴控制标题动画、音乐和本地化字幕，按钮通过明确的 @timeline 动作控制播放。保留既有游戏功能、默认动画与画质设置。

在 Animate 选择已保存的资源，展开底部面板并选中轨道或曲线关键帧。修改关键帧值或音乐片段增益，保存资源草稿，再预览、暂停和定位。停止预览恢复作者场景状态。撤销／重做属于编辑操作；移动预览播放头不会自动写入关键帧。重新绑定前查看完整长路径。保存项目并重新打开实际下载文件，确认关键帧、字幕与增益。

嵌套时间轴的淡入淡出权重应乘入子动画及音频贡献；定位和反向播放使用相同的有界局部时间。显示帧率与音频采样率分开，显示帧不能取代整数采样时钟。混音器编辑属于项目数据；临时预览、传输及监听控制不能悄悄改写作者数据。

在 UI 本地化中选择项目语言并编辑翻译表；编辑器语言是另一项独立设置。缺译时采用源语言回退，保留作者标识符。游戏文字及无障碍描述应同步更新。字形覆盖依赖浏览器排版与可用字体，不宣称拥有独立完整文本引擎。

当其他按钮持有焦点时打开模态界面，键盘／控制器激活应限制在可操作的模态范围。禁用或隐藏控件不能继续响应。第二个空闲手柄不能重置第一个手柄的持续方向状态。原生输入框保持输入法组合状态；组合期间 Escape、方向键和 Enter 属于输入法。用键盘与触摸检查 RTL 滑块方向。

构建 Web 并下载 ZIP，通过 HTTP(S) 部署后只运行导出播放器：测试播放、暂停、跳过、继续、Unicode 输入和字幕。自动 PCM／DOM 检查验证语义；实际听感、实体手柄、手机输入法候选窗与辅助技术仍需对应设备观察。本版不重复无关渲染器与全部模板矩阵。
