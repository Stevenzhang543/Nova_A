# Nova_A 26.24 — 结构化图与可读工作区

状态：开发与审计中，尚未正式发布。当前源码目标为 26.24.0，项目格式 2/schema 29 不变。最终资格只由冻结源码上的全部门禁和 releases/v26.24 校验值确认。

## 已实现修改

- 手动拖动节点后固定位置，普通整理保护固定节点，显式完整重新整理可包含它们；撤销与代码重新投影保留对应状态。
- 图布局检查异步重入与卸载，测量缓存删除失效节点与端口。大图跨区域连线增加有界边界走廊尝试，修复不同节点尺寸的一万节点案例中的失败路径。
- 结构节点、语法字段、端口、帮助和 78 个图/Rhai 诊断编号共用三语言显示来源。原始详情可展开复制，作者标识与代码不翻译。
- 底部标签与操作分区，窄宽度改用选择框。资源工具栏获得完整行高，内部虚拟列表保持有界可视高度，资源观察器跟随标签重挂载；保留全部资源。
- 文本框补齐只读、禁用、错误、等待样式。Script 返回 Design 时同步校正保留画布的大小；项目关闭仍释放资源。
- 审计报告改为无损紧凑 JSON，减少格式缩进开销。添加独立测试、七份参考项目、三语课程及逐文件修改记录。默认动画保持启用。
