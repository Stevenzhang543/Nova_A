# Nova_A 26.30 — UI layout changes and bounded user qualification

## Consequences checked before editing

The shared presentation stylesheet affects many editor forms but does not own game data, serializers, history, runtime rendering or export shaders. Changes therefore target named form cards and the asset folder tree; they do not turn a canvas, timeline, waveform, large asset list, collision matrix or graph into a generic scrolling page. Default animations and authored effects remain unchanged. The Inspector width is a presentation preference: existing stored widths remain authoritative and continue to use the same 252–480px bounds.

## Godot source review

Read `godot-master/scene/gui/box_container.cpp::_resort`: it gathers each sortable control's minimum, desired and maximum size, records stretch flags/ratios and distributes the available space. The relevant principle is to honor control content and constraints within its actual container, rather than relying only on the outer window width. Nova uses existing CSS container queries and flex/grid sizing for this purpose. No Godot implementation was copied, and this is not a parity claim.

## User-flow coverage

The suite opens the populated creator project, changes Player position while focused, resizes, maximizes/restores the Inspector, downloads the actual saved project and checks its serialized position. It activates all six workspace routes and all currently available bottom/Manage navigation entries from their live DOM inventory. Explicit inner navigation covers script modes, presentation pages, network pages, world tools, ecosystem pages, settings categories, build pages and rendering pages. Conditional TileMap and populated world/network tooling use the actual platformer and streamed-host projects, not fabricated DOM panels.

Five representative profiles cover English/German/Chinese; all five palette choices; 100%, 150% and 200% text; 1366×768, 1024×768, 900×600 and 844×390 landscape. The German 150% / 1024px profile repeats every bottom/Manage route. Other profiles sample shared form/focus behavior instead of multiplying all unrelated conditions. One landscape navigation uses actual browser touch input; this is not physical-device certification.

The static companion `docs/PANEL_INVENTORY_26_30.md` enumerates every Vue source/conditional branch and host. Its entries do not imply every conditional dialog, plugin contribution, device permission or server error was exercised. Browser evidence explicitly lists every visited route/state; external/device-dependent branches retain their separate qualification limitations.
