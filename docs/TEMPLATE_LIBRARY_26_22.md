### Clear Scene · empty

1. From the launcher Library search for Clear Scene; select the visible card and Create.

2. Read the in-project Getting Started document. Requirements: Ready offline.

3. Create objects in Design, then press Play. The empty scene intentionally has no game controls.

4. Expected: An empty scene is ready for your first object; an empty Game preview is expected.

5. Stop, change one relevant authored value, Undo/Redo, save/reopen and repeat the same controls.

6. Export Web, serve the output over HTTP and repeat the expected behavior; inspect Problems/Console if it differs.
