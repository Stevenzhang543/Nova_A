# Nova_A 26.26 / 26.26.0

## 26.26 — 资源制作与可读资源库

Engine: **26.26.0** · Project Format 2/schema 29.

### 导入与重导入

先导入小批量有效文件。通过已有资源替换图片、音频或字体，保留 UUID；创建新资源是另一种身份选择。批量导入失败不能悄悄保留前面文件。撤销、重做、保存、重开后应保留所选身份与作者覆盖值。

### 依赖与导出

删除或替换前查看依赖及使用者。修复缺失引用时选择原本期望的现有资源身份；来源改变后检查图集与变体。先保存再重建，对照下载游戏包中的实际资源。只替换旧游戏包旁边的散文件不会更新包内内容。

### 资源库与面板

用网格或列表发现资源，在检查器/详情查看完整路径、元数据、来源及导入设置。长名称应可完整查看，键盘能到达并操作控件。大资源库保持渲染条目有界；延迟和内存结果只代表已测负载，不保证所有设备。保留全部四十个启动模板。

### 检查与边界

播放时替换资源并撤销，修复缺失使用者，移动项目后重开，选择变体、重建图集并导出。字体和音频仍需目标设备检查。离线创作保持可用；托管发现/发布需要真实配置的服务证据。完整面板清单区分源码条件分支和实际操作过的状态。
