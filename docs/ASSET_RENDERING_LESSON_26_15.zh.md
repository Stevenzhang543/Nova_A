# 生产资源与渲染工作流

## 先建立可观察的结果
学习导入时创建 Empty；学习光照时选择 Rendering Lab。启动器会在创建前显示真实运行截图、要求、控制方式与预期结果。搜索、分类和难度共同过滤；重置后显示全部四十个模板。“功能手册”打开相关系统章节，“相关任务”打开当前模板的完整操作说明。复用已有基础场景的模板和未绑定实际动作的演示控件均会明确说明。

## 导入、检查与恢复
打开设计工作区中的资源面板。导入图片及其图集 JSON，或正交 Tiled 地图和对应图片、图块集。批量进度显示完成、失败和取消数量。取消停止尚未提交的工作，已成功导入的资源保留；展开任务记录可查看并重试单个失败项。窄面板选中资源后进入全宽详情，点击“浏览”返回；较宽区域同时显示浏览、预览和详情。

预览读取实际图片，包括引用图集的派生帧。概览显示来源、错误及带类型检查的依赖选择器。缺少图片时先导入图片，再在相应来源字段中绑定并使用导航按钮检查。通过资源浏览器移动或重命名原图后，UUID 引用应保持不变。重新导入失败时保留上一个有效版本并显示错误。切换项目后，旧任务的迟到结果不能写入新项目。

## 切片和逐帧动画
选择导入图集，在切片页提取或更新帧。子帧保留稳定来源标识并共享原始图片，通过“打开原始来源”返回。原文件重命名或帧顺序调整不能产生无关的新身份。删除、错误和不支持的数据会进入明确的校验或修复流程。

普通图片可启用网格切片，设置列数、行数、边距和间距后创建子帧。“立即裁剪”分析实际透明像素。“自动切片”保存连通可见区域和首个区域的轮廓，本身不会创建独立的子帧资源。“从帧创建动画”生成普通 AnimationClip，保留来源顺序和各帧时长；无来源时长时使用1/12秒。随后通过普通动画工作流绑定到实体。仅提取帧不会自动给实体附加动画。

## 将 Tiled 地图放入场景
在创建场景 Tilemap 前绑定全部图片和外部图块集。导入会保留 firstgid、水平/垂直/对角翻转、向下来源行到向上世界坐标的转换，以及逐帧变化时长。支持有限正交 JSON 地图和图集式图块集，以及文档说明的简单 CSV TMX/TSX 子集。不支持的无限地图、等距布局、压缩数据、组/对象/图像图层和复杂碰撞几何会明确拒绝；这些功能应继续在原始 Tiled 文件中编辑。

导入地图拥有来源与图层。需要本地编辑图块定义时，在 Tilemap 中创建“可编辑副本”。副本是独立普通 TileSet，共享图片 UUID；编辑、撤销/重做和导出使用副本。重新导入更新原地图，不覆盖本地定义。图层绘制仍可使用，不能用不同格式的图块集覆盖原始地图文档。

## 共享资源和命名变体
通过资源菜单创建 Theme、Material、InputMap、PhysicsMaterial、AnimationLibrary 或 DataTable。点击保存前均为草稿。错误 JSON、未完成的变体和名称在切换资源/工作区时保留。“已保存运行值”明确显示已保存内容的解析结果。创建命名变体、编辑局部覆盖并保存，然后创建继承覆盖资源。子资源继承父级字段和变体，仅用本地字段替换对应值。重复名称、非对象 JSON、缺少父级、类型冲突和循环继承都会被拒绝。保存并重新打开后同时检查父资源和子资源，再依赖导出结果。

## 观察实际渲染并导出
在 Rendering Lab 的设计工作区选择 Point Light，修改强度。管理 → 渲染中的全局光照与输出设置独立于选中对象属性。确认像素确实变化，再检查诊断。方向光阴影暂不支持，相应控件会禁用并解释；更改光类型不会丢失已有值。法线方向会随图像旋转/翻转。初始化或着色器编译失败进入明确的回退路径；恢复图形上下文后重新建立资源。

纹理数量/字节上限、最高512MiB的 GPU 预算和每帧公平上传队列限制资源增长。启用剔除后，预加载边距请求附近资源。先检查队列、字节数和延期计数，再调整预算；增大预算会占用更多内存，不能保证帧率提升。动态画布和视频纹理按帧更新。Canvas 网格三角形边缘的抗锯齿可能与 WebGL 不同。

通过项目 → 构建选择 Web。没有目录选择器的浏览器会下载包含播放器、WASM、游戏包和文件清单的完整 ZIP。解压后通过 HTTP 提供目录；单独的 game.nova-pak 并不是完整浏览器应用。Windows 导出使用匹配当前版本的原生播放器。比较导出游戏与编辑器中的已修改光照和资源依赖，再保存并重新打开项目。证据记录实际文件哈希与测量结果，不能代表所有 GPU、物理设备或安装环境。
