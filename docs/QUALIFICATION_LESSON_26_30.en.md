## 26.30 — Integrated authoring and release qualification

Engine: **26.30.0** · Project Format 2/schema29. Start with a copy of a project and keep its migration backup. Open Project Health, resolve invalid references, then save and reopen before export. Do not overwrite the only old-format copy.

Create a template from Library, identify its main scene and entry script, then change one visible property. Preview, stop, undo, redo, save and reopen; confirm the same authored value. Build a Web game and check the downloaded player separately from the editor. Repeat this procedure for each template you actually intend to ship; catalog presence is not a successful walkthrough.

For code/graph equivalence, use a small function with a variable, branch and loop. Switch to Visual, inspect connections and nesting, edit a supported value, return to Code, and compare the resulting behavior. Unsupported source must remain preserved with diagnostics. Imported project use modules share a program namespace; they are not native aliased imports. Deliberately introduce a syntax error, verify the last valid running program remains, repair and reload. Changing persistent layout may require restart. Reopen the saved script to distinguish authored data from preview state.

For an animated menu, change a bound property/keyframe, seek and play, inspect nested clips and final pose, then export. Preview mute/solo belongs to the audition session; authored mixer changes belong to the project. For streamed worlds, unload/reload and replace a navigation target. A missing target must stop the agent; cell restore must not change another cell. For multiplayer, grant permission, connect two peers, inspect ownership, disconnect/rejoin, then verify actual downloaded players. Transform-delta snapshots are not full deterministic rollback.

Try every workspace using long paths and populated lists, narrow and wide windows, large text, EN/DE/ZH, keyboard focus and pointer menus. Read error details before retrying; cancel dialogs must preserve authored data. High contrast and low-end mode are optional settings. Record idle duration, frame samples and device rather than claiming universal FPS or leak freedom. Default animation and authored effects remain available.

Upload the Web ZIP contents to HTTP(S) root or subpath with relative assets and WASM MIME type. The editor needs no application backend for local work; optional authentication/relay needs its own compatible service. Installation/Add to Home Screen is an online shortcut: no service worker or offline reload is provided. Desktop requires its documented system runtime. Native physics JSONL CLI runs bounded physics requests only, not project/Rhai/server gameplay. Linux/macOS/device and independent accessibility acceptance require their real environments.

Read FEATURE_INVENTORY_26_30.md, PANEL_INVENTORY_26_30.md, COMPETITIVE_REVIEW_26_30.md and ISSUE_CLOSURE_26_30.md for declared routes and remaining limits. Actual acceptance belongs to frozen-source reports and checksums. Troubleshooting: restore migration backup, use Recovery Browser after interrupted saves, disable a failing package, inspect Console/Build diagnostics and retain the last valid export. Never turn an unavailable platform or unexecuted panel state into a passing result.
