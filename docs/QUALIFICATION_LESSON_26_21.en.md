# Nova_A 26.21 — readable editing and reliable history

## Open and arrange
Open creator-v2621-code-game, creator-v2621-blocks-game or creator-v2621-mixed-game from the reference library. Play with WASD or arrows, collect checkpoints and press R to restart. Keep animations and rendering effects enabled.

## Make controls readable
Open Manage → Settings. Set Form labels to Automatic or Above controls. Increase UI scale through 100%, 150% and 200%; narrow and maximize the Inspector. Automatic labels respond to panel width and text size. Numeric pairs wrap instead of losing their editable space. Hover or keyboard-focus a dropdown to read its entire selected value in a wrapping tooltip; Escape dismisses it. Native selection and existing help remain available.

Choose each of Cloud Blue, Meadow Cream, Blush Berry, Midnight Blue and Night Garden. Switch English, German and Chinese. Reload and verify the selected global preferences remain. Reset Settings restores Automatic labels. These preferences must not dirty a saved project.

## Edit, undo and export
Select Player. Change X, then Y immediately. Undo once: only Y returns. Undo again: X returns. Redo twice. Save, reopen and confirm both values. Change a slider, undo it, and repeat after narrowing/restoring the panel while a field has focus. Export Web and compare movement and the authored starting position with editor preview.

## Large scenes and evidence
Open authoring-5000-stress, use 200% text and scroll to Stress Object 5000. Select it and confirm the Inspector. Virtual rows preserve their spacing and actions. Loading time and complete-frame FPS are separate measurements: this release must not claim universal best performance.

## Qualification boundaries
The release evidence records actual commands, source hashes, browser actions and results. Source inventories and geometry checks do not prove every conditional workflow. Only Windows/Web are available locally; independent users, assistive technology, other platforms, signing and real-duration soak remain separately pending. Preserve previous releases.
