# Nova_A 26.27 — 性能、空闲稳定性与低端编辑器

Engine 26.27.0 · Project Format 2/schema 29。保留全部模板、默认动画、作者效果及既有游戏功能；26.26 发布文件独立保留。

## 本版修改
- 隐藏设计/游戏画布跳过图形提交；隐藏且停止编辑时以15Hz上限保留插件和热重载更新，播放与调试暂停保持原有更新。已有画布继续复用，切换回 Design 后同步尺寸，不增加第二份预加载缓存。
- 低端编辑器可独立设置装饰动态效果、空闲帧率上限和预览策略，并可重置。默认模式保留动态效果；系统减少动态效果独立生效。停止编辑时的低频等待不再每显示帧轮询，播放与拖动不降频。
- 图片预览采用明确尺寸与像素比上限，加载重试有间隔；卸载时释放回调和画布像素。断裂连接提示使用弱引用，不积累历史项目对象。
- Game 的后备分辨率由设备及作者画质设置控制，不受编辑器像素比偏好覆盖。作者明确选择的自适应显示能力保留；物理与动画时钟保持不变。
- 纹理驻留预算充足时避免每帧分配和排序全部缓存候选；过期释放、当前帧保护和超预算淘汰顺序保持。
- Profiler 展示实际分辨率、后端、抗锯齿、GPU计时可用性、CPU阶段及帧分位数。堆增长速率改用真实单调时间，不再假定每秒六十帧。

## 验证范围
比较同设备、同场景、同分辨率和效果的编辑器与导出播放器；记录首次/暖切换、真实前台静置、后台恢复、同页项目切换、资源计数及输入。渲染检查覆盖真实像素、抗锯齿边缘、透明顺序、缓冲区边界、纹理预算及设备丢失恢复；Native/WASM实际运行相同脚本输出夹具，媒体测试覆盖时钟分割等价与释放。

详细测量方法、改善与回归见 PERFORMANCE_26_27.md 及冻结发布证据。软件GPU结果不能作为物理显卡成绩，短时静置不能认证全天无泄漏。未取得真实设备证据的旧电脑、手机、其他操作系统和安装签名资格保持未认证；未运行的无关矩阵不算通过。
