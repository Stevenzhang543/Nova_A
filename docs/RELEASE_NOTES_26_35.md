# Nova_A 26.35

Engine 26.35.0; Project Format 2/schema 29 remains compatible. Release destination: releases/v26.35.

- Softer shared controls, floating surfaces and dialogs; more space around headers/property groups while connected docks, compact rows and bounded numeric/slider fields remain precise.
- Composed launcher with the existing Nova SVG mark, quiet node motif and preserved project actions, recents, templates, migration and recovery. Large-text template labels wrap as whole controls; recent-project hints have their own line.
- One finite spring system for menus, dialogs, palette, shared sections, tab indicators and committed reorder feedback. Input/focus is immediate; rapid closing makes overlays inert. Reduced motion and low-end mode disable decorative effects, including active animations.
- Valid/invalid/insertion feedback for hierarchy, assets/folders, tabs and dock gestures; direct canvas/resize/timeline manipulation stays immediate. Fixed the hierarchy resize handle's wrong edge and nested hierarchy drag bubbling into dock ownership. A fixed breadcrumb band prevents selection from shifting and cancelling an unselected hierarchy drag.
- Narrow hierarchy docks use shared overflow menus for scene, navigation and object actions, retaining Pin, Visibility, Lock and Enabled controls. Font-relative containment gives object names and search fields space at enlarged interface text; full names and IDs remain available in tooltips and the object menu. Stale menus close when their panel or object disappears; editing honors the existing recovery read-only mode.
- Shared menus remain keyboard-dismissable when every action is disabled, including read-only Scene actions.
- Selective transient menu/palette blur, with opaque accessibility/performance/unsupported-host fallbacks. No continuous decorative motion or persistent-panel blur.

## Verification and limits

Actual 26.34 baseline screenshots/measurements are preserved, including labeled harness calibration failures. Focused production-module spring/interruption tests, native controls, actual input/drag/cancel/history, large-text launcher inspection and source-bound all-panel/navigation/authoring/export checks cover the changed risks. Fresh Rust, native Windows, WASM, TypeScript and Web builds remain delivery requirements. Only successful frozen-source execution in the evidence ZIP certifies local qualification.

Generic resource-field drops, free-position floating windows, animation clip dragging and stable-identity keyframe neighbor settling remain follow-up work. Software-browser timing and layout/style/task counters do not certify paint costs, physical screen latency, device GPU costs, native drag-image appearance or prolonged comfort. Signing, clean-machine installation, other OS/device matrices, real low-end hardware and independent accessibility/security reviews remain external. The native stdio utility is physics-only; renderer-disabled WebView authority is a separate export.
