# Nova_A 5.0 troubleshooting

If the editor will not start, use the safe-layout/safe-mode flags, verify WebView2, and export a privacy-reviewed crash package. If a project will not open, use migration preview or read-only inspection; never force a newer document through an older editor. For missing assets, use Project Health reference mapping and deterministic re-save. For script errors, open Problems, follow the Script Studio help target, and migrate legacy API v1 calls to v2.

For Build errors, use the `?` beside the diagnostic. Confirm target availability, matching host, identifier, semantic version, startup scene, explicit include rules, deterministic release settings, provenance, and Web headers. For packages, review publisher, license, provenance, hash, certification, dependencies, and permissions; use Safe Mode and rollback if startup fails. Web output requires HTTP(S). A locally successful run does not clear external certification gates.
