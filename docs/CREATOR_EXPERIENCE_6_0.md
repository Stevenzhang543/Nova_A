# Nova_A 6.0 creator experience

Nova_A 6.0 turns the editor's existing production surface into a learnable workflow. First-run onboarding explains goals, workspace ownership, Rhai/Visual Graph parity, test and recovery paths, and the evidence boundary. **Manage → Learn** then exposes one searchable lesson per public feature and twelve complete game/release projects. Command Palette opens it without pointer navigation.

Every lesson has the same contract: classification; purpose and use case; preconditions; exact steps and result; persistence/export behavior; undo/recovery; common mistakes and fixes; keyboard/accessibility alternative; minimal and production examples; related Rhai and Visual Graph APIs. Progress is local editor preference data and never changes the project.

Progressive disclosure keeps transforms, history, simulation and Problems immediately available. Specialized work belongs to its named workspace; the Inspector remains contextual instead of becoming a second project-settings screen. Balanced, low-end and quality profiles change editor presentation costs only. No profile changes authored game content.

The complete lessons are generated from the same catalog into `manual/index.html`, `MANUAL.en.md`, `MANUAL.de.md` and `MANUAL.zh-CN.md`, preventing the in-app and offline descriptions from drifting.
