# Nova_A 26.29 — 世界、联网与平台交付

Engine 26.29.0 · Project Format 2/schema 29。保留既有编辑器、游戏功能、默认动画、画质和此前发布文件。

## 本版修改

- 世界流送恢复仅作用于当前分块后代；缺省 enabled 不再重新启用对象。导航目标失效立即停止旧路径，退出或禁用成员的导航缓存及时清理。
- WebSocket 握手在早期关闭或主动停止时立即结束并清理计时器与回调。联网诊断新增三语恢复范围、已接受快照年龄、刻和权威对等端；明确现有修正仅重放变换增量。
- Build Settings 展示目标对应的运行时与工具链前提，未知目标不再套用 Android。新增 Windows 外部只读启动检查，以及 Linux/macOS 匹配宿主构建说明和手动 CI 候选配方。
- 新增真正不创建窗口、不加载 WebView 的原生 physics JSONL stdio 工具。它提供有界物理命令，不加载完整项目、Rhai 游戏脚本，也不是联网游戏服务器。Windows 工具随参考资料 ZIP 交付，不新增发布根目录文件。
- 保留可直接上传的静态 Web 编辑器、可下载的 Web 游戏 ZIP 和 PWA 工作流；明确可选联网服务、权限及 HTTPS/WSS/CORS 前提。三语手册新增对应操作章节。

每个文件见 EDIT_LEDGER_26_29.md；具体实现和限制见 WORLD_26_29.md、NETWORK_26_29.md、PLATFORM_26_29.md。
