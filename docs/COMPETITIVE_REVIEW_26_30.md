This is a bounded engineering comparison, not a parity certification or benchmark. Current declarations are enumerated in FEATURE_INVENTORY_26_30.md (402 operations, 58 components, 169 Rhai entries, 208 graph nodes at generation). Every catalog route remains an implementation assertion until exercised. SOURCE_MAP_26_30.md distinguishes editor/player TypeScript, Rust core, native host, fixtures and generated outputs.

## Reference review and concrete design lessons

Local Godot sources reviewed: godot-master/scene/gui/container.cpp connects and disconnects child minimum-size changes; editor/docks/dock_tab_container.cpp applies scaled minimum sizes and expansion; scene/2d/navigation/navigation_agent_2d.cpp stops navigation on exit and requests a path after target changes. These motivate container-aware sizing, explicit lifecycle cleanup and invalidation; no implementation was copied. Full Godot source enumeration is not claimed. GDScript reference: https://docs.godotengine.org/en/stable/tutorials/scripting/gdscript/gdscript_basics.html .

Official GameMaker documentation checked during26.30 preparation: [Structs and constructors](https://manual.gamemaker.io/lts/en/GameMaker_Language/GML_Overview/Structs.htm) describes constructor-created structures; [Method variables](https://manual.gamemaker.io/lts/en/GameMaker_Language/GML_Overview/Method_Variables.htm) describes functions bound to an instance or struct. Nova_A dynamic maps and function pointers do not establish equivalence to those scope/type contracts. This comparison covers these documented scripting mechanisms, not every GameMaker product feature.

Next work should prioritize explicit module namespaces, complete state checkpoint/side-effect ownership, measured graph conversion coverage, assistive-technology/device qualification and matching-host releases. Keep these gaps recorded even where a similarly named panel already exists. Improve reliable diagnostic/recovery contracts before advertising parity.
