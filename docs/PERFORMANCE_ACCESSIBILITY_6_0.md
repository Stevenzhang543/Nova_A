# Nova_A 6.0 performance and accessibility qualification

## Bounded creator profiles

- **Balanced** caps display density while retaining ordinary previews.
- **Low-end** uses 1× pixel density, hierarchy performance mode, reduced preview effects and bounded virtual windows without changing project content.
- **Quality** raises preview fidelity for capable hardware but preserves all safety limits.

Qualification covers startup ownership, a 10,000-object hierarchy, a 50,000-asset normalized search with a bounded virtual window, a 1,000-node graph index, physics/render/graph capture bounds, memory-history limits and package output. Timings in local evidence are regression signals, not universal hardware claims.

## Accessibility matrix

All new workflows provide semantic headings, labels, live status, keyboard focus, target-size-safe controls and non-color status text. Onboarding supports Left/Right, Enter and Escape. Learning lessons use native summary/details semantics in the offline manual. English, German and Chinese are required at 1024×640, 1366×768, 1920×1080 and 2560×1440/high DPI in light/dark and standard/reduced motion. Existing RTL preview, screen-reader metadata, text scaling, contrast and input-remapping workflows remain available.

Browser/hardware, screen-reader/OS combinations and real low-end devices require independent evidence. They are never promoted from local static or synthetic tests.
