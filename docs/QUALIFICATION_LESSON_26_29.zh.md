## 26.29 — 世界、联网与平台交付

Engine: **26.29.0** · Project Format 2/schema 29。保留既有功能与默认动画。本章区分本机可以执行的操作，以及需要其他宿主、运行时或服务的操作。

为导航目标使用稳定实体 UUID，并将分块成员放在自己的根节点下。目标丢失或禁用后，旧路径与速度会立即清除；目标返回后可重新绑定。分块交接只恢复当前分块后代，未提供 enabled 时保持原启用状态。这只是有界变换／速度交接，不是完整脚本或物理检查点。检查卸载重载和目标替换，再保存、重开并运行导出项目。

在 Network Studio 启用联网包并明确授权后再连接。选择本地会话或明确配置的直接传输，检查实体所有权和 RPC 方向。Diagnostics 显示变换增量修正范围，以及最近应用的授权快照数据包的年龄、刻和发送端。年龄采用本地单调时钟，不代表远端延迟或完整世界状态。Stop 会立即结束未完成的 WebSocket 握手并释放计时器；重新连接使用新会话纪元，旧数据包不能恢复权威。

手动快照恢复或多人存档不会还原任意 VM 状态、求解器接触、随机数、音频、文件和联网副作用。重放变换增量不等于完整确定性游戏重模拟。设计依赖 rollback 的玩法前，请阅读联网契约；完整检查点与副作用日志仍是独立工程任务。

打开 Build Settings，阅读当前目标与架构的前提。Windows 桌面编辑器和游戏播放器需要 WebView2。无法启动时，从源码包运行 `powershell -NoProfile -File scripts/check-windows-prerequisites.ps1`；此命令仅诊断，不安装软件。低端画质设置不能替代缺失运行时。Linux/macOS 配方需要匹配宿主及系统库；存在构建说明不等于已有合格二进制。

参考资料 ZIP 包含 Windows 原生物理工具，源码位于 nova_headless crate；可用 `cargo run --release -p nova_headless -- --stdio` 构建并启动。它处理有界 JSONL 物理请求，不创建窗口或加载 WebView；不读取 project.nova、不执行 Rhai 游戏，也不作为多人服务器监听网络。现有关闭渲染的游戏服务器导出仍需正常桌面运行时。使用 `--version` 和 hello 命令查看具体边界。

将 Web ZIP 内容上传到 HTTP(S) 根目录或子目录，保留相对资源路径和正确的 WASM MIME 类型。本地编辑与单机游戏不需要应用后端；Build Web 可下载独立游戏 ZIP。可选认证、大厅、中继和联网必须明确配置兼容服务及 Origin／CORS／TLS 策略。PWA 安装或 iPhone 添加到主屏幕属于在线网页入口，不是原生 iOS 包或数据备份。本版没有 Service Worker，不支持断网重载。请在真实目标设备上验证。最终发布资格由冻结源码的实际执行证据决定，不能仅凭本说明推断通过。
