# Nova_A 26.36 / Engine26.36.0

This release replaces the earlier Nova_A letter and vector branding with the user-supplied light and dark PNG artwork. The launcher, persistent editor chrome and bundled manual select the matching mark for their own light/dark theme. Editor and manual favicons follow the selected theme. Windows application/installer icons and PWA/home-screen icons use the fixed dark artwork derivative, while exported players receive a bundled dark PNG favicon. Original supplied images and a derivation/identity manifest accompany the source.

Branding retains existing control and logo geometry, accessibility names, theme preference behavior and reduced-motion settings. The change adds no mandatory backend, dependency or permission. Editing, game rendering, history, project schema and runtime APIs retain their existing contracts. Project Format2/schema29, Rhai API2, Graph Format1, Plugin API2, Package Manifest1 and workspace document3 remain unchanged. Current mixed-authoring and renderer-disabled authority references are copied with26.36 identities; historical references and lessons remain intact.

The English/German/Chinese manual has a short branding lesson and current release metadata. Its literal N/gradient mark is replaced by the same supplied artwork. Existing website deployment edits and unrelated deleted www files are preserved without deployment or external publication.

## Linked verification and limits

The12-gate change-risk plan covers exact original/derived asset identity, pinned environment, fresh native/WASM/TypeScript/Web builds, actual theme/minimum/large-text branding and manual behavior, root/subdirectory static hosting and downloaded-player startup, Windows export, renderer-disabled authority, physics-only native stdio, source/archive hygiene and manual metadata/content. It deliberately omits unrelated engine,197-route panel, template, motion/performance, security and prolonged-soak sweeps. Every omitted gate has an explicit not-run reason; none is presented as passed.

Development captures are separate from release qualification. Only successful executed gates against the frozen candidate and independent package/hash verification establish local acceptance. Physical OS icon backgrounds, other browsers/devices, signing, clean-machine installation, assistive technology and external security/performance certification remain unmeasured. The native stdio utility is physics-only; renderer-disabled WebView authority is a separate full-game export. Web installation remains online-only and has no service-worker offline reload.
