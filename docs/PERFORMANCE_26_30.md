# Nova_A 26.30 性能验证范围

本版保留默认动画、渲染质量设置和所有编辑功能。布局改动集中于表单的可用宽度、控件高度与最大化页面的滚动层级；不宣称更改物理、渲染器算法或获得跨硬件的固定 FPS 提升。

`scripts/verify-v26.30-performance-user.mjs` 实际执行当前参考项目的120秒前台空闲、10秒隐藏后恢复、脚本/设计切换、20秒编辑器播放，以及真实下载的 Web 游戏启动和20秒回调采样。记录堆、DOM、监听器、任务时间及 requestAnimationFrame 间隔。回调频率不是 GPU 实际呈现 FPS；结果仅适用于当前 Windows/Edge 环境。最终发布报告位于证据包 performance 门禁，开发报告不作为冻结版本通过证明。

模板门禁核对40个模板的 Web/原生打包内容、内容哈希及增量缓存行为，不声称逐个游戏均经人工完整通关。原生构建、WASM、Windows实际启动、源码冻结、下载输出一致性和独立解压校验共同保护发布路径。

多小时空闲、低端实机、其他操作系统与移动设备性能仍需对应设备实测。省略重复历史压力矩阵；保留与本版布局、默认值、当前版本构建和输出直接相关的检查。
