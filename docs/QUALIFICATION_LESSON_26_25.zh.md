## 26.25 — 调试、继承事件与移动网页

Engine: **26.25.0** · Project Format 2/schema 29.

先阅读调试器能力说明：回调边界暂停和命令重放不等于暂停 Rhai 虚拟机。帧快照不是实时 VM 调用栈。继续或取消当前会话；过期源码位置不能覆盖当前草稿。监视表达式只允许有界、无副作用的检查，不执行任意游戏函数。

编辑事件前查看继承来源。同优先级按继承及声明顺序派发。无效回调和循环继承必须阻止保存，并提供定位诊断。修改后保存、重新打开、导出，核对实际内容。

触摸设备使用横屏。旋转不会销毁编辑器或未保存字段；竖屏提示只阻止操作。软件键盘缩小视口不视为旋转。设计画布单指编辑、双指平移缩放。

在 HTTPS 网站通过浏览器菜单安装；iPhone Safari 使用“分享 → 添加到主屏幕”。这是仅在线的主屏幕网页应用，不是原生 iOS 安装包。更新前保存或导出项目备份；不支持断网重新加载，已打开标签仅能继续使用已载入资源。

检查：诊断错误得分和失败回调，核对会话与源码身份，保存/重开/导出继承事件，在未保存表单和菜单打开时旋转，启动下载的游戏。Windows 浏览器模拟不能证明真实手机或 Safari 已通过。


窄屏手机可使用专注工作区扩大画布。
