# Nova_A 26.22 — 属性编辑与撤销练习

这是开发阶段的验收指南。示例面向引擎 26.22.0、Project Format 2/schema 29；生成示例不代表版本已经通过发布验收。

## 打开示例

打开 `creator-v2622-code-game`、`creator-v2622-blocks-game` 或 `creator-v2622-mixed-game`。使用 WASD 或方向键移动，收集检查点，按 R 重新开始。保留所有动画和渲染效果。输出质量、动画菜单以及权威服务器示例保留原有操作流程。

## 编辑与撤销

选择 Player，快速修改 X 和 Y。撤销一次只恢复 Y，再撤销一次恢复 X，然后重做两次。持续拖动滑块超过两秒，松开后一次撤销应恢复拖动前的值。在另一场景重复操作。输入 `120+3` 等有效表达式后立即保存，重新打开并检查数值。

选择位置不同的两个对象，确认界面标明混合值。输入共同数值并检查两个对象。应用和还原预制体覆盖，分别撤销。如果编辑使外部合并的原始依据过期，必须重新审查合并，不能直接使用旧结果。

## 纠正无效输入

输入 `1/0` 或超出字段范围的数值。草稿应保留并显示说明，已保存数值不变；保存和播放应等待纠正。按 Escape 恢复原值，或输入有效数值。切换对象或资源时，不得把旧草稿写入新选择。关节的无限限制使用明确的“无限”开关，大的有限数值仍应保持有限。

## 导入与音频

导入一段较短的 WAV 文件，在音频混音器选择它并添加循环区域。将起点改到终点之后，应显示无效草稿而不是删除区域。纠正起点，再修改终点，然后逐次撤销，分别检查两个端点。持续拖动主音量超过两秒，一次撤销应恢复整个拖动。再检查图片的每单位像素和轴心字段，以及保存和重新打开。

当前的编码格式、质量和平台压缩选项保存的是导入意图；导入器不会将源文件转码成这些格式。保存值一致不代表听觉或视觉质量已经验收。播放增益、过滤、循环和导出渲染仍需各自的实际运行检查。

## 可读性与输出

在 100%、150%、200% 界面缩放下，缩窄和最大化属性、资源及音频面板。数字输入应保留至少六位数字的可读空间，成组字段应换行。检查键盘步进、焦点、标签、混合值、默认值、覆盖和目标资源。使用英语、德语、中文以及全部五种配色重复检查，注明尚未打开的条件面板。

保存、关闭并重新打开项目。导出 Web，重复游戏、菜单和已修改属性的操作，同时比较实际行为与保存数据。在 `releases/v26.22` 创建十一份发布文件前，应验证旧版本文件的校验和没有变化。

## 证据与限制

已完成检查见 `IMPLEMENTATION_TRACKER_26_22.md`，尚未执行的能力见 `GAP_REGISTER_26_22.md`。生命周期矩阵已记录每项字段的归属和明确的证据限制；完成分类并不代表所有字段及输入均通过验证。开发报告不能直接作为冻结版本的发布验收。独立用户、辅助技术、其他操作系统、签名、设备音频及长时间运行测试属于单独的外部检查。

如果工作室中存在尚未保存的资源修改，项目保存、导出、播放和单步执行会暂停。请先在对应编辑器中保存资源，或明确重新加载以放弃草稿，然后重试。数值草稿会先接受验证。独立的动画资源预览仍可播放未保存的片段。解除脚本与图表的链接时，只删除真实的链接标记，保留代码、字符串内容和其他注释。
