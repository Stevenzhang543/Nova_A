# Nova_A 26.24 结构图、布局与本地化工作说明

**状态：开发中。此文档不代表 26.24 已完成资格审计或已发布。** 项目格式仍为 2 / schema 29，图格式仍为 1，Rhai API 仍为 2。应用、Rust 和 WASM 的版本权威已统一为 26.24.0；最终冻结与发布尚未执行。

## 图的位置和源代码

在 Script 工作区编辑 Rhai 后，Visual Graph 使用同一个结构表示。布局操作不修改语句、变量、函数或执行连线。源文件中的注释和用户标识继续保留；中英文或德文界面只改变系统标签。

More commands 中的 Pin selected positions（固定选中节点位置）会保存位置保护标记。普通 Arrange all nodes 和 Arrange selected nodes 避开固定节点，把它们作为碰撞障碍。手动拖拽提交后自动固定被移动的节点，取消拖拽不改变位置或固定状态。固定不阻止再次手动拖动；Unpin selected positions 可解除保护。Rearrange including pinned nodes 是明确覆盖固定位置的完整整理命令。这些操作均通过原有图编辑历史记录，可以撤销和重做。

固定状态保存在节点已有的 `config.layoutPinned` 中，无须新项目格式。结构重投影按稳定语法标识继承此状态。编译器不把该元数据写成运行时语句。异步整理完成时再次核对文档标识、作用域、几何版本和快照；中途发生编辑的结果不提交。

布局继续使用真实 DOM 测量。屏外但仍存在的节点保留测量，以免大图裁剪后反复丢失尺寸；从图中删除的节点和端口会被移出测量缓存。组件关闭后取消线程、计时器和测量帧。

## 可读性和显示

底栏把标签与固定操作分开，窄空间使用标签选择器。最大化、固定和展开按钮保持可见。资源区内部、所有条件面板及全语言全主题矩阵仍要进一步完成审计，不能把底栏标题通过误报为全部内容通过。

文本输入补齐搜索、邮件、网址、密码和隐式文本框的共同主题样式。只读、禁用、无效和待处理状态有明确的边框或光标区别。只读内容仍可选择复制。默认动画保留。

结构节点库、节点标题、字段和端口标签支持英文、德文和中文。作者自己改写的标题、变量名、函数名、关键字和源码不翻译。未知或扩展键原样显示。节点库使用主题文字和背景，类别色保留为边缘提示。声明导航按钮支持文字换行和界面缩放。

场景画布原本就通过持久视图保留，不需要再复制一个画布进行预加载。本版在页面 DOM 更新后同步调整画布，避免等待下一次尺寸观察回调才修正网格。项目管理器显示时 EditorLayout 被卸载，WorldCanvas 的现有卸载路径负责释放渲染器和监听器。

## Godot 本地源码对照

这次针对根目录提供的 Godot 源码检查了以下具体实现，并未宣称逐行理解整个第三方仓库，也没有复制其实现：

- `scene/gui/graph_edit.cpp`：连接去重、端口类型兼容检查，以及最小尺寸更新。
- `scene/gui/graph_edit_arranger.cpp`：选择集参与整理、层次与端口关系、节点尺寸、移动开始/结束信号和吸附。Nova_A 的布局提交相应经过单次历史操作和异步有效性检查。
- `scene/gui/graph_node.cpp::_resort`：先排标题，再读自动换行后的最小尺寸，随后计算子控件伸缩。Nova_A 继续由实际测量驱动布局，不能按旧固定高度假设长译文仍能放下。

## 当前验证及边界

开发阶段已执行的证据在 `release-audits/v26.24-*.json` 和对应截图中；最终发布必须重新绑定冻结后的源码与实际构建物。

- 结构转换：68 个案例，包括固定种子生成的 32 个程序、项目模块展开和长列表分组。37 种可执行结构节点经过源码/图代码的原生及 WASM 四路轨迹比较。Invalid 作为拒绝状态单独验证，不计入可执行结构覆盖。
- 布局引擎：实测尺寸、固定节点避让、选区、输入不变、缓存收缩、取消与工作线程回退，以及 100/1,000/10,000 节点案例。
- 本地化显示函数：全部 38 种类型，包括错误/保留源码显示；验证作者数据不变。
- 真实操作：代码建立图、符号导航、固定/整理/撤销、手动拖拽和取消、12 轮 Script/Design 切换、三语言切换后源码保留。
- 底栏：8 个可见标签，1024/1440/1920 窗口宽度与 100%/200% 文字缩放。资源工具栏内部区域已检查，600 项资源的网格/列表末项可达、缩宽后返回及窗口数量检查通过；媒体、网络等仍需要专门的有内容项目，尚不能据此声称全部条件状态已通过。
- 报告写入：一万条嵌套记录的紧凑 JSON 回读，中文和换行保留；循环引用及 BigInt 在覆盖原报告前失败。

帧时序来自本机自动化浏览器，不能用于宣称真实低端硬件帧率提高。一次观测中的 144 帧中位间隔约 41.6 ms，95 百分位约 45.9 ms；这不是前后性能对比，也不证明不存在内存泄漏。

## 补充开发证据：诊断、路由与文档重开

78 个图编译、布局、Rhai 词法/语法诊断编号有中文和德文说明。英文、未知编号及原始消息均保留。代码检查器和转换审查面板共用来源，原始详情可展开复制。三语真实浏览器测试验证错误转换阻止、草稿逐字保留及原始详情。

工作室保留回归验证真实键盘接线、手动路径点、撤销/重做、跨工作区草稿恢复与显式冲突处理。事件文档的保存验证使用切换另一份文档再重开并核对回调，而非依赖保存按钮是否禁用；资源显示名可以相同，因此按完整路径识别文档。

大图测试发现旧版本在 10,000 个不同尺寸节点的链中有 1 条跨区域路径失败。本版在有界网格搜索前增加每轴最多 32 条边界走廊候选，每段仍检查障碍，不移动节点或扩大网格预算。相同输入与位置下当前 9,999 条连线全部生成。基线为提交 0bfc303，交替运行两版本，各预热两次、测量十五次；原始样本和 p50/p95/p99 见 v26.24-graph-layout-benchmarks.json。样本少，p95/p99 都可能等于最大值；CPU 布局数据不能作为帧率或通用性能保证。

本版三语言验收课已编写，离线教材生成入口及布局/创作/程序员门禁入口已添加；教学内容已按 26.24 生成并通过手册审计，但完整发布资格运行尚未完成。核心功能仍需全部有内容面板、导出流程、全仓库中文注释与冻结发布验证。

## 2026-09-22 双向保存事务

图保存与代码保存均使用资源事务，失败恢复记录内容、顺序、目录、选择和代次。脚本保存先计算独立元数据副本，成功后才通知运行时；副本不能重定向图身份。18 项真实数据库回归通过，包含保护目录、冲突关联、分阶段中断、新资源撤销、CRLF 原文和多伙伴提交。程序员套件及旧构建的用户操作套件通过；后续反向保存修改仍需新构建界面复测。五配色完整面板矩阵正在执行，不能提前标为通过。
