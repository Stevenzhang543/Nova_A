# Nova_A 26.28 — 动画、音频与游戏界面制作

Engine26.28.0 · Project Format2/schema29。保留26.27全部功能、默认动画、画质与发布产物。

## 本版修改
- 嵌套时间轴将父片段淡入淡出权重传递到动画和音频；保留末帧姿态，修正反向进入边界的单次事件；定位保持无事件副作用。
- 混音器新增独立试听静音／独奏和重置，作者M/S仍保存与导出。长总线名可换行，动画绑定路径可展开复制，传输工具保持可见；大字窄屏采用可滚动完整创建标签及有最小高度的编辑区，避免工具栏遮挡。
- 模态、隐藏和禁用状态变化后清理无效焦点与重映射；各手柄独立记忆方向边沿；RTL滑块绘制、键盘、控制器与触摸方向一致。
- 游戏提示与无障碍文字统一随项目语言变化；图连线／布局临时消息按当前编辑器语言重新计算。补充缺失词条和标准API签名帮助，不翻译作者标识符。
- 新增本版带音乐、标题动画、三语字幕和明确播放动作的参考菜单，更新三语手册及网站部署说明。逐文件详见EDIT_LEDGER_26_28.md。

## 关联验证与边界
当前源码执行动画／采样／PCM、嵌套淡化、反向定位、序列化、试听隔离及UI焦点／输入回归；实际浏览器编辑曲线、增益与字幕，保存重开、撤销恢复并运行下载的Web播放器；受影响的媒体面板覆盖三语、五套配色及窄屏大字。最终通过状态以冻结源码的executed-gates和发布证据为准，开发报告不替代发布资格。

不重复未改动的全部模板、渲染性能、长时间静置与依赖矩阵。文本排版使用浏览器与字体栈，不宣称Godot全部文本／动画能力等价。硬件听感、物理手柄、移动输入法候选窗、屏幕阅读器和其他平台构建须实际设备另行验证。
