# 制作动画菜单与同步过场

本任务把动画、音频与界面制作连接到同一个保存项目。可从 UI Showcase 或当前动画菜单参考开始。先制作副本、保留导入原件并保存。参考的 expected-output 与 test-controls 描述具体操作；实际执行报告只证明其中真正观察过的步骤。

## 菜单布局与本地化

在 Interface 选择 Canvas 和 RectTransform 子对象。检查参考尺寸、缩放、锚点、最小/最大尺寸、安全区域、裁剪、滚动和文本溢出的真实预览。Fixed 布局明确不使用响应式断点。负内外边距会被限制并提示；需要重叠时使用带符号的位置/锚点偏移。隐藏、裁剪或模态背景中的子控件不应继续接受键盘焦点。设置可理解的无障碍名称、焦点与阅读顺序。component-source 元数据不会实例化 UI 子树；可复用关联内容应使用预制体。

打开主题资源，只在确实需要继承时设置父主题，并仅覆盖想修改的令牌/样式。子主题必须继续响应父主题的后续修改。spacing 令牌不会自动替换每个 Panel 的间距。保存有效草稿，再故意输入无效值并切换页面，确认原文仍保留且已保存运行值未变。源文件冲突需明确处理；重复语言归属和无效样式会拒绝保存。

为文本及支持的标签/占位符设置本地化键，填写英、德、中文和回退语言。检查长译文、字体回退和字形覆盖。构建需保留所选语言表、递归回退表与字体依赖。CSV 保留字符串和变体单元格；PO 支持普通多行字符串及 Nova 变体元数据。带索引的 gettext 复数请使用无损 CSV。用 IME 输入中英文混合内容、选择替换部分文本，再用 Tab 导航。组合输入中的 Enter 应提交文字而不触发游戏动作；编辑器按钮也不应传递游戏快捷键。

## 明确区分编辑、录制与预览

选中场景目标并打开 Animation。新建或选择动画片段，添加数值属性轨道、目标、关键帧时间与值。选中关键帧后编辑切线、插值与缓动，在 Dope/Curve 视图分别检查时序和曲线。调整资源结构与属性区域宽度，使用重置面板大小恢复默认。精灵帧有独立持续时间；命令和标记属于离散副作用，需要单独检查目标与载荷。

“将编辑记录到草稿”只添加未保存关键帧，不会随每次属性变化自动写入资源。请明确保存。无效或非有限数值应连同准确字段诊断保留，不能悄悄修正。限制为100条轨道、每轨10,000个关键帧；拒绝时不能写入一半新轨道。片段、控制器、遮罩、骨架、蒙皮、时间轴六类草稿应在资源/工作区切换和项目离开的保存/放弃/取消过程中保留。

先保存，再使用“预览已保存资源”。它开启自己的真实运行会话。暂停或修改实际运行时间，观察求值后的姿态；跳转不执行跨过的全部命令。“停止预览并恢复场景”恢复编辑值，旧预览不能接管后来由全局 Play 开启的新会话。运行录制在恢复场景之后转成未保存草稿，避免 Stop 把新录制内容覆盖掉。保存草稿并重新打开确认。

## 控制器、骨架与根运动

创建参数、状态和转换，检查起止状态、条件、退出时间、混合持续时间、目标偏移、中断方式以及标记/归一化时间同步。测试恰好位于边界的帧及中断中的转换。层遮罩、叠加权重、1D/2D 混合树和同步时序使用相同运行求值器。零权重层仍推进时钟但不贡献姿态；触发器不能在很久之后误触发无关转换。

先检查骨骼父子关系、静止姿态和蒙皮权重，再测试 IK、约束、相对静止姿态的重定向和镜像绑定。无效索引、循环与过量计算需要明确诊断。根运动 Apply 保留对已创作根位置和旋转的绝对采样；Ignore 忽略根位置和旋转但保留缩放。累积位移需要显式调用 animationRootMotionDelta/applyAnimationRootMotion，现有场景不会自动改为累积模式。检查完整循环和反向跳转，尤其是脚本也在移动对象时。切分曲线可能以1e-6采样误差容限烘焙为有限线性关键帧；这是有界近似，超限拒绝，不保证任意曲线的符号等价。

## 让音乐、字幕与时间轴同步

将轨道绑定到正确对象/资源，设置片段起点、长度、源偏移、播放率和增益包络。逐一检查用到的可见性、动画、音频、嵌套时间轴、命令与字幕轨道。在相应区间显示字幕，将参考中的可见 Skip 动作连接到实际时间轴目标。跳转应重建当前姿态/字幕而不执行所有跳过的命令。重叠音频需要独立声音实例；嵌套速率也必须影响音频。

在 Audio 选择片段与试听总线，检查输出总线、发送以及低通/高通、压缩、延迟、混响参数。混音器试听使用独立的真实游戏混音器实例，停止试听不能停止其他游戏声音。循环、裁剪和波形编辑应作为明确、可撤销的修改。显示的 RMS/采样峰值是估算，不是 BS.1770 响度或过采样真峰值。暂停/跳转时查看播放时钟、采样位置与实际声音状态。

共享媒体时钟跟随真正执行的固定模拟步。暂停冻结播放，暂停单步会计算姿态/采样位置但保持静音暂停。缓冲音频的带符号速率有界；流式播放使用浏览器媒体机制，不支持的速率会暂停并提示。大文件使用 Stream。限制为64MiB驻留 PCM、单片段32MiB和16个待解码任务。设备延迟、实际网络流恢复仍需相应硬件验证。

## 保存、重开并导出同一个流程

完整运行菜单与过场：启动音乐，观察字幕起止、暂停/恢复、前后跳转、循环、结束和 Skip。停止再运行，确认声音、监听器、预览与原生文本桥被释放。检查窄面板、深浅主题、三种语言及100/150/200%缩放，分别测试触摸按下/取消、键盘与 IME。

保存后重新加载应用，用 Open 文件选择器打开实际下载项目，重复相同流程。导出完整 Web ZIP，通过 HTTP 提供解压文件并在播放器复测。原生导出使用真正通过资格检查的 Windows 构建。确认语言/字体/音频依赖、字幕、焦点与 Skip 保留。保存失败记录和带哈希产物。固定帧/采样与序列化检查属于程序验证，不能替代扬声器、屏幕阅读器、低端设备或长期运行观察。


## 绑定参考项目动作并确认保存结果

选中菜单按钮，在检查器的时间轴动作中选择播放、暂停、跳过或继续。明确的 @timeline:play/pause/skip/resume 值会查找按钮本身或最近父级上启用的 TimelinePlayer。把共享播放器放在菜单 Canvas 上即可，无需 Script2D 或写死目标 UUID。选择自定义回调可恢复此前的脚本回调。参考序列长30秒，Arrival 标记为20秒，Introduction 标记为0秒。暂停保留位置；跳过遵守不可跳过片段；继续从设置的标记开始播放。
