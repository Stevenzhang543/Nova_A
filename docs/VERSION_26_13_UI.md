## Consequences assessed before edits

- At 1,024×640, the 26.12 graph palette overlays 310 pixels of the canvas while the details pane takes another 340 pixels. Responsive pane decisions must use the actual editor container, not the outer browser alone. Resizing a pane should preserve graph coordinates, current selection and viewport; hiding a pane must leave a reachable reopen control.
- Typed AST nodes currently inherit reporter pills and hidden data pins from legacy block styling. They need ordinary cards, wrapping headers, and accessible structural pin controls in either authoring mode. Legacy execution blocks keep their own appearance.
- Node size and pin position estimates are currently fixed arithmetic. Measured rendered bounds must be kept outside source semantics, update after content/scale changes, and fall back safely for virtualized nodes. Measurement must not cause history or compile churn.
- Each new code projection queues one initial measured arrangement by exact live asset identity. The editor consumes it only once after rendered bounds are available, uses the same undoable worker path, and cancels the pending/running operation on pointer, key or wheel interaction and unmount. Existing saved and recovered graphs keep their positions.
- Full and selected layout must be explicit undoable content operations. Selection, current viewport and unaffected manual positions remain stable; asynchronous results must be rejected if their graph revision or selected scope becomes stale. User cancellation must leave the graph unchanged.
- Edge selection, disconnect and reroute controls mutate actual edges through the existing history path. Connecting compatible pins must work by keyboard as well as pointer, report mismatches, and avoid modifying text fields through global shortcuts.
- Compact script toolbars and resizable inspectors must retain every command through a reachable overflow/control surface. Panel resizing is layout preference state, not a script-content edit. A collapsed details pane needs a visible reopen action and accurate expanded state.
- Viewport panning, node dragging, box selection, wire endpoints and measurements now account for the actual canvas CSS scale as well as graph zoom. Pointer cancellation, lost capture, Escape and unmount restore unfinished drags rather than recording partial node/comment/routing-point movement. Numeric routing coordinates are validated before mutation, with 64 points per wire and 100,000 per document bounds.
- Pending wheel-history timers are flushed before saving, opening a graph or arranging nodes, and cancelled before Undo/Redo. A delayed timer therefore cannot mark a newly opened/saved graph dirty or make arrangement Undo unexpectedly restore an older viewport. Minimap drag cancellation also restores its original viewport and dirty state.
- Automatic routes stay transient. A route-only worker request with an explicitly empty selected-node set reconstructs routes on open, undo/redo, content changes and changed measurements without moving nodes or creating history. Both explicit arrangement and automatic routing reject stale document/scope/geometry results. A failed route is identified visibly and selected through its diagnostic; it is not replaced with a falsely successful curve through obstacles.
- The source editor preserves the final 26.12 scoped rename, module diagnostics and save/conversion guards. Its file tabs replace the mouse-only nested close icon with a separately named button. Its compact toolbar retains secondary commands in a keyboard-accessible disclosure. Inspector tabs use natural height and cannot flex-shrink below wrapped coverage text.
- Event Sheet departure delegates to the Event Sheet editor's awaited Save/Discard/Cancel guard before changing modes. Left/Right/Home/End navigate the mode tabs without implicitly approving a save; Enter/Space activates the focused tab through its existing guarded action.
- The first browser run reproduced a pre-existing global CSS conflict: a 26.10 `!important` rule forced every `.studio-grid` to one column below 1,100 pixels, overriding the new measured column budget and reducing the source textarea to 77 pixels. The source grid now identifies its measured layout; the root-owned global rule excludes that marker while retaining its behavior for other studios. The revised real-browser check measured a 347-pixel-high, 550-pixel-wide textarea at 1,024×640, and passed the pane-resize/focus checks.

- Unsaved editor state previously lived inside components unmounted by workspace changes. The new session cache is a WeakMap keyed by the exact live asset object, with project, UUID, asset-kind and exact saved-base checks. It retains full draft text without truncation or silent eviction; ordinary object replacement cannot revive a stale draft merely by UUID. An explicit failed-project-load rollback can restore snapshots only when the saved content at snapshot time matches. That snapshot source is stored separately from the original draft base, so an already-conflicted draft remains recoverable and still shows its conflict after rollback. This is in-session recovery; it does not promise browser-restart persistence.
- All three editors register a live dirty-draft provider, so the project departure guard sees mounted edits before unmount. Source also retains inactive dirty tabs. Graph recovery includes its bounded existing history, selected identities, scope and viewport; unfinished pointer movement is cancelled first and completed wheel viewport edits are recorded before capture. Successful Save or explicit Discard clears recovery. Saved-source changes display two version previews and require Keep (acknowledge the new base before the next validated Save) or Discard. The preview can truncate its display at20,000 characters, while recovery retains the entire source.
- Event Sheet recovery reads its own trusted cached JSON directly. Running that draft through the saved-document normalizer would silently rewrite invalid callbacks and clamp invalid numbers. A new pure draft validator adds localized errors for raw callback identifiers, priorities and deterministic seeds before Save. Saved/imported documents retain the established external parser.
- The scripting mode contract explanation moves from an ellipsized paragraph to a reachable Help disclosure with wrapping and bounded scrolling. Its tablist contains only the three mode tabs. Graph node-search/wire controls receive ordinary themed buttons; source-list rows align to their content instead of stretching a single asset to fill the pane.
- The browser save/reopen test found that the layout engine's empty selected-node set skipped every edge, contradicting the intended route-only contract. The backend agent repaired that filter and added an actual routed-edge/blocked-route regression. The editor exposes routing busy state and distinguishes dashed provisional paths while the worker computes final paths; the browser test waits for completion.
