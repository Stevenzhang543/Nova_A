# Nova_A 3.9 optional networking gate

The optional package defines bounded WebSocket/native-UDP transport, RPC direction/authority, replication ownership, interpolation/prediction/rollback, diagnostics and fixed-tick headless-server contracts.

It remains Experimental. Message bounds, bandwidth budgeting and the headless interface pass; hostile-network security, sustained packet-loss and multiple-native-instance qualification remain incomplete. Networking is not a Nova_A 4.0 core-stability blocker.
