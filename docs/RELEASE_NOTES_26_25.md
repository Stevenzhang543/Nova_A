## 编辑器与运行时
- 调试器区分回调边界暂停、命令重放及 VM 语句暂停能力。保留支持的边界步进；宿主快照不再伪装完整 VM 调用栈。
- 协议绑定执行会话、暂停编号及权限；取消和继续调用实际宿主。监视表达式拒绝调用、赋值和 getter 副作用。作者源码定位与编译会话绑定，过期位置不会覆盖未保存草稿。
- 语言服务拒绝修订、API 或外部函数列表不匹配的回复。图调试清理旧会话文档。
- 继承事件同优先级顺序与运行时一致；保存边界拒绝资源身份替换和循环。事件/蓝图界面展示条件、动作与来源，并提供诊断定位。原有回调去重规则明确显示。

## 网页与触屏
- 缺少必需能力的浏览器先显示可读启动提示。Web 包仍支持直接部署到静态网站子目录。
- 触屏编辑器横屏工作；竖屏保护保留已挂载项目与未保存字段。处理可视视口、键盘、安全区域和触摸控件，设计画布支持单指编辑及双指平移缩放。
- 旋转会安全关闭顶部菜单，横屏后可重新打开。手机可使用专注布局扩大画布；不声称小屏与桌面同等可读。
- 新增相对路径 PWA 清单和图标，以及 iPhone 添加主屏幕说明。采用仅在线策略，不安装缓存旧应用壳的 service worker；更新需要保存后重载，部署须整包原子更新。
