## Every registered Rhai API entry

| Identity | Signature | Behavior |
|---|---|---|
| lifecycle.awake | fn awake() | Runs once when this instance enters play. |
| lifecycle.start | fn start() | Runs after every active instance has awakened. |
| lifecycle.fixed_update | fn fixed_update(dt) | Runs once per fixed physics tick. |
| lifecycle.update | fn update(dt) | Runs once per rendered gameplay frame. |
