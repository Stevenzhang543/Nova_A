# Nova_A 5.0 security and diagnostics privacy policy

Report vulnerabilities privately through the project security channel before public disclosure. Critical and High dependency findings block Stable installation or release until fixed or explicitly isolated with evidence. Packages fail closed on provenance, trust/hash, compatibility, dependency, license, certification, or permission errors. Archive paths are normalized and traversal is rejected; native package entry points are never executed by the browser.

Diagnostics and crash packages are local exports. They are never uploaded automatically. Before export, the user chooses whether project identifiers and paths are included. Source contents, credentials, signing keys, tokens, environment secrets, and arbitrary user files are excluded. Network actions in deployment/team workflows remain disabled unless enabled and still require a direct user action. Release evidence includes dependency and license audits without embedding secrets.
