# Nova_A 26.21 — 清晰的编辑界面与可靠的撤销

## 打开与运行
打开 creator-v2621-code-game、creator-v2621-blocks-game 或 creator-v2621-mixed-game。使用 WASD 或方向键移动，收集检查点，按 R 重新开始。保留动画和渲染效果。

## 调整可读性
进入 Manage → 设置，选择自动标签或将标签置于控件上方。分别检查 100%、150%、200% 界面缩放，并缩窄、最大化及恢复检查器。自动布局根据面板实际宽度与字号排列标签；数值字段可以换行。将鼠标移到下拉框，或用键盘聚焦，即可在自动换行的提示中阅读完整选中值。按 Escape 关闭提示，原生选项操作及原有帮助保持可用。

依次检查 Cloud Blue、Meadow Cream、Blush Berry、Midnight Blue、Night Garden，以及英语、德语和中文。重新打开后全局偏好应保留。重置设置恢复自动标签。修改这些编辑器偏好不应使已保存项目出现未保存标记。

## 编辑、撤销与导出
选择 Player，先修改 X，立即修改 Y。撤销一次只恢复 Y，再撤销一次恢复 X。重做两次，保存、重新打开并验证坐标。修改滑块后撤销；字段聚焦时缩窄、最大化和恢复面板。导出 Web，对比编辑器预览与输出的初始位置和移动行为。

## 大场景与审计范围
打开 authoring-5000-stress，在 200% 缩放下滚动至 Stress Object 5000 并选择它。检查行间距、检查器及原有操作。加载时间与完整帧率必须单独测量，不能据此宣称所有场景性能最佳。
