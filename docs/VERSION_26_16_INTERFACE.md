## Scope, baselines and consequences assessed before editing

All files in this ledger are staged in `.cache/development-v26.16`. They do not change an earlier release. WorldCanvas starts from the final26.15 canvas baseline SHA256 `18fa6cea5554b0a23d49231d657914f847bffa09957fc579a52a58d09bf8b0b7`; its fresh-canvas replacement, renderer initialization generations, cleanup and once-per-frame camera delta remain intact. GameplayRuntime preserves the final26.14 callback/pool baseline `0dca6a61e08c7641d60449c179728762a55c85ee5191993c8ec2e87552279718`, plus the16 media changes. The store/physics copy starts from the final active14 source;15 had no override. Asset graph and package copies start from final15 and retain its source validation, explicit inclusion, stripped closure, derived-sprite and authoritative-package changes.

The previous runtime and responsive validator had different geometry. Partial anchors expanded to the whole parent, disabled ancestors left children interactive, container policies were ignored, and z-order could be overridden by a later entity index. The shared solver changes those incorrect results. No persisted UI component field is removed. Fixed layout retains anchors but uses unscaled pixel sizes and ignores responsive breakpoints. Canvas DPI is an authored multiplier; physical pixel density does not independently multiply logical coordinates. Safe-area previews supply explicit logical device insets.

Text previously compressed glyphs into one line despite wrapping/overflow fields. Measured wrapping, clipping and ellipsis retain glyph shape; some text now occupies more lines or visibly clips. Authored Text font size/weight remain authoritative for geometry and drawing. Theme font size/weight style native controls; a theme does not silently replace a sibling Text component's authored typography. Locale fallback fonts also apply to native controls. Native TextInput retains its100,000 UTF-16 unit authored limit, and truncation cannot split an astral character. Canvas paragraphs/grapheme processing has a separate32,768-unit limit, reported by validation.

Native composition previously committed intermediate values or closed on IME Enter. The bridge now defers commits until composition ends, preserves selection, and lets editor controls own their keyboard activation. Checkbox activation occurs on release inside, never on pointer cancellation. Slider pointer/keyboard changes now emit one on_value_changed callback for each actual value change. Duplicate unchanged samples emit none. Password accessibility values are masked, including explicit value overrides.

Tinting used destination-in on the shared scene surface, potentially erasing previous UI. Tinting now happens only in a bounded isolated source surface, then uses the ordinary image or nine-slice draw. Failure produces a missing-image marker and diagnostic rather than an untinted success claim.

Theme inheritance resolves parent values separately from editable child source. A child GUI save preserves omitted variables/tokens/classes so later parent edits remain effective. Locale/theme validation precedes writes. Duplicate locale ownership and invalid creation refuse before asset mutation. Draft save/discard/cancel protects document switches; project/session retention also covers panel departure. Whole-project playback restoration and preview ownership belong to the media/UI lifecycle contract.

## Field, serialization and runtime semantics

The explicit fixture covers every own field of all ten UI component classes. It exercises independent scene JSON save/hydration, disabled and removed metadata, deterministic package bytes, package file recovery and hydration. Button.state is deliberately omitted from persisted authoring values and resets to Normal/Disabled according to interactable. Removed components reload disabled. Blank accessibility defaults can be derived from a control's kind on hydration; explicit authored fixture values remain unchanged. Serialization fidelity is not a claim that arbitrary metadata has a runtime consumer.

RectTransform.componentSource/componentVariant remain metadata; they do not instantiate a reusable subtree. Validation says so and directs linked content to prefab instances. Container padding/margin insets clamp negative values to zero, with a visible finding; signed position/anchor offsets support intentional overlap. Scroll/mask geometry and safe areas use logical viewport pixels. Physical device insets need a matching-device test. Fixed layouts deliberately skip responsive breakpoints.

Theme variable spacing does not replace each Panel's authored gap/padding. Grouped tokens resolve only when a supported style references them. Invalid style properties refuse save; unused token and unresolved parent findings are visible. Native control font family comes from the theme variable plus locale fallback fonts. Text components retain their own typography and optional imported font/outline. The fallback family order is tested; physical glyph coverage and assistive technology pronunciations are not certified by those tests.

Localization runtime uses the first matching table; new/edited tables cannot create duplicate locale ownership. Existing externally supplied duplicate tables should be merged. CSV supports string and JSON variant cells. PO supports ordinary multiline strings and Nova variant metadata. Indexed gettext plurals are rejected with guidance to use the lossless CSV representation. The existing font/locale asset formats and serialized field names are preserved.

Caption starts/ends share simulation time, pause does not advance expiry, and stop clears active captions. Timeline seek reconstructs subtitle tracks in the timeline evaluator. Ordinary one-shot captions are not a historical transcript and do not reappear after they have expired and time is moved backward. Physical audio output latency is separate from this deterministic clock contract.

## Explicit resource budgets

- UI solver:20,000 scene entities,64 ancestry,256 runtime breakpoint checks per component,2,000 findings. Existing project hydration accepts32 breakpoint rows; source/runtime limits are separately reported. Scene-index ordering cannot outrank authored z-order.
- Canvas paragraph/grapheme processing:32,768 UTF-16 units; native/persisted TextInput:100,000 units with safe cuts. Actual font measuring is bounded by that content limit; pathological very long unbroken text may still be more expensive than ordinary UI labels.
- Preview:4million backing pixels and20Hz dirty updates. Image tint cache:16MiB; oversized source region refuses instead of modifying the scene canvas.
- Theme inheritance/token chains:32; one theme source:2million UTF-16 units; bounded classes/variables/variants.
- Localization tables:256 cached records/16MiB text,20,000 entries per table,64 fallback languages. Extraction:64 ancestry,100,000 traversed objects,20,000 fields/object,512 scripts/4million UTF-16 script units, explicit incomplete-coverage diagnostic.
