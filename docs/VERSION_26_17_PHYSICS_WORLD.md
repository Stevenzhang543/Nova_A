## Findings to reproduce and close

Physics2D.sweep/nearest filter only their first hit, so an excluded or sensor hit hides a later eligible result. Query enrichment uses the owner's primary collider instead of the hit compound child. World.nearest samples64 rays and can miss a small target between rays while repeatedly synchronizing all bodies. Navigation's cache signature omits authored clearance; direct path lookup accepts a disabled region; SceneGeometry presently shares the obstacle-only sampling path. World origin shifting clears all retained Rust handles/contacts and leaves other world-space state unshifted. Scene streaming sets SceneDocument.loaded without installing the owned scene into the active World. These observations are not claimed fixed until actual behavioral tests pass.
