# Nova_A 5.x support policy

Nova_A 5.0 is the compatibility baseline for the 5.x line. Stable contracts receive compatible bug, security, migration, and documentation fixes throughout 5.x. Project Format 2 schema 29, Rhai API 2, Plugin API 2, Package Manifest 1, and Build CLI 1 do not receive a breaking change in a 5.x minor or patch release. Windows x86-64 editor/player and Web player are Tier 1; support is limited to the minimum systems and evidence boundaries in the platform matrix.

Experimental targets and packages have no production compatibility promise and are hidden from default release authoring where incomplete. Support reports should include a privacy-reviewed diagnostic bundle, exact version, target, renderer, reproduction project or minimal steps, and whether the problem occurs in a clean reference project. Never include credentials, signing material, or private project paths unless explicitly reviewed.
