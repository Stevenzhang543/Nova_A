# 26.24 结构化图与可读工作区验收课

本文描述 26.24 的预期操作和已实现契约。开发检查不是最终发布资格；发布状态以本版实施跟踪和冻结证据为准。

## 先理解代码与图

打开代码示例，在 Script 工作区创建 Rhai 脚本。具名函数必须位于模块作用域；循环内才允许 break/continue。数组、映射、闭包、动态调用、条件、循环、异常处理及项目 use 依赖使用相同解析器和运行时限制。代码切换成图时，结构区域有可编辑节点；仅保留源码的旧 Execute Rhai 区域不应冒充结构覆盖。错误区域阻止转换，编辑器和未保存草稿保持打开。

依次尝试：写一个带中文注释的函数；切换图；选择声明并改名；修改字面值；返回代码；检查注释、作用域和引用；撤销与重做；保存、重开项目并导出 Web。改变函数参数顺序会改变调用语义，不会自动猜测作者想要的参数迁移。共享函数存在其他模块调用者时，不安全的单文件改名应拒绝。请先审查调用者，再修改接口。

## 自动布局与固定位置

节点使用实际测量尺寸。手动拖动完成后，该节点位置自动固定；按 Escape 取消拖动不会创建固定状态。选中节点后，在图命令中使用固定或取消固定位置。普通整理保留固定位置并避开它们；明确选择包含固定节点的完整重新整理才允许移动它们。固定标记属于编辑器几何信息，不进入生成的 Rhai。用一次撤销检查位置与固定状态一起恢复。

反复切换 Script 与 Design，检查网格尺寸、选择和图状态。现有画布在工作区切换时保留；返回可见状态后更新大小。关闭项目仍须释放资源。本机短时切换测量不等于无内存泄漏证明，也不等于所有硬件的帧率保证。

## 诊断与原始详情

中文、德文和英文界面共用结构名称、端口及诊断显示来源。诊断编号保持稳定；中文和德文先显示原因说明，展开原始详情可查看完整标识符、源位置与底层消息。未知诊断保留原文，不能隐藏。写入 const broken; 后尝试转换，应看到缺少初值的提示；草稿必须原样保留。修正后才能继续。

## 底部面板与大资源库

在 1024、1440、1920 宽度及 100%/200% 界面缩放下逐个打开底部标签。窄宽度使用标签选择框，展开与折叠按钮仍可操作。资源工具栏应完整占据自己的行；资源区提供主要滚动区域。600 项测试库通过内部占位保留总长度，仅创建可见窗口附近的卡片。滚动到末项、切换列表、离开资源标签并改变宽度后返回，末项仍可到达，项目内容不能减少。

## 程序员验收

运行本版结构等价、文案、真实图操作、诊断、资源窗口与底栏测试，再运行保留的语法槽、类型图、布局和发布工具测试。等价测试强制结构重新生成，并比较原始/生成代码在原生及 WASM 的执行轨迹。语言表不能代替执行证明；布局截图不能代替真实鼠标和键盘操作。全部 21 个发布门禁、冻结源码、11 个独立校验的发布文件仍是发布前置条件。
