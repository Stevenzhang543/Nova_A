# Nova_A 26.10 release notes

Machine version: **26.10.0**. Nova_A 26.10 closes the local 2026 roadmap as a stable, lightweight 2D creator platform. Product versioning does not break Project Format **2/schema 29** or any of the seven frozen public contracts.

## Stable creator platform

- The platform-readiness model and gap register use explicit, typed evidence. A local release is blocked by any unclassified item, missing readiness dimension, or open severity 0/1 issue. Work needing another host, real hardware, signing identity, public deployment or independent people remains visibly external.
- Control identities are locale-independent. The cumulative user audit inventories each reachable launcher, workspace, panel, subpanel, menu, dialog, Inspector, input, drag surface and shortcut, with an executed, safely sandboxed, disabled-with-reason, destructive, OS-mediated or external disposition.
- English, German and Chinese manuals are regenerated from the public feature catalog and accompanied by current API/SDK, migration, troubleshooting, support, reproducibility, clean-machine and usability guides.
- Representative code-authored, block-authored and mixed-authoring game references exercise save/reload, play, synchronized code/graph behavior and deterministic Windows/Web build inputs.
- UI naming, rounded typography, semantic colors, empty/error states, keyboard focus, reduced motion and translated/scaled containment share one contract across all panels.

The local gate covers TypeScript, Rust, WASM, Web, Windows editor/player installers, all templates and historical fixtures, graph/code/event parity, renderer/physics/audio/network determinism, plugin lifecycle, security, performance, stability, repository hygiene, manuals, layout, interaction evidence and the exact eleven-file release package.
