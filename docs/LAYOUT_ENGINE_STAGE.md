## Contract and consequences

`graphLayoutEngine.ts` exports `layoutGraph(request)` and `layoutGraphAsync(request, { signal, onProgress, yieldControl })`. The request structurally accepts current graph nodes/edges, `measuredBounds` keyed by node UUID, `measuredPorts` keyed by pin UUID with local offsets in graph units, optional `selectedNodeUuids`, `origin`, `gap` and `preserveReroutes`. Missing selection means all nodes; an empty selection moves none and recalculates every fixed-node wire route and blocked-route diagnostic. A nonempty partial selection routes edges touching that selection.

The result contains `positions` only for movable nodes, complete absolute orthogonal `routes`, nested control `regions`, precise `diagnostics` and actual timing/count `metrics`. No source, node fields, graph identity, selection, viewport or history is mutated. Editor integration must snapshot its document generation, cancel obsolete jobs, and apply an accepted proposal as one existing undo transaction. Measured DOM dimensions must be divided by graph zoom. Node size changes, drag and pan-independent geometry changes invalidate transient routes. Complete automatic polylines are distinct from authored `edge.reroutes` waypoints.

The deterministic forest recognizes typed child-to-parent ownership edges, preserves pin order, cuts cycles without dropping nodes, packs measured child regions and disconnected roots, and avoids fixed-node rectangles for selected-only layout. Very deep chains continue in separate regions after 32 ownership/flow levels with an explicit diagnostic; all original edges remain. Explicit automatic layout replaces selected/all manual node positions as requested; it does not repeatedly rearrange a graph during ordinary editing.

Routes avoid node obstacles through direct corridors and a bounded local visibility grid. Manual waypoints are retained unless the caller requests route reset. An obstructed waypoint or dense configuration exceeding the local routing search produces `WIRE_ROUTE_BLOCKED` and no fabricated clear route. Arbitrary graph topology cannot guarantee absence of wire-to-wire crossings; this stage guarantees clear routes against node rectangles for routes it returns. Rich reroute editing and crossing presentation belong to the editor integration.

`graphLayoutService.ts` exports `requestGraphLayout(request, { signal, onProgress, useWorker, workerFactory, workerTimeoutMs, onFallback })`. It copies structural fields to support Vue proxies, gives each request one disposable worker, rejects cancellation as `AbortError`, ignores late replies, and falls back to the same chunked engine after unavailable/failed/timed-out workers. Worker-reported invalid-input errors remain errors. The 8ms cooperative yield threshold does not claim hard real-time interruption of a single JavaScript operation.
